# 物理教案设计

这是一个面向物理教师的备课网页应用，用来按课题、年级、课时和学情生成可审阅的教案框架。全站只有一张表，不要建登录、注册或权限页，不要新增表，不要编造表里没有的字段。页面运行在已注入 `callAppBridge` 的宿主中，表数据只走下列桥接调用，不要自建后端，不要用本地假记录冒充已保存教案。

统一主题叫「光谱备课台」：台面是浅灰蓝到雪白的纵向渐变，导航是深靛蓝，强调色用琥珀金细线，像光谱划过实验报告。标题用衬线字体，正文用柔和无衬线。卡片白底、细描边，悬停时轻微上浮并带淡靛色光晕。页眉可放极淡的公式水印（如 F=ma），不可抢内容。Logo 用内联 SVG 画一个简单原子轨道，不要外链图片。窄屏时导航收成一排文字，左右分栏改为上下堆叠。

表只有这些字段，名字必须原样使用：课题（文本）、年级（文本）、课时（数值）、学情与薄弱点（文本）、教案框架（指令流）。没有教案编号、创建日期、状态、图片字段，主体和表单都不要自行添加；也不存在需要隐藏的自动编号字段。布尔值本应用用不到。

教案框架不是手工填写的。它的指令描述是：请使用技能 xiaozhi-teach-physics-lesson-planner，为对应年级学生围绕课题设计指定课时的物理教案框架，并结合学情与薄弱点，以 Markdown 文本输出物理观念、概念引入与辨析、实验和数据归纳、模型建构、生活或科技应用训练及课堂小结；实验标注安全等级，结合薄弱点安排思路引导与变式训练，供教师审阅调整。前端不要调用该技能，不要自己编写教案正文。提交后由后台异步写入教案框架。指令要求的是 Markdown，不是 JSON，因此轮询字段就是教案框架。

数据源一律写 `物理教案/默认表格`。提交时表名写 `物理教案`。获取列表用 `callAppBridge({type:"GetTableCSV", data:"物理教案/默认表格", payload:"课题,年级,课时,学情与薄弱点,教案框架"})`。返回的 csv 不含标题行，列顺序就是 payload 的顺序；学情和教案框架里会有逗号、引号和换行，必须按带引号的 csv 解析，空列也要占位。行号从 1 开始，对应 csv 数据行的顺序，先记下原始行号再做搜索筛选，筛选后不准重排行号。课题可以重复，不要用课题反查行号。

新建用 `callAppBridge({type:"SubmitRecord", data:"物理教案", payload:表单JSON})`。JSON 只含课题、年级、课时、学情与薄弱点；课时是数值不是字符串；不要写入教案框架，以免盖住后台结果。提交成功后当前行固定为 1。然后每 2 秒调用 `callAppBridge({type:"GetCellValue", data:"物理教案/默认表格", payload:"教案框架/1"})`，直到内容为非空文本。空串、空白、null 都视为未完成。教案纸先显示「正在组织物理观念、实验与变式训练…」。超过 90 秒仍为空，则提示教师稍后到教案库打开，不要伪造一篇教案。

查看任一字段详情用 `callAppBridge({type:"GetCellValue", data:"物理教案/默认表格", payload:"字段名/行号"})`。教案框架用 Markdown 主题渲染，保留实验安全等级等原文，不要改成纯文本摘要。修改已有记录时，对当前行依次调用 `callAppBridge({type:"SetCellValue", data:"物理教案/默认表格", payload:"字段名/行号/值"})`，只更新课题、年级、课时、学情与薄弱点，禁止对教案框架调用 SetCellValue。不要用 SubmitRecord 充当修改。删除用 `callAppBridge({type:"DeleteRecord", data:"物理教案/默认表格", payload:行号.toString()})`。记录数用 `callAppBridge({type:"GetRecordCount", data:"物理教案/默认表格"})`。本应用不需要选图、拍照、录音和关联表。

页面顶部固定导航。左侧是轨道 Logo 和「物理教案设计」。右侧三个标签：首页、设计教案、教案库。当前页标签用琥珀金下划线。点击只切换页面，不刷新丢失正在进行的轮询。

首页是备课台，不是表格页。
主标题：物理教案设计。说明：按课题与学情搭出可审阅的物理教案框架，实验安全等级和变式训练留给教师把关。
主按钮：设计新教案，跳到设计教案页，并准备一份空白草稿。
其下三张并列统计卡，数字来自真实接口，失败时显示「暂时无法统计」，不要填示例数字。
教案总数：`callAppBridge({type:"GetRecordCount", data:"物理教案/默认表格"})`。点击进入教案库并清除筛选。
覆盖年级：同一条 GetTableCSV 中年级去重后的个数。点击后页内展开年级分布小筹码；再点某个年级，进入教案库并按该年级筛选。
累计课时：同一条 csv 里课时转成数值后求和，非法值当 0。点击进入教案库。
接下来是最近教案。标题右侧有「全部教案」。列表必须用卡片，不用表格式首页。数据来自上述 GetTableCSV，取原始行号 1 到 4（新提交的记录在第 1 行）；不足 4 条就全部显示。每张卡片显示课题、年级筹码、课时（如「2 课时」）、学情与薄弱点前 40 字；教案框架不铺满卡片，只在有内容时显示「教案已生成」，否则显示「生成中」。点击卡片查看详情，不是只高亮。没有记录时显示空状态和「设计第一份教案」按钮，点击进入设计页。

设计教案页是左右分栏的备课台。左栏写需求，右栏是一张米白色「教案纸」。
左上标题：设计教案。说明：写清课题、年级、课时和薄弱点，生成后请审阅再使用。
左栏表单标题：物理教案。表：物理教案。字段与表定义一致。
课题：单行文本，占位「例如：牛顿第一定律」，必填。
年级：单行文本，必填。上方提供可点的建议筹码：八年级、九年级、高一、高二、高三，点中只填入文本，仍允许手改成其它年级。
课时：数值步进器，默认 1，最小 1，最大 12，必填；旁注「课时」。
学情与薄弱点：多行文本，占位「例如：惯性与力的概念容易混淆，分组实验分工不清」。可空，但为空时在按钮旁轻提示「填写薄弱点后，变式训练会更贴学生」。
教案框架：不出现输入框。它只出现在右侧教案纸上。
按钮：生成教案。课题、年级、课时不合法时禁用，并指出缺哪一项。点击后调用 SubmitRecord，当前行设为 1，按前面的规则轮询教案框架，结果渲染到教案纸。
按钮：再写一份。清空四个输入和教案纸，当前行设为 0，不删除刚才已经生成的记录。
按钮：导出教案。仅当教案纸已有正文时可点。先用 GetCellValue 取当前行的四个字段和教案框架，再 `callAppBridge({type:"WriteFile", data:文件名, payload:文本})`。文件名用 `physics-lesson-` 加随机数加 `.md`，避免课题里的特殊字符。文件正文依次写课题、年级、课时、学情与薄弱点，再空一行接教案框架原文。然后打开 `https://www.ithinkair.com:3031/download/` 加该文件名。不要用 private 链接下载，不要塞进 iframe。
按钮：去教案库。跳转教案库。
右栏教案纸在未生成时显示四段将要出现的结构名：物理观念、概念引入与辨析、实验和数据归纳、模型建构、生活或科技应用训练、课堂小结，并写一句「实验会标注安全等级，请教师审阅调整」。这只是空白纸上的栏目提示，不是教案内容。生成完成后，整页 Markdown 替换这些提示。纸张顶部用小字显示当前课题、年级和课时。

教案库页管理全部记录，仍用卡片墙，不要改成只读独立页，也不要另做一张只读表的页面。
左上标题：教案库。说明：查阅、修改基本信息或删除已生成的教案。
右上两个按钮：刷新、+ 设计新教案。刷新重新调用 GetTableCSV 和 GetRecordCount。+ 设计新教案进入空白设计页。
搜索框按课题或学情与薄弱点包含匹配，不区分多余空格。
筛选器是年级下拉，选项为「全部年级」加上 csv 里出现过的年级。改变搜索或筛选只隐藏卡片，不改变原始行号。
卡片字段与表单字段同源，GetTableCSV 的 payload 必须是 `课题,年级,课时,学情与薄弱点,教案框架`。卡片正面显示课题、年级、课时、学情前 60 字、教案框架是否已生成。点击卡片空白处打开详情。每张卡片上的按钮都要单独实现，点击时不要误触详情：
查看：打开教案纸详情层。
编辑：打开编辑层，不是新建。
删除：先确认「确定删除该教案？删除后不可恢复」。确认后 DeleteRecord，payload 为该原始行号的字符串。成功后刷新列表和首页统计；若删的是当前行，当前行改为 0 并关掉详情。取消则什么都不做。
导出：与设计页同一套 WriteFile 规则，文本以该行 GetCellValue 为准。
没有匹配项时显示「没有找到对应教案」和清除筛选按钮。一条记录都没有时显示空状态和设计按钮。

详情层盖在当前页上，标题为课题，不是新的只读站点页面。打开时把当前行设为该卡片行号，并用 GetCellValue 逐个读取课题、年级、课时、学情与薄弱点、教案框架。前四项放在教案纸上方的信息条里，教案框架用 Markdown 渲染。若教案框架仍为空，信息条显示「尚未生成」，并每 2 秒继续轮询该行的教案框架，最多 90 秒。
详情层按钮：
关闭：关掉层，不改数据。
编辑信息：打开编辑层。
导出教案：导出当前行。
删除：与卡片删除相同。
上一条：行号减 1；当前行小于等于 1 时不可点。
下一条：行号加 1；当前行大于等于当时的 GetRecordCount 时不可点。切换时重新 GetCellValue，不要沿用上一份的 Markdown。
从首页最近卡片进入的也是这一层。

编辑层标题：修改教案信息。只编辑课题、年级、课时、学情与薄弱点，校验规则与设计页相同。教案框架在层内只读预览，不能改字。打开时用 GetCellValue 填充，不要只靠卡片上的截断文字。
保存修改：依次 SetCellValue 四个字段到当前行，然后重新 GetCellValue 刷新卡片和详情。保存不会重写教案框架，按钮下方写明「修改学情不会自动重写教案；若要按新学情重做，请重新生成」。
取消：关闭编辑层，不写回。
重新生成：用当前表单里的四个值 SubmitRecord 一份新记录，当前行变为 1，回到设计教案页并轮询新的教案框架。旧记录保留，并用轻提示说明「已另存为一份新教案」。不要在重新生成时调用 DeleteRecord。

当前行初始为 0。只有 SubmitRecord 成功才把当前行设为 1。编辑、查看、删除都使用打开时所记的原始行号。所有按钮的等待态要禁止连点。桥接调用失败时用一句话说明失败，保留用户已填写的课题和学情，不要清空草稿，也不要编造生成结果。
