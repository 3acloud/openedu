# 化学解题教练
	这是一个面向初中与高中必修起点的化学解题教练网页应用，包含首页、解题台、解题档案三个页面。学生先写下题目和已有尝试，再由后台按「定物质、三重表征、写式列式、守恒检验」异步生成分步提示。页面不预写原题答案，不在学生尝试前替学生交卷。
	全站统一「钴蓝试剂瓶」主题：导航与主按钮为深钴蓝 #163A5F，强调色为焰色铜橙 #E07A3D，辅助色为试剂青绿 #2A9D8F，页面背景是纸白到浅雾蓝的渐变 #F7F4EF → #E7EEF6。卡片白底、细边、轻阴影，悬停时轻微上浮并显出淡淡的六边形分子水印。字体用柔和 sans-serif。空状态用一只空烧瓶插画，不要用报错弹窗代替空列表。不包含登录、注册、权限页面。
	页面顶部固定导航栏，深钴蓝背景
		左侧显示烧瓶 Logo 和「化学解题教练」
		右侧标签：首页、解题台、解题档案
		当前页标签用铜橙色下划线标出，点击标签切换页面
	首页
		主标题：化学解题教练
		说明：先把题目和你已经写下的尝试交给教练。教练不直接公布原题答案，而是按定物质、三重表征、写式列式、守恒检验逐级给提示。
		主按钮：开始解题，点击进入「解题台」，并清空未保存的草稿，当前行设为 0
		次按钮：查看解题档案，点击进入「解题档案」
		方法阶梯：横向四张小卡片，只解释方法名称，不写任何例题答案
			定物质：先确认反应物、生成物和题目在问谁
			三重表征：把宏观现象、符号和图示对齐
			写式列式：再写方程式或关系式，并配平
			守恒检验：用质量、原子、电荷或电子守恒回头检查
		并列三张统计卡片，悬停上浮，点击后进入解题档案并带上对应筛选
			总解题数：显示全部记录数
				API名称:GetRecordCount,数据源:化学解题/默认表格
				callAppBridge({type:"GetRecordCount", data:"化学解题/默认表格"})
			已写下尝试：统计「已有尝试」去空白后不为空的记录数
				API名称:GetTableCSV,数据源:化学解题/默认表格,字段:[年级,题目,已有尝试]
				callAppBridge({type:"GetTableCSV", data:"化学解题/默认表格", payload:"年级,题目,已有尝试"})
			覆盖年级：统计「年级」去重后的个数，同一接口结果在前端计算
		最近解题：卡片列表，取表格前 5 行；提交后新记录在第 1 行，因此行号越小越新
			API名称:GetTableCSV,数据源:化学解题/默认表格,字段:[年级,题目,已有尝试]
			每张卡片显示年级徽章、题目（最多两行）、已有尝试摘要；已有尝试为空时显示「尚未写下尝试」
			没有记录时显示空烧瓶和「还没有解题记录」
			点击卡片查看详情：跳到解题台，当前行设为该卡片行号，并按下方「读取一行」加载年级、题目、已有尝试和解题引导
	解题台
		左右分栏：左侧是「实验记录单」，右侧是「教练批注」。窄屏改为上下排列，批注在记录单下面。
		左上标题：解题台
		说明：选出年级，写下题目。已有尝试可留空；留空时教练从下一步提示开始，而不是直接给出原题答案。
		右上文字按钮：解题档案，点击进入解题档案
		年级用六个试剂瓶芯片单选，必须使用原文：初一、初二、初三、高一、高二、高三。初中三个用青绿，高中三个用钴蓝，选中项加铜橙描边。不可多选，不可自造「七年级」等别名。
		表单标题:化学解题,表:化学解题,字段:[{字段名:年级,类型:单选项,可选项:初一,初二,初三,高一,高二,高三},{字段名:题目,类型:文本},{字段名:已有尝试,类型:文本}]
			题目是多行文本，占位示例只提示题型，不附带答案：「例如：用石灰石和稀盐酸制取二氧化碳，写出化学方程式，并说明如何检验该气体」
			已有尝试是多行文本，占位：「写下你已经判断出的物质、方程式或卡在哪一步；还没写也可以」
			本表没有自动编号 ID，也没有创建日期，不要编造记录编号、创建时间等字段，不要在表单上隐藏一个不存在的字段
			解题引导是指令流，不是手工输入项，不出现在可编辑表单里，也不放进 SubmitRecord 的 JSON
		按钮必须全部实现
			生成分步引导：年级和题目都有值才可点。点击后用 SubmitRecord 新建记录，不要把解题引导写进 payload
				callAppBridge({type:"SubmitRecord", data:"化学解题", payload:"{\"年级\":\"所选年级\",\"题目\":\"题目原文\",\"已有尝试\":\"已有尝试原文或空字符串\"}"})
				提交后当前行固定为 1，然后立刻按「轮询解题引导」处理
			保存修改：仅当前行大于等于 1 时可点。依次 SetCellValue 更新年级、题目、已有尝试，禁止用 SubmitRecord 修改，禁止改写解题引导
				callAppBridge({type:"SetCellValue", data:"化学解题/默认表格", payload:"年级/当前行/新年级"})
				callAppBridge({type:"SetCellValue", data:"化学解题/默认表格", payload:"题目/当前行/新题目"})
				callAppBridge({type:"SetCellValue", data:"化学解题/默认表格", payload:"已有尝试/当前行/新已有尝试"})
				保存成功后提示「记录已更新。指令流不会因保存而重新生成」。
			按当前内容重新生成：年级和题目有值才可点。这是再新建一条，不是修改旧行。先向学生说明「会新增一条记录，原记录仍保留」，确认后走与「生成分步引导」相同的 SubmitRecord，当前行变为 1，再轮询新的解题引导
			清空：清空年级、题目、已有尝试和右侧批注，当前行设为 0，不删除任何记录
			删除本条：仅当前行大于等于 1 时可点。确认后删除
				callAppBridge({type:"DeleteRecord", data:"化学解题/默认表格", payload:当前行.toString()})
				删除后清空表单，当前行设为 0，并刷新首页统计可依赖的记录数
			刷新引导：对当前行再取一次解题引导；当前行为 0 时不可点
		右侧教练批注
			未生成时显示四步阶梯说明和一句「生成后，批注会出现在这里」
			等待时显示冒泡烧瓶动画和等待文案：「正在按定物质、三重表征、写式列式、守恒检验整理提示，不会直接公布原题答案。」
			生成结束后，解题引导用 Markdown 主题渲染，标题、列表、强调沿用钴蓝与铜橙，不要把 Markdown 源码原样甩出
			若正文里出现「定物质」「三重表征」「写式列式」「守恒检验」这四个小标题，点亮左侧对应阶梯；没有这些标题时，四步只作阅读索引，不要编造「当前进行到第几步」
			批注区右上角是「<」和「>」
				API名称:GetRecordCount,数据源:化学解题/默认表格
				当前行初始为 0
				当前行小于等于 1 时，「<」不可操作
				当前行为 0 且记录数为 0，或当前行大于等于记录数时，「>」不可操作
				点「<」读取当前行减 1；点「>」在当前行为 0 时读取第 1 行，否则读取当前行加 1
		读取一行时，逐字段调用 GetCellValue，不要靠列表摘要填充
			callAppBridge({type:"GetCellValue", data:"化学解题/默认表格", payload:"年级/行号"})
			callAppBridge({type:"GetCellValue", data:"化学解题/默认表格", payload:"题目/行号"})
			callAppBridge({type:"GetCellValue", data:"化学解题/默认表格", payload:"已有尝试/行号"})
			callAppBridge({type:"GetCellValue", data:"化学解题/默认表格", payload:"解题引导/行号"})
			前三项填入左侧表单，解题引导渲染到右侧
		轮询解题引导
			指令描述没有要求「以JSON格式输出」，所以轮询指令流字段「解题引导」，不要另找品种、描述之类不存在的字段
			前端不要自己调用化学模型，也不要改写字段上的技能指令；解题引导只由 SubmitRecord 之后的后台异步生成
			每 1.5 秒调用一次 GetCellValue，数据源为化学解题/默认表格，payload 为「解题引导/1」
			得到非空文本后停止轮询，用 Markdown 显示，并轻提示「引导已生成」
			超过 60 秒仍为空，则停止自动轮询，保留等待文案，并让「刷新引导」可点；不要用本地假答案填补
			轮询期间禁用「生成分步引导」和「按当前内容重新生成」，避免重复提交
	解题档案
		左上标题：解题档案
		说明：回看每一次题目、尝试和教练批注。卡片可悬停，点击卡片展开详情。
		右上按钮：+ 新的解题，进入解题台并执行清空，当前行设为 0
		搜索框：按题目关键字筛选
		筛选芯片：全部、初一、初二、初三、高一、高二、高三。选中年级后只留该年级
		列表数据
			API名称:GetTableCSV,数据源:化学解题/默认表格,字段:[年级,题目,已有尝试]
			callAppBridge({type:"GetTableCSV", data:"化学解题/默认表格", payload:"年级,题目,已有尝试"})
			返回值没有标题行。题目和已有尝试可能含逗号、引号或换行，按标准 CSV 解析，禁止用简单的 split(',') 截断
			行号从 1 开始，与 CSV 数据行顺序一致，第 1 行是最新提交
			GetTableCSV 的字段与可编辑表单字段一致：年级、题目、已有尝试。解题引导是指令流详情，不进 CSV，查看时另取
		主体用卡片，不用只读大表格独占一页。每张卡片显示年级、题目、已有尝试摘要
			点击卡片：展开详情，不跳走
			查看引导：详情区显示完整题目、完整已有尝试，并调用 GetCellValue 取「解题引导/该行」，用 Markdown 主题显示；内容为空时显示「这条记录的引导还没生成，可回解题台刷新」
			编辑：进入解题台，当前行设为该行，按「读取一行」填表。之后的保存只能走 SetCellValue
			删除：确认后 callAppBridge({type:"DeleteRecord", data:"化学解题/默认表格", payload:行号.toString()})，然后重新 GetTableCSV 刷新卡片，不缓存旧行号
		详情底部按钮：去解题台修改、删除、收起。三个按钮都要实现
		无匹配结果时显示「没有符合条件的解题记录」，并保留「+ 新的解题」
	数据操作约定
		只使用表「化学解题」里已有字段：年级、题目、已有尝试、解题引导。数据源写「化学解题/默认表格」。SubmitRecord 的 data 写「化学解题」
		获取列表：callAppBridge({type:"GetTableCSV", data:"化学解题/默认表格", payload:"年级,题目,已有尝试"})
		获取记录数：callAppBridge({type:"GetRecordCount", data:"化学解题/默认表格"})
		按值查行：callAppBridge({type:"GetRecordRow", data:"化学解题/默认表格", payload:"字段名/值"})，行号从 1 开始。本应用主路径用 CSV 顺序行号，只有需要按题目精确反查时才用 GetRecordRow
		读取单元格：callAppBridge({type:"GetCellValue", data:"化学解题/默认表格", payload:"字段名/行"})
		读取单元格 Bullet：callAppBridge({type:"GetCellBullet", data:"化学解题/默认表格", payload:"字段名/行"})。本表无需要展示的 Bullet 字段时不要凭空做一层标签
		新建只走 SubmitRecord，payload 是 JSON 文本，只含年级、题目、已有尝试。提交成功后当前行是 1
		修改只对当前行依次 SetCellValue，payload 形如「字段名/行/值」。不要用 SubmitRecord 冒充修改
		删除的 payload 必须是文本，行号先 toString()
		布尔值若将来出现，只能用「是」或「否」。本表没有布尔字段，不要加
		指令流字段解题引导不是用户填写的。要看详情，先 GetCellValue，再用 Markdown 主题显示
		本表无关联表，不要再套一层 GetTableCSV 去查不存在的关联表
		本表无图片、无文件字段，不要调用 SelectImage、SelectFile、CapturePhoto，也不要拼接 download 或 private 文件链接
		没有创建日期和自动编号字段，主体卡片和表单都不要显示这类自造字段
	全局约束
		所有出现的按钮、卡片点击、筛选、搜索、上一行、下一行、刷新、保存、删除、重新生成都必须真正可用，不能只有样式
		从首页最近卡片、档案卡片进入详情时，都要能看到该行的解题引导，不能只展开题目摘要
		编辑时加载的字段要和列表字段一致，避免点开后年级或题目是空的
		界面文案保持初中到高中必修能读懂的语气。可以提示下一步该想什么，不可以在静态页面、占位符、空状态或按钮说明里写好标准答案、配平结果或实验结论
		各页颜色、圆角、悬停和烧瓶 Logo 保持同一套钴蓝试剂瓶主题
