# 化学用语教练

这是一个面向初高中学生的化学用语练习网页应用，版式像一本摊开的实验记录本。学生一次只选一个层级，写下问题或自己的作答，提交后由后台教练检查书写、化合价与配平，并逐步提示。包含首页、练习台、练习册三个页面。不要登录页。不要编造表里没有的字段，不要出现编号、创建日期等字段。页面禁止本地生成或写死辅导文本，辅导内容只能来自后台异步写入的「辅导反馈」。

页面统一主题「实验记录本」：暖纸色背景 `#F4F0E6`，带极淡的六边形晶格水印；顶部导航为深海试剂蓝 `#0E3A4D`；主按钮为焰色铜橙 `#D4782A`；辅助色为铜绿 `#2A9D8F`。字体使用 `"Noto Sans SC","PingFang SC",sans-serif`。卡片白底、圆角 16px、轻阴影，悬停上浮并按练习方向染边。化学式在界面中用等宽字体。各页面操作按钮的功能必须全部实现，不要只做外观。

页面顶部导航栏，深海试剂蓝背景，底部一条铜橙色细线
	左侧是锥形瓶图标和「化学用语教练」
	右侧标签：首页、练习台、练习册；当前页铜橙色下划线
	窄屏时标签可横向滚动，不折叠丢失

数据操作约定（必须调用，不要用本地假数据）
	读取列表：callAppBridge({type:"GetTableCSV", data:"化学用语练习/默认表格", payload:"学段,已开设化学课,练习方向,问题或作答,辅导反馈"})
		返回不含标题行的 csv，字段顺序与 payload 一致
		按标准 CSV 引号规则解析，问题或作答、辅导反馈中可能含逗号和换行
		全表第 1 条数据对应行号 1；筛选后仍保留原始行号，删除、取值、改值都用原始行号
	记录数：callAppBridge({type:"GetRecordCount", data:"化学用语练习/默认表格"})
	新建：callAppBridge({type:"SubmitRecord", data:"化学用语练习", payload:表单JSON文本})
		只提交用户字段，不要把辅导反馈写进 JSON
		布尔值只能是「是」或「否」，不能用 true/false
		提交成功后当前行设为 1
	详情：callAppBridge({type:"GetCellValue", data:"化学用语练习/默认表格", payload:"字段名/行"})
		指令流字段「辅导反馈」的详情必须以 GetCellValue 为准，并用 Markdown 渲染
	修改：callAppBridge({type:"SetCellValue", data:"化学用语练习/默认表格", payload:"字段名/行/值"})
		只改当前行的用户字段，逐字段调用，不用 SubmitRecord
		值里若含斜杠，分隔只取前两处斜杠，其余全部算作值
		不要对「辅导反馈」调用 SetCellValue
	删除：callAppBridge({type:"DeleteRecord", data:"化学用语练习/默认表格", payload:行号.toString()})
		payload 必须是文本
	当前行初始为 0。行号从 1 开始。新提交的记录在第 1 行。

首页
	主标题：化学用语教练
	说明：一次练一个方向，把元素符号、化合价、化学式和方程式写规范
	主按钮：开始练习，点击进入「练习台」
	其下是三个统计卡片，进入页面时重新计算
		练习总次数
			API名称:GetRecordCount,数据源:化学用语练习/默认表格
		初中练习数、高中练习数
			API名称:GetTableCSV,数据源:化学用语练习/默认表格,字段:[学段]
			按「学段」计数；点击卡片进入练习册并带上对应学段筛选
	接下来是六个练习方向试剂卡，横排自动换行，每张卡一种颜色
		元素符号用钴蓝，化合价用铜橙，化学式用翠绿，化学方程式用靛青，离子方程式用品红，电子转移用琥珀金
		每张卡显示方向名和一句短提示：元素符号看大小写，化合价先标再查，化学式核对原子个数，化学方程式先写再配平，离子方程式拆强电解质，电子转移标明得失
		数量来自 GetTableCSV 字段「练习方向」的分组计数
		点击某张卡进入练习台，并预选该练习方向
	最近练习：卡片列表，取全表前 5 行（无日期字段，第 1 行即最新）
		API名称:GetTableCSV,数据源:化学用语练习/默认表格,字段:[学段,已开设化学课,练习方向,问题或作答,辅导反馈]
		每张卡片显示学段、已开设化学课（是显示「已开课」，否显示「未开课」）、练习方向色标、问题或作答前 42 字
		辅导反馈只显示前 36 字纯文本摘要；为空则显示「教练还在写」
		点击卡片查看详情，不要只高亮
		无记录时显示空状态：「还没有练习，去写第一道小题」，按钮进入练习台
	详情层（首页最近卡片与练习册共用）
		逐字段 GetCellValue 填充：学段、已开设化学课、练习方向、问题或作答、辅导反馈
		API名称:GetCellValue,数据源:化学用语练习/默认表格,字段名:对应字段,行号:该卡片原始行号
		辅导反馈用 Markdown 主题显示在米黄色记录纸上，纸面左侧有一条红线
		辅导反馈为空时显示「教练还在写反馈」，并提供「刷新反馈」按钮，再次 GetCellValue
		详情按钮：编辑（进入练习台编辑模式）、删除（确认后 DeleteRecord）、关闭
		这些按钮都必须可用

练习台
	左上标题：练习台
	说明：一次只练一个层级。先写你的问题，或写下你自己的化学式、方程式，教练会指出错在哪一步
	右上按钮：查看练习册，进入练习册
	左侧是书写区，右侧是辅导反馈纸。窄屏改为上下排列
	表单标题:化学用语练习,表:化学用语练习,字段:[{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:已开设化学课,类型:布尔},{字段名:练习方向,类型:单选项,可选项:元素符号,化合价,化学式,化学方程式,离子方程式,电子转移},{字段名:问题或作答,类型:文本},{字段名:辅导反馈,类型:指令流,指令类型:任务智能体}]
		辅导反馈不是输入项，不出现在填写区，也不放进 SubmitRecord 的 JSON
		学段用两个大选项卡，默认「初中」
		已开设化学课用开关，开为「是」，关为「否」，默认「是」；旁边短句：还没开课选「否」，教练会从更基础的写法讲起
		练习方向用六张可点选的试剂卡，同一时间只能选中一张，默认「元素符号」
		若学段为初中且选中离子方程式或电子转移，显示不阻断的提示：这两个方向通常在高中练习，仍可提交，教练会按学段把握深浅
		问题或作答是多行文本，按当前练习方向切换占位例句
			元素符号：氧的元素符号怎么写？我把钠写成了 na
			化合价：硫酸里硫显多少价？请看我标的对不对
			化学式：二氧化碳的化学式是什么？我写的是 CO3
			化学方程式：氢气在氧气中燃烧，我配平的方程式对吗
			离子方程式：盐酸与氢氧化钠反应的离子方程式
			电子转移：锌与稀硫酸反应，标出电子转移
		方向卡下方有两个例句芯片，点击把对应例句填入问题或作答，学生仍可再改
		问题或作答去掉首尾空格后为空时，「获取辅导」不可点，并提示「先写下问题或你的作答」
		超过约 800 字时提示「一次只练一个小题，写短一点，教练才好逐步提示」，不禁止提交
		静态小字：若这是正在进行的考试，教练会约你考后再复盘，而不会当场给出完整答案
	按钮：获取辅导
		仅新建模式可用。点击后防重复点击
		payload 为 JSON 文本，例如 {"学段":"初中","已开设化学课":"是","练习方向":"元素符号","问题或作答":"学生输入"}
		API名称:SubmitRecord,数据源:化学用语练习,字段为上述四个用户字段
		提交后当前行设为 1
		右侧反馈纸先显示等待文案：「教练正在看你的作答，先不直接报答案……」
		轮询标题:化学用语练习,表:化学用语练习,字段:辅导反馈,输出到:辅导反馈纸,等待消息:教练正在看你的作答，先不直接报答案……
		指令描述没有指定「以JSON格式输出」，所以只轮询「辅导反馈」，不要轮询别的字段
		每 1.5 秒调用一次 GetCellValue，payload 为「辅导反馈/1」
		得到非空文本后停止轮询，用 Markdown 渲染到反馈纸
		约 60 秒仍为空则停止自动轮询，提示「生成时间较长，可稍后刷新」，并显示「刷新反馈」按钮，点击后再 GetCellValue
	按钮：再练一题
		清空问题或作答和反馈纸上的显示，当前行设为 0，保留学段、已开设化学课、练习方向
		不删除任何记录
	反馈纸右上角有浏览按钮，数据来自 GetCellValue，不用本地缓存冒充
		API名称:GetRecordCount,数据源:化学用语练习/默认表格
		按钮 < ：行号加 1，查看更早一条；当前行小于 1 或当前行已达记录数时不可操作
		按钮 > ：行号减 1，查看更新一条；当前行小于等于 1 时不可操作
		切换行时用 GetCellValue 读回学段、已开设化学课、练习方向、问题或作答、辅导反馈，填写区同步显示该行，进入浏览态而不是编辑态
		若该行辅导反馈仍为空，沿用同一等待与刷新逻辑，轮询字段仍是该行的辅导反馈
	编辑模式（从详情或练习册进入时）
		顶部提示：正在修改第 N 行。保存只更新作答信息，不会重新生成辅导反馈
		用 GetCellValue 逐字段填入表单；辅导反馈只在右侧 Markdown 展示
		按钮「获取辅导」隐藏
		按钮：保存修改
			依次 SetCellValue 更新当前行的学段、已开设化学课、练习方向、问题或作答
			已开设化学课仍写「是」或「否」
			不调用 SubmitRecord，不改辅导反馈
			保存成功后提示「已保存」，练习册列表刷新
		按钮：作为新练习重新辅导
			用当前表单四个用户字段 SubmitRecord，当前行改为 1，再按新建流程轮询第 1 行的辅导反馈
			这是新记录，不覆盖正在编辑的旧行
		按钮：取消编辑，退出编辑模式，清空填写区，当前行设为 0

练习册
	左上标题：练习册
	说明：回看每一次书写和教练的逐步提示
	右上按钮：+ 新的练习，进入练习台的新建模式
	搜索框：按问题或作答包含的文字筛选，输入即筛
	筛选器：学段（全部、初中、高中），练习方向（全部及六个方向），已开设化学课（全部、是、否）
	筛选在前端对 GetTableCSV 的结果进行，卡片上的行号保持全表原始行号
	主体用卡片列表，不用另做只读表页面。卡片字段与表单字段一致：学段、已开设化学课、练习方向、问题或作答、辅导反馈
		API名称:GetTableCSV,数据源:化学用语练习/默认表格,字段:[学段,已开设化学课,练习方向,问题或作答,辅导反馈]
		问题或作答显示前 80 字，辅导反馈显示前 60 字纯文本；辅导反馈为空显示「生成中」
		点击卡片主体打开与首页相同的详情层
		每张卡片的操作按钮：查看详情、编辑、删除，三个都要实现
			查看详情：打开详情层，辅导反馈以 GetCellValue 的 Markdown 全文显示
			编辑：进入练习台编辑模式，当前行等于该卡片原始行号，逐字段 GetCellValue 填表
			删除：先确认「确定删除这条练习吗？」，确认后 callAppBridge({type:"DeleteRecord", data:"化学用语练习/默认表格", payload:行号.toString()})，然后重新 GetTableCSV 与 GetRecordCount
	无匹配时显示「没有找到这样的练习」，并给出清除筛选按钮
	从首页带着学段或练习方向进来时，对应筛选器处于选中状态

全局交互
	从任一页面返回首页时重新统计，并刷新最近 5 条
	详情、编辑、删除、筛选、搜索、翻阅、刷新反馈、再练一题、保存修改、作为新练习重新辅导，每一项都要真正调用对应接口或真正改变界面状态
	Markdown 区域渲染标题、列表、加粗和行内代码，便于阅读化学式；不要把辅导反馈当作可执行 HTML 插入页面
	全站无登录、无注册、无个人中心。配色、卡片悬停和导航在三个页面保持一致
