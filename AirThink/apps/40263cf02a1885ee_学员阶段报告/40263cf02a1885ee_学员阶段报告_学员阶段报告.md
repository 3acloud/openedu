# 学员阶段报告书案

这是一个供教师审阅使用的学员阶段报告网页应用，不是家长端，也不提供发送功能。依据表「阶段报告」起草、审阅和归档阶段报告。页面统一采用「灯下书案」主题：米纸色背景（#F3EDE2 渐变到淡青雾 #E7F0F2），顶部为墨蓝导航（#1C2B3A，底边一条薄金线 #C6A15B），卡片为暖白纸（#FFFCF7，1px #E4D7C3 边，圆角 16px），主按钮石青（#1F4E5F），强调色朱砂（#B55233）。标题用衬线字体，正文用柔和 sans-serif。卡片和按钮有上浮与阴影悬停。不包含登录、注册或账号页。不要编造表里没有的字段，尤其不要编造编号、创建日期、真实姓名、电话、邮箱、百分比或课时。

表只有这些字段：学员化名（文本）、报告类型（单选项：中期报告、续课报告、期末报告、里程碑报告、应答报告）、学习记录文件（文本，存文件全局文件名）、允许家长沟通（布尔，值只用「是」或「否」）、允许分享课堂状态（布尔，值只用「是」或「否」）、报告（指令流，不是手工填写，SubmitRecord 后由后台异步生成）。本表没有自动编号 ID，也没有创建日期，表单和列表都不要出现这类字段。

操作表只使用下列方式，数据源固定为「阶段报告/默认表格」：
使用 callAppBridge({type:"GetTableCSV", data:"阶段报告/默认表格", payload:"学员化名,报告类型,学习记录文件,允许家长沟通,允许分享课堂状态,报告"}) 获取不含标题行的 csv。csv 第 1 行数据对应行号 1。按 CSV 规范解析，字段内逗号和换行按引号处理。列表筛序时必须记住原始行号，不能把筛选后的序号当成行号。
使用 callAppBridge({type:"GetRecordCount", data:"阶段报告/默认表格"}) 获取记录数。
使用 callAppBridge({type:"GetCellValue", data:"阶段报告/默认表格", payload:"字段名/行"}) 查看单元格。报告详情一律用 GetCellValue 取「报告」，再用 Markdown 主题渲染，不要拿 csv 里的报告列当正文。
使用 callAppBridge({type:"SubmitRecord", data:"阶段报告", payload:"表单JSON文本"}) 新建。提交后当前行是 1。JSON 只含学员化名、报告类型、学习记录文件、允许家长沟通、允许分享课堂状态，不要提交手写的报告。
使用 callAppBridge({type:"SetCellValue", data:"阶段报告/默认表格", payload:"字段名/行/值"}) 修改当前行。修改不是 SubmitRecord，也不要改写「报告」。
使用 callAppBridge({type:"DeleteRecord", data:"阶段报告/默认表格", payload:"行号字符串"}) 删除。行号必须 toString() 后再传。
学习记录文件用 callAppBridge({type:"SelectFile"})、callAppBridge({type:"SelectImage"}) 或 callAppBridge({type:"CapturePhoto"}) 取得全局文件名。下载链接是 https://www.ithinkair.com:3031/download/全局文件名 ；浏览器打开链接是 https://www.ithinkair.com:3031/private/全局文件名 。图片用下载链接显示；html 用 private 链接放进 iframe。可读文本预览才调用 callAppBridge({type:"ReadFile", data:"全局文件名"})，乱码或二进制则提示改用下载或打开，不要把乱码写进报告。

「报告」没有指定以 JSON 格式输出，所以 SubmitRecord 后轮询的就是「报告」字段，不是别的字段。前端不调用生成技能，不拼装、不改写、不删减报告，不把定性判断换算成百分比，不补缺失数字。应用内不要出现发送、邮件、外部分享或推送给家长的按钮。

页面顶部导航栏，墨蓝底、金色细线
	左侧是台灯与打开的笔记本图标，以及「阶段报告书案」
	右侧标签：首页、起草报告、报告卷宗
	当前页标签用金线标出。点击标签切换页面，不整页刷新丢失已打开的审阅抽屉状态时可先关闭抽屉。

首页
	主标题：阶段报告书案
	说明：凭学习记录起草可核验的阶段报告、后续学习计划和续课建议，只供教师审核，不从这里发送。
	主按钮：起草新报告，跳转到「起草报告」
	次按钮：打开报告卷宗，跳转到「报告卷宗」
	三张并列统计卡片，点击后跳到报告卷宗并带上对应筛选，功能必须实现
		报告总数
			API名称:GetRecordCount,数据源:阶段报告/默认表格
		可沟通份数：允许家长沟通为「是」的数量
			API名称:GetTableCSV,数据源:阶段报告/默认表格,字段:[学员化名,报告类型,学习记录文件,允许家长沟通,允许分享课堂状态,报告]
			在前端筛选允许家长沟通为「是」后计数
		可分享课堂状态份数：允许分享课堂状态为「是」的数量
			同一份 csv 中筛选允许分享课堂状态为「是」后计数
	其下是报告类型分布：五枚横向细条，分别统计中期报告、续课报告、期末报告、里程碑报告、应答报告的数量。点击某一条，跳到报告卷宗并按该类型筛选。没有记录时条形为 0，不要编造样例数据。
	最近卷宗：卡片列表，取 csv 前 5 行。新提交记录在第 1 行，所以前 5 行就是最近 5 份，不要发明日期字段来排序。
		每张卡片显示学员化名、报告类型色标、允许家长沟通、允许分享课堂状态、学习记录文件名。报告只显示 GetCellValue 正文的前 60 字纯文本摘要；取摘要失败就显示「待审阅」，不要用 csv 错列内容冒充摘要。
		点击最近卡片：进入报告卷宗并打开该原始行号的详情抽屉，而不是直接进入编辑。
		无记录时显示空书案插图和按钮「起草第一份报告」。

「起草报告」页面
	左半是案头表单，右半是审阅纸。窄屏改为上下排列。
	左上标题：起草报告
	说明：填写化名、报告类型并附上学习记录。生成结果只在右侧供教师审核。
	表单标题:阶段报告,表:阶段报告,字段:[{字段名:学员化名,类型:文本},{字段名:报告类型,类型:单选项,可选项:中期报告,续课报告,期末报告,里程碑报告,应答报告},{字段名:学习记录文件,类型:文本},{字段名:允许家长沟通,类型:布尔},{字段名:允许分享课堂状态,类型:布尔},{字段名:报告,类型:指令流}]
		报告出现在字段定义中，但表单上不是输入框，只在右侧审阅纸只读展示。
		学员化名必填。输入里如果出现连续电话号码或 @，在字段下提示「请使用学员化名，不要填写电话或邮箱」，不自动改写用户输入。
		报告类型用五枚可选芯片，必须且只能选一个。芯片旁的静态说明仅帮助教师选择，不参与生成：中期报告是阶段盘点，续课报告侧重后续计划与续课建议，期末报告是阶段收束，里程碑报告标记关键进步，应答报告回应特定问询。
		允许家长沟通、允许分享课堂状态用开关，提交值只能是「是」或「否」，默认「否」。开关下方用短句说明：家长可见内容和课堂状态是否写入报告，由后台根据记录中的授权和这两个开关决定；关闭时不要期望前端另外生成家长版。
	学习记录区
		按钮：选择学习记录，调用 SelectFile，把返回的全局文件名写入学习记录文件
		按钮：选择图片记录，调用 SelectImage，同样写入学习记录文件
		按钮：拍摄学习记录，调用 CapturePhoto，同样写入学习记录文件
		后一次选择覆盖前一次，并立即更新预览
		按钮：清除附件，清空学习记录文件和预览
		有文件名时显示文件名、下载、在浏览器打开。图片显示缩略图，html 用 iframe 打开 private 链接。
		按钮：预览文本，调用 ReadFile；仅在返回可读文本时显示在折叠区
	按钮：生成报告
		学员化名、报告类型、学习记录文件都有值时才可点击
		点击后用 SubmitRecord 提交，当前行设为 1
		提交 JSON 示例：{"学员化名":"小舟","报告类型":"续课报告","学习记录文件":"全局文件名","允许家长沟通":"否","允许分享课堂状态":"否"}
		轮询标题:阶段报告,表:阶段报告,字段:报告,输出到:审阅纸,等待消息:正在依据学习记录起草阶段报告，请稍候。此页只供教师审核，不会发送。
		每 2 秒调用一次 GetCellValue，数据源:阶段报告/默认表格,字段名:报告,行号:1
		得到非空文本后停止轮询，在审阅纸用 Markdown 渲染。等待期间按钮禁用，审阅纸显示等待消息，不要填入示例报告。
	生成完成后的按钮，都必须实现
		再起草一份：清空表单、附件预览和审阅纸，当前行设为 0，两个布尔恢复为「否」
		去卷宗审阅：跳转报告卷宗并打开第 1 行详情
	当前行初始是 0。当前行为 0 时审阅纸显示引导：附上学习记录后生成，正文将出现在这里。

「报告卷宗」页面
	左上标题：报告卷宗
	说明：检索、审阅和修正已提交的阶段报告。修正资料不会重新触发生成。
	右上按钮：起草新报告，跳转到「起草报告」
	搜索框：按学员化名包含匹配，前端过滤
	筛选器：报告类型（全部加五个可选项）、允许家长沟通（全部、是、否）、允许分享课堂状态（全部、是、否）
	筛选数据来自同一份 GetTableCSV，字段与表单一致：[学员化名,报告类型,学习记录文件,允许家长沟通,允许分享课堂状态,报告]
	主体是卡片列表，不用单独的只读页面。每张卡片就是一条记录，保留 csv 原始行号。
		卡片显示学员化名、报告类型色标、两个布尔药丸、学习记录文件名
		报告摘要只用该行 GetCellValue 的前 80 字纯文本；为空则显示「报告尚未生成」
		点击卡片：打开编辑抽屉并载入该行，便于直接改表单
		每张卡片的按钮都要实现：查看详情、编辑、删除、下载学习记录、打开学习记录
			查看详情：打开审阅抽屉，不进入编辑
			编辑：打开编辑抽屉
			删除：先确认「删除后不可恢复，且不会发送任何内容」，确认后 DeleteRecord，payload 为原始行号.toString()，然后重新 GetTableCSV 和 GetRecordCount
			下载、打开分别访问 download 与 private 链接；没有文件名时按钮禁用
	无匹配时显示空状态，并给出「清除筛选」按钮，点击后恢复全部。
	查看详情抽屉
		标题为学员化名加报告类型
		用 GetCellValue 逐字段读取当前行：学员化名、报告类型、学习记录文件、允许家长沟通、允许分享课堂状态、报告
		报告区用 Markdown 纸面呈现。空内容时显示「报告尚未生成，可稍后刷新」，不要编造正文
		学习记录沿用下载、打开、图片或 iframe、预览文本
		按钮：刷新报告，再次 GetCellValue 读取报告并渲染
		按钮：复制报告，把报告原文复制到剪贴板；报告为空时禁用
		按钮：编辑此份，关闭详情并打开同一行的编辑抽屉
		按钮：关闭
		右上角按钮 < 和 >
			< 读取上一原始行，> 读取下一原始行，数据都来自 GetCellValue
			API名称:GetRecordCount,数据源:阶段报告/默认表格
			当前行小于等于 1 时 < 不可操作
			当前行大于等于记录数时 > 不可操作
	编辑抽屉
		标题：修正报告资料
		提示：保存只更新当前行的资料字段，使用 SetCellValue，不会重新生成报告，也不会发送。
		载入时当前行等于卡片原始行号，五个可编辑字段均用 GetCellValue 填充。报告不放入输入框，只在抽屉底部只读显示 Markdown 摘要。
		可重新选择文件、图片或拍摄，覆盖学习记录文件；也可清除附件。
		按钮：保存修改。依次 SetCellValue 写入学员化名、报告类型、学习记录文件、允许家长沟通、允许分享课堂状态。布尔只能写「是」或「否」。不要 SetCellValue 报告，不要 SubmitRecord。完成后刷新卡片并保持当前行。
		按钮：取消，关闭抽屉且不写回。
		学员化名和报告类型为空时不能保存。

各页共通
	报告类型色标固定：中期报告石青、续课报告金棕、期末报告墨蓝、里程碑报告celadon、应答报告朱砂。
	布尔「是」用青色药丸，「否」用灰色药丸。
	所有列表用卡片，点击最近列表看详情，点击卷宗卡片进入编辑。
	操作中的按钮要有禁用态，失败时显示简短错误，不要用假数据填表。
	页脚固定一句：报告供教师审核使用，应用不发送报告。
	每个写到的按钮、筛选、跳转、轮询、预览和抽屉都必须真正实现。
