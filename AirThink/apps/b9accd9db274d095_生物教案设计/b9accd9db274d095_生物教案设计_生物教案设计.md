# 生物教案设计
	这是一个给初高中生物教师审定用的备课网页应用，只使用表「生物教案」。教师写下课题、学段、学情和真实课时，提交后由后台异步写成教案正文。无登录、无注册、无权限页。不要另建表，不要编造字段。
	全站是实验室手账，不是通用绿色后台。
		背景为暖纸色 #F3EEE4，带极淡方格，像教案纸
		顶栏由墨绿 #1C3D34 过渡到苔绿 #2F6A4A，底边一条金线 #C4A574
		标题用衬线，界面文字用无衬线
		Logo 用内联双叶 SVG，旁边写「生物教案设计」
		卡片白底、圆角 16px，悬停上浮并加重叶影
		主按钮为叶绿底白字；只有删除用浆果色 #A33B32，且必须二次确认
		学段不只靠颜色区分：初中色标旁仍写「初中」，高中色标旁仍写「高中」
	页面顶部导航栏
		左侧 Logo 与「生物教案设计」
		右侧标签：首页、备课台、教案册
		当前标签下划金线
		切换页面时，若备课台有未保存改动，先确认再离开

	数据操作约定
		数据源一律是：生物教案/默认表格
		SubmitRecord 的表名一律是：生物教案
		字段只有：课题、学段、年级、教材版本、班额、课时分钟数、学情与薄弱点、分层情况、教案内容
		本表没有自动编号 ID，没有创建日期，没有状态、图片、附件。不要出现记录编号、计划编号、创建时间、封面
		这些不存在的字段既不要显示在列表，也不要藏在表单里
		学段是单选项，提交值只能是「初中」或「高中」
		班额、课时分钟数是数值
		没有布尔字段，不要使用「是」「否」
		没有关联表，不要再请求其它数据源
		教案内容是指令流，不是手工项。不要做输入框，不要对它 SetCellValue
		它的指令描述没有写「以JSON格式输出」，所以只轮询「教案内容」，不要拆 JSON 子字段
		教案内容的详情用 Markdown 主题显示
		不要在前端调用技能 xiaozhi-teach-biology-lesson-planner；技能已在该字段的指令描述里，只在 SubmitRecord 后由后台执行
		列表：callAppBridge({type:"GetTableCSV", data:"生物教案/默认表格", payload:"课题,学段,年级,教材版本,班额,课时分钟数,学情与薄弱点,分层情况"})
			返回不含标题行。按标准 CSV 引号规则解析，禁止 split(',')
			CSV 第 1 行对应行号 1，往后顺延
		记录数：callAppBridge({type:"GetRecordCount", data:"生物教案/默认表格"})
		详情：callAppBridge({type:"GetCellValue", data:"生物教案/默认表格", payload:"字段名/行号"})
		修改已有行：对 8 个手填字段依次 callAppBridge({type:"SetCellValue", data:"生物教案/默认表格", payload:"字段名/行号/值"})
			只按前两个斜杠切分，值取第二个斜杠之后的整段
			修改用 SetCellValue，不用 SubmitRecord，也不重写教案内容
		新建：callAppBridge({type:"SubmitRecord", data:"生物教案", payload:"表单JSON文本"})
			JSON 只含 8 个手填字段，不含教案内容
			提交成功后当前行就是 1
			紧接着轮询教案内容
		删除：callAppBridge({type:"DeleteRecord", data:"生物教案/默认表格", payload:行号.toString()})
		本应用无图片、文件、语音，不要调用 SelectImage、SelectFile、CapturePhoto 和任何录音接口
		接口失败时提示「暂时无法连接教案册，请稍后重试」，不要填假记录，不要用示例教案冒充结果

	首页
		主标题：生物教案设计
		说明：把课题、学情和真实课时，收成一份待审定的生物教案
		按钮：开始备课，进入备课台，当前行设为 0，并清空表单
		三张并列统计卡，读数完成前显示「—」，悬停微抬
			教案总数
				API名称:GetRecordCount,数据源:生物教案/默认表格
			初中教案
				API名称:GetTableCSV,数据源:生物教案/默认表格,字段:[学段]
				只统计学段恰好为「初中」的行
			高中教案
				API名称:GetTableCSV,数据源:生物教案/默认表格,字段:[学段]
				只统计学段恰好为「高中」的行
		统计卡下一条细指标：平均班额
			API名称:GetTableCSV,数据源:生物教案/默认表格,字段:[班额]
			只对能解析的正数取平均，四舍五入为整数；没有记录时显示「—」
		最近生成
			说明：新提交的记录在第 1 行，取前 4 条，不要编造日期来排序
			API名称:GetTableCSV,数据源:生物教案/默认表格,字段:[课题,学段,年级,教材版本,班额,课时分钟数,学情与薄弱点,分层情况]
			用卡片，不用表格。行号等于 CSV 序号
			每张卡片显示课题、学段、年级、教材版本、班额、课时分钟数，学情与薄弱点截取前 36 字
			点击卡片进入教案册，并打开该行审阅层
			没有记录时不放假卡片，只显示「还没有教案。先去备课台写一个课题。」和按钮「去备课台」
		首页卡片上不放删除，避免误触

	备课台
		左上标题：备课台
		说明：先写清学情再生成。正文供教师审定，实验课要核对安全等级、对照和材料处理
		右上按钮：去教案册
		左侧手账表单，三组，组标题用汉字序号
			一、课题定位
				课题，单行，必填
				学段，分段选择，只有「初中」「高中」，必填，不要默认替教师选中
				年级，单行，必填，占位「如七年级 / 高一」
				教材版本，单行，必填，占位「如人教版」
			二、课堂条件
				班额，数字，必填，小于 1 不能提交
				课时分钟数，数字，必填，小于 1 不能提交
				班额大于 60，或课时分钟数不在 35 到 50 时，不拦截，只在字段下提示「与常见课堂不同，将按你写的数字安排」
			三、学情
				学情与薄弱点，多行，必填，占位「如：容易把呼吸作用写成光合作用的逆反应」
				分层情况，多行，必填，占位「如：约三分之一学生需要支架，少数学生可做拓展解释」
			只含空白的字段视为未填
		表单标题:生物教案,表:生物教案,字段:[{字段名:课题,类型:文本},{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:年级,类型:文本},{字段名:教材版本,类型:文本},{字段名:班额,类型:数值},{字段名:课时分钟数,类型:数值},{字段名:学情与薄弱点,类型:文本},{字段名:分层情况,类型:文本}]
			教案内容不在此表单中
			没有要隐藏的编号或日期
		按钮都要实现
			生成教案
				校验通过才可提交
				若当前行>=1，先确认：「将新生成一份，出现在第 1 行，不会覆盖你正在看的这一份。」
				当前行是 0 时确认可省略
				callAppBridge({type:"SubmitRecord", data:"生物教案", payload:JSON文本})
				JSON 形状：{"课题":"","学段":"初中","年级":"","教材版本":"","班额":40,"课时分钟数":40,"学情与薄弱点":"","分层情况":""}
				班额、课时分钟数传数字
				提交后当前行设为 1
				轮询标题:生物教案,表:生物教案,字段:教案内容,输出到:教案预览,等待消息:叶片展开中，正在按课时编排观察、实验安全、分层任务和提问链
				轮询调用 callAppBridge({type:"GetCellValue", data:"生物教案/默认表格", payload:"教案内容/1"})
				每 2 秒一次。空值、null，或文本只是「生成中」「处理中」，都视为未完成
				读到非空正文后，再隔 2 秒复读，两次一致才结束，并用 Markdown 渲染到教案预览
				超过 90 秒仍未完成就停止，提示「生成较慢，可稍后在教案册打开第 1 行」，当前行仍为 1
				轮询时生成按钮不可点，禁止重复提交
			保存修改
				仅当前行>=1 可点；否则禁用，并说明「先生成或载入一份，才能保存修改」
				依次 SetCellValue 写回课题、学段、年级、教材版本、班额、课时分钟数、学情与薄弱点、分层情况
				不调用 SubmitRecord，不轮询，不改教案内容
				成功后提示「基本信息已保存。正文不会自动重写；要新正文请再点生成教案」
			删除这份
				仅当前行>=1 可点
				确认文案要带课题名，说明不可恢复
				callAppBridge({type:"DeleteRecord", data:"生物教案/默认表格", payload:当前行.toString()})
				成功后当前行设为 0，清空表单和预览
			清空
				有未保存改动时先确认
				清空 8 个字段，当前行设为 0，预览回到空态，不删除库中记录
		右侧教案预览
			标题：待审定正文
			右上角按钮 < 和 >
				API名称:GetRecordCount,数据源:生物教案/默认表格
				当前行初始是 0
				当前行<=1 时，< 不可操作
				当前行>=记录数时，> 不可操作
				记录数是 0 时，> 也不可操作
				切换前若表单有未保存改动，先确认
				< 使当前行减 1，> 使当前行加 1
				换行后，8 个手填字段分别 GetCellValue 填入表单，再取教案内容
				API名称:GetCellValue,数据源:生物教案/默认表格,字段名:课题,行号:当前行
				年级、教材版本、班额、课时分钟数、学情与薄弱点、分层情况、学段同样取，字段名用表内原名
				API名称:GetCellValue,数据源:生物教案/默认表格,字段名:教案内容,行号:当前行
			预览上方固定审定条，不是数据库字段：「请教师审定后再用。实验安排请核对安全等级、对照设计和材料处理。」
			正文用 Markdown 主题显示标题、列表、表格和引用，区域可滚动
			若正文里有 Markdown 标题，在预览侧生成锚点，点击滚到对应标题；没有标题就不显示空目录
			复制正文：复制当前教案内容原文，成功提示「已复制，可粘贴到备课本」
			打印审阅稿：只打印预览区，不打印导航和表单
			当前行是 0 或正文为空时，只显示「生成完成后，这里会展开一整份教案。」不要放示例课文
		从教案册点编辑进入时：当前行等于该行号，用 GetCellValue 填满表单并载入教案内容

	教案册
		左上标题：教案册
		说明：按课题回看。点卡片即看详情，不要为这张可编辑的表再做单独只读页
		右上按钮：+ 新的教案，进入备课台并执行清空
		搜索框按课题、年级、教材版本做包含匹配，不区分大小写，只过滤已取回的数据
		学段筛选：全部、初中、高中
		排序两个按钮都要实现，且不改变删除所用的原始行号
			最新在前：按原始行号从小到大，默认使用这个
			课题顺序：按课题做中文本地化升序
		主体是卡片列表
			API名称:GetTableCSV,数据源:生物教案/默认表格,字段:[课题,学段,年级,教材版本,班额,课时分钟数,学情与薄弱点,分层情况]
			卡片字段与备课台表单字段一致，以便点入后编辑
			学情与薄弱点、分层情况各截取前 40 字；审阅层里显示全文
			筛选和排序只改变可见顺序，行号始终是未筛选 CSV 的原始序号
			点击卡片主体打开审阅层
			每张卡片的按钮都要实现
				审阅：打开审阅层
				编辑：进入备课台并载入该行
				删除：确认后 callAppBridge({type:"DeleteRecord", data:"生物教案/默认表格", payload:该行号.toString()})，再重新 GetTableCSV
		没有匹配时显示「没有符合的教案」，不要改成假数据
		删除后若被删行号小于备课台记住的当前行，把该当前行减 1；若相等，把备课台当前行置 0 并清空其预览

	审阅层
		首页最近卡片、教案册卡片、审阅按钮都打开这一层
		宽纸色面板。点击遮罩或「关闭」只关闭面板，不删数据
		先列出 8 个字段的完整值，标签用字段原名
			每个字段都 callAppBridge({type:"GetCellValue", data:"生物教案/默认表格", payload:"字段名/该行号"})
		再显示教案正文
			API名称:GetCellValue,数据源:生物教案/默认表格,字段名:教案内容,行号:该行
			用 Markdown 主题显示
			若为空，显示「正文还在生成或尚未生成」，按钮「再读一次」重新 GetCellValue
		底部按钮都要实现
			在备课台修改：进入备课台并载入该行
			复制正文
			删除：与教案册删除相同，成功后关闭审阅层，并刷新首页统计、最近卡片和教案册
		首页点击最近列表项必须打开这份详情，不能只做高亮

	刷新
		进入首页时刷新记录数、两项学段统计、平均班额和最近 4 条
		进入教案册时重新 GetTableCSV
		SubmitRecord、全部 SetCellValue、DeleteRecord 成功后，刷新当前可见数据
		SetCellValue 成功不改变当前行

	实现约束
		做成一个单页应用：首页、备课台、教案册，加一个审阅层
		上面每一个按钮的功能都要实现，不能只画出来
		列表字段与表单字段一致
		指令流只在 SubmitRecord 之后异步出现；保存修改不会重写正文
		窄屏时标签可换行，表单在上，预览在下
		不要用户登录页，不要伪造记录
