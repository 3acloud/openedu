# 数学解题教练

这是一个面向初中和高一的数学单题辅导网页应用，包含首页、解题台、辅导册三个页面。不要用户登录页。不要在前端另接模型解题，辅导正文只来自表「解题」的指令流字段「解题辅导」。不要编造表里没有的字段，不要添加编号、日期、状态等额外字段。

页面统一主题为「稿纸与黑板」：页面背景是暖米色稿纸 `#F3EDE2`，带很浅的方格；顶部导航是深夜黑板色 `#1E2746`；强调色是粉笔黄 `#E4B15A`；正文深墨色 `#243044`；卡片白底、左侧一条粉笔黄色标，悬停时轻微上浮并加深阴影。标题用衬线字体（优先 `"Source Han Serif SC","Songti SC",serif`），正文用无衬线（优先 `"PingFang SC","Noto Sans SC",sans-serif`）。按钮、卡片、求助色标都有悬停反馈。窄屏时左右栏改为上下堆叠。

页面顶部导航栏，黑板色背景，底部一条细粉笔黄线
	左侧显示白色圆形里的 Σ 标志和「数学解题教练」
	右侧标签：首页、解题台、辅导册；当前页标签用粉笔黄字和黄色下划线
	点击标签切换页面，不整页刷新丢失已加载的详情状态；从首页点进某条记录时，切到辅导册并打开该行详情

数据源一律写「解题/默认表格」，表名一律写「解题」。字段只允许：题目、题目图片、学段、求助、已有思路、解题辅导。
	学段可选项只有：初中、高中
	求助可选项只有：卡住了、做错了、不知道怎么列式、出同类题、考前梳理
	解题辅导是指令流，不是输入框，禁止手填，禁止用 SetCellValue 改写
	布尔值本应用用不到；若出现布尔字段，只用「是」或「否」
	图片字段存全局文件名。展示图片用 `https://www.ithinkair.com:3031/download/全局文件名`
	操作表必须用下面的调用，不要自造接口：
		callAppBridge({type:"GetTableCSV", data:"解题/默认表格", payload:"题目,题目图片,学段,求助,已有思路,解题辅导"})，返回不含标题行的 csv
		callAppBridge({type:"GetRecordCount", data:"解题/默认表格"})
		callAppBridge({type:"GetRecordRow", data:"解题/默认表格", payload:"字段名/值"})，行号从 1 开始
		callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"字段名/行"})
		callAppBridge({type:"SetCellValue", data:"解题/默认表格", payload:"字段名/行/值"})
		callAppBridge({type:"SubmitRecord", data:"解题", payload:"表单JSON文本"})
		callAppBridge({type:"DeleteRecord", data:"解题/默认表格", payload:"行号字符串"})，行号必须先 toString()
		callAppBridge({type:"SelectImage"}) 返回图片全局文件名
		callAppBridge({type:"CapturePhoto"}) 返回图片全局文件名
	接口失败时只显示一句「暂时没取到辅导册，请再试一次」，不要伪造记录。

首页
	主标题：数学解题教练
	说明：把卡住的那一步交给教练。先写出你的尝试，教练只推一把，不先甩答案。
	一行小字：高中只陪伴高一预备知识与函数；正在考试或测验时，不要提交这道题。
	主按钮：开始这道题，跳转到解题台，不预选求助
	其下是五个求助入口卡片，点击跳转到解题台并预选对应求助，同时换好输入提示：
		卡住了：你试到哪一步了？
		做错了：把步骤写出来，圈出最可疑的一步
		不知道怎么列式：先写已知和要求
		出同类题：写出原题，或只写考查点
		考前梳理：写要梳理的章节，和最没底的内容
	五张入口卡片颜色不同：卡住了用粉笔黄，做错了用赭红，不知道怎么列式用青灰，出同类题用靛蓝，考前梳理用橄榄绿
	接下来并列三张统计卡，数字来自真实记录，禁止写死
		辅导次数
			callAppBridge({type:"GetRecordCount", data:"解题/默认表格"})
		初中题数、高中题数
			callAppBridge({type:"GetTableCSV", data:"解题/默认表格", payload:"学段"})
			按「初中」「高中」分别计数
	接下来是求助分布：五个小胶囊，显示每种求助的条数
		callAppBridge({type:"GetTableCSV", data:"解题/默认表格", payload:"求助"})
		按五个可选项分组计数，没有的显示 0
	接下来是最近辅导，标题「最近看过的题」，卡片形式，最多 5 张
		callAppBridge({type:"GetTableCSV", data:"解题/默认表格", payload:"题目,题目图片,学段,求助,已有思路,解题辅导"})
		csv 第 1 行是最新提交，取前 5 行；行号就是 csv 序号（从 1 开始）
		每张卡片显示：题目图片缩略（无图则显示方格纸占位）、题目（空则写「图片题」）、学段色标、求助色标、已有思路前 36 字
		点击卡片：进入辅导册，当前行设为该行号，打开详情
		没有记录时不显示空表格，显示一句「辅导册还是空白的」和按钮「去做第一题」

解题台
	左栏是稿纸，右栏是黑板。
	稿纸左上标题：解题台
	说明：一次只交一道题。题目文字和题目图片至少要有一个。
	右上按钮：清空稿纸。点击后清空题目、题目图片、已有思路和黑板，学段保持、求助保持，当前行设为 0，不删除记录。
	若从首页求助入口进入，预选该求助，并使用对应占位提示。
	表单标题:解题,表:解题,字段:[{字段名:题目,类型:文本},{字段名:题目图片,类型:图片},{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:求助,类型:单选项,可选项:卡住了,做错了,不知道怎么列式,出同类题,考前梳理},{字段名:已有思路,类型:文本},{字段名:解题辅导,类型:指令流}]
		题目：多行文本
		题目图片：预览区。按钮「拍题目」调用 CapturePhoto；按钮「从相册选」调用 SelectImage；按钮「去掉图片」清空全局文件名和预览。三个按钮都要实现。预览地址是 `https://www.ithinkair.com:3031/download/全局文件名`
		学段：两个大选项，初中、高中，必选，默认初中。选中高中时，稿纸下缘显示：「高中只覆盖高一预备知识与函数。几何与代数、概率与统计、选择性必修，教练只会帮你整理已知、所求和卡点。」
		求助：五个色标单选，必选，默认卡住了。切换时只改已有思路的占位提示，不改已写内容
		已有思路：多行文本。占位随求助变化
		解题辅导：不出现在稿纸输入区
	按钮：请教练看看
		题目和题目图片都空时禁用
		点击后用 SubmitRecord 提交，payload 是 JSON 文本，只含题目、题目图片、学段、求助、已有思路；题目图片传全局文件名，没有则传空字符串；不要提交解题辅导
		提交后当前行固定为 1
		然后轮询解题辅导，因为指令描述没有指定「以JSON格式输出」
			每隔 2 秒调用 callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"解题辅导/1"})
			黑板先显示「教练在黑板另一侧看你的稿纸…」
			得到非空文本后停止轮询，用 Markdown 主题渲染到黑板
			最多轮询 40 次，超时则写「这题还在批，可稍后到辅导册打开最新一条」，并刷新辅导册数据
	右栏黑板
		标题：教练黑板
		正文区用 Markdown 渲染解题辅导，保留标题、列表、公式段落的层次；背景是 `#1E2746`，文字是 `#F7F1E3`
		当前行是 0 且尚未提交时，黑板只显示：「先写下你的尝试。教练不会在你开口前给出原题答案。」
		黑板底部按钮：到辅导册看这一题。仅当前行大于 0 时可点，点击后打开辅导册该行详情

辅导册
	左上标题：辅导册
	说明：每张卡片是一次提问。点卡片看教练怎么说，编辑只改题目信息，不会重写黑板。
	右上按钮：+ 再问一题，跳转解题台并执行清空稿纸
	搜索框：按题目或已有思路包含文字筛选，输入即筛，不另设无功能按钮
	筛选芯片：全部、初中、高中，以及五个求助；可同时选一个学段和一个求助；芯片点击立即生效
	列表用卡片，不用单独的只读详情页
		数据：callAppBridge({type:"GetTableCSV", data:"解题/默认表格", payload:"题目,题目图片,学段,求助,已有思路,解题辅导"})
		卡片顺序与 csv 行序一致，第 i 张对应行号 i，筛选只是隐藏卡片，不改变行号
		卡片显示题目、学段、求助、已有思路前 48 字、图片缩略；解题辅导不在卡片上展开
		点击卡片就是查看详情
		每张卡片右侧两个图标按钮：编辑、删除。都要实现
	详情面板，从右侧滑出，不新开页面
		打开时当前行设为该行号
		逐字段取详情，不要只用 csv 里的解题辅导：
			callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"题目/当前行"})
			callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"题目图片/当前行"})
			callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"学段/当前行"})
			callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"求助/当前行"})
			callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"已有思路/当前行"})
			callAppBridge({type:"GetCellValue", data:"解题/默认表格", payload:"解题辅导/当前行"})
		上半部显示原图（有全局文件名才显示）、题目、学段、求助、已有思路
		下半部标题「解题辅导」，GetCellValue 得到的文本用 Markdown 主题显示；为空则显示「教练还没写完」
		按钮：改一改再问。把这五行复制到解题台稿纸，当前行设为 0，不提交、不删除原记录
		按钮：编辑这条
		按钮：删除这条
		按钮：关闭
	编辑
		在同一页打开稿纸式表单，不要跳到新的只读页
		当前行等于被点的行号
		用上面六个 GetCellValue 填充。题目图片显示现图，允许「拍题目」「从相册选」「去掉图片」
		解题辅导只读展示一小段提示「编辑不会重写教练黑板」，不提供输入框
		按钮：保存修改。依次 SetCellValue，只写这五个字段，值里的斜杠要原样传入，调用形式为 callAppBridge({type:"SetCellValue", data:"解题/默认表格", payload:"字段名/当前行/值"})：题目、题目图片、学段、求助、已有思路。禁止 SetCellValue 解题辅导，禁止用 SubmitRecord 保存修改
		保存成功后关闭表单，按当前行重新 GetCellValue 刷新详情和卡片
		按钮：取消修改。丢弃未保存内容，不调用接口
	删除
		先弹出确认「从辅导册抽走这张卡片？」
		确认后 callAppBridge({type:"DeleteRecord", data:"解题/默认表格", payload:行号.toString()})
		删除后当前行设为 0，关闭详情，重新 GetTableCSV 和首页统计
		取消则什么都不做
	没有匹配记录时，显示「这叠卡片里没有这样的题」，按钮「清空筛选」要能恢复全部芯片

当前行初始为 0。提交成功后当前行是 1。点卡片、点首页最近卡片、点编辑，都把当前行设成该 csv 行号。所有出现的按钮都必须真正完成上述动作，不能只有样式。
