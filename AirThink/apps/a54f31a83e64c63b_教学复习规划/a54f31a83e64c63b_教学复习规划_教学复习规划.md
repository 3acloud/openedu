# 教学复习规划
	这是一个面向教师的教学复习规划网页应用，用来结合课程标准、章节关系与班级共性学情，识别复习重难点，安排分阶段课时和主动回忆、错题重做等活动。不包含用户登录页面。本应用只有一张表「复习规划」，禁止自行编造计划编号、记录ID、创建日期或其他表定义中不存在的字段。
	页面统一采用「墨蓝书案」主题：页面背景为暖米纸色 #F6F1E7，叠一层很淡的方格纸纹理；主色墨蓝 #1B3A4B，强调色琥珀金 #C4A35A，冲刺提示色朱砂 #B85042，卡片为白米色、大圆角、轻阴影。标题用衬线字体，正文用柔和无衬线。卡片和按钮悬停时微微上浮，左侧出现琥珀书签色条。复习类型用固定色签：单元复习青绿、期中复习琥珀、期末复习墨蓝、考前冲刺朱砂。
	页面顶部固定导航栏，墨蓝背景
		左侧显示打开的书本图标和「教学复习规划」
		右侧标签：首页、编排计划、计划册、考前看板
		当前标签用琥珀金下划线标出，点击切换页面，不刷新丢失已打开的详情抽屉状态以外的必要数据；切换后重新读取对应数据
	全局数据约定
		数据源一律写作：复习规划/默认表格
		表名一律写作：复习规划
		可编辑字段只有：学科、复习类型、复习范围、课标与章节关系、班级学情、考试日期、可用课时
		复习计划是指令流，不是用户手工填写的，禁止放进输入框，禁止用 SetCellValue 改写
		获取列表：callAppBridge({type:"GetTableCSV", data:"复习规划/默认表格", payload:"学科,复习类型,复习范围,课标与章节关系,班级学情,考试日期,可用课时"})
		返回的 csv 不包含标题行，列顺序与 payload 一致。单元格可能含逗号、引号或换行，必须按标准 CSV 规则解析，禁止按逗号简单拆分
		行号从 1 开始，等于该记录在这份完整 csv 中的顺序号。搜索和筛选只改变展示，不改变原始行号。删除、读取、修改都使用原始行号
		记录数：callAppBridge({type:"GetRecordCount", data:"复习规划/默认表格"})
		读取单元格：callAppBridge({type:"GetCellValue", data:"复习规划/默认表格", payload:"字段名/行号"})
		修改已有记录：对当前行依次 callAppBridge({type:"SetCellValue", data:"复习规划/默认表格", payload:"字段名/行号/值"})，禁止用 SubmitRecord 修改
		删除：callAppBridge({type:"DeleteRecord", data:"复习规划/默认表格", payload:行号.toString()})
		新建才使用 callAppBridge({type:"SubmitRecord", data:"复习规划", payload:表单JSON文本})。提交后当前行是 1
		布尔值本表不使用。日期用 YYYY-MM-DD。复习类型只能是：单元复习、期中复习、期末复习、考前冲刺
		前端不得虚构得分率、错题率、提分幅度或未填写的学情。空着的课标、学情、考试日期原样提交，留给后台标明待补充
	首页
		主标题：教学复习规划
		说明：把课标关系、章节脉络和班级共性弱项，收成一份可上课使用的复习手帐
		主按钮：+ 编排复习计划，点击进入「编排计划」页面
		其下四张并列统计卡片，数字来自实时接口，禁止写死
			计划总数
				API名称:GetRecordCount,数据源:复习规划/默认表格
			近30天考试
				API名称:GetTableCSV,数据源:复习规划/默认表格,字段:[考试日期]
				统计考试日期落在今天至其后30天内的记录数；空日期不计入
			课时合计
				API名称:GetTableCSV,数据源:复习规划/默认表格,字段:[可用课时]
				把可用课时相加，空值按 0，不显示小数尾巴
			冲刺计划
				API名称:GetTableCSV,数据源:复习规划/默认表格,字段:[复习类型]
				统计复习类型为「考前冲刺」的记录数
		接下来是「最近编排」卡片列表，取完整表格前 5 行（新建提交后位于第 1 行）。没有记录时显示空纸页文案：还没有复习计划，从编排计划开始
			API名称:GetTableCSV,数据源:复习规划/默认表格,字段:[学科,复习类型,复习范围,课标与章节关系,班级学情,考试日期,可用课时]
			每张卡片显示：学科、复习类型色签、复习范围、考试日期、可用课时、班级学情前 36 字
			考试日期若晚于今天，右上角显示「还有N天」；若是今天显示「今天考试」；若已过显示「已过考期」；空日期显示「日期待补充」
			点击卡片打开复习计划详情抽屉，不是跳到只读独立页
	「编排计划」页面
		左侧为学情底稿，右侧为计划成稿，宽屏并列，窄屏上下排列
		左上标题：编排计划
		说明：写清范围、课标关系和班级共性弱项。生成结果只依据已填内容，缺项会标明待补充
		右上按钮：查看计划册，跳转到「计划册」
		表单标题:复习规划,表:复习规划,字段:[{字段名:学科,类型:文本},{字段名:复习类型,类型:单选项,可选项:单元复习,期中复习,期末复习,考前冲刺},{字段名:复习范围,类型:文本},{字段名:课标与章节关系,类型:文本,多行},{字段名:班级学情,类型:文本,多行},{字段名:考试日期,类型:日期},{字段名:可用课时,类型:数值},{字段名:复习计划,类型:指令流,指令类型:任务智能体,指令描述:使用技能 ea0b2214d89b6eec_xiaozhi-teach-review-planner，为{{学科}}制定{{复习类型}}计划。复习范围：{{复习范围}}；课程标准与章节关系：{{课标与章节关系}}；班级共性弱项、历史得分率及错题情况：{{班级学情}}；考试日期：{{考试日期}}；可用课时：{{可用课时}}。根据已提供的信息梳理四层知识图谱，识别重难点，安排分阶段课时与主动回忆、错题重做等活动，并给出学习策略层面的考前建议。缺失的数据请标明待补充，不要虚构得分率或承诺提分。以 Markdown 文本输出。,输出类型:文本}]
		表单只显示并允许填写：学科、复习类型、复习范围、课标与章节关系、班级学情、考试日期、可用课时
		课标与章节关系、班级学情用多行文本。班级学情占位提示：可写共性弱项、历史得分率和典型错题；没有的数据留空，不要估计
		学科、复习类型、复习范围、可用课时为必填。可用课时必须是大于 0 的数字。未通过校验时不提交
		底部按钮：清空底稿、生成复习计划
			清空底稿：清空输入和右侧成稿，当前行设为 0，不删除已有记录
			生成复习计划：仅新建时可用。把已填字段组成 JSON 文本提交，JSON 不包含复习计划
				callAppBridge({type:"SubmitRecord", data:"复习规划", payload:"表单JSON文本"})
				提交后当前行是 1
		右侧计划成稿初始显示一张空白稿纸：提交后，复习计划会以 Markdown 出现在这里
		提交后轮询指令流字段。指令描述要求以 Markdown 文本输出，不是 JSON，因此轮询「复习计划」，不要另找 JSON 字段
			轮询标题:复习规划,表:复习规划,字段:复习计划,输出到:计划成稿,等待消息:正在梳理四层知识图谱，识别重难点并编排分阶段课时…
			每 2 秒调用一次 callAppBridge({type:"GetCellValue", data:"复习规划/默认表格", payload:"复习计划/1"})
			得到非空文本后停止轮询，用 Markdown 主题渲染到计划成稿，保留标题、列表和表格
			等待超过 90 秒仍为空时，提示可稍后到计划册查看，并允许继续等待，前端不得编造计划正文
	「计划册」页面
		左上标题：计划册
		说明：按学科和复习类型翻看已生成的复习手帐
		右上按钮：+ 编排复习计划，跳转到「编排计划」
		搜索框：按学科或复习范围包含匹配，输入即筛选
		筛选色签：全部、单元复习、期中复习、期末复习、考前冲刺，可再按考试日期升序或保持表格原序
		主体用卡片，不用独立只读页。卡片展示字段与表单可编辑字段一致，便于点卡片编辑
			API名称:GetTableCSV,数据源:复习规划/默认表格,字段:[学科,复习类型,复习范围,课标与章节关系,班级学情,考试日期,可用课时]
			每张卡片显示学科、复习类型色签、复习范围、考试日期与倒计时、可用课时、课标与章节关系前 42 字、班级学情前 42 字
			每张卡片操作必须全部实现：查看计划、编辑、删除
			无匹配时显示：没有符合条件的计划
		查看计划：打开右侧详情抽屉
			依次 GetCellValue 读取学科、复习类型、复习范围、课标与章节关系、班级学情、考试日期、可用课时、复习计划
			API名称:GetCellValue,数据源:复习规划/默认表格,字段名:复习计划,行号:该卡片原始行号
			左侧显示学情摘要和倒计时，右侧用 Markdown 主题显示复习计划。内容为空时显示：计划仍在生成或尚未生成，不补写正文
		编辑：不新开页面。打开与编排计划相同的底稿表单，当前行设为该卡片原始行号
			用 GetCellValue 逐字段回填七个可编辑字段，不以可能失真的 csv 长文本为准
			复习计划仍只在抽屉里只读展示，表单不提供复习计划输入框
			按钮：取消、保存修改
			保存修改时依次 SetCellValue 更新当前行的学科、复习类型、复习范围、课标与章节关系、班级学情、考试日期、可用课时
			保存后提示：源信息已更新。已生成的复习计划不会因此重写；若要新计划，请新建一条
			禁止对编辑调用 SubmitRecord
		删除：先弹出确认「删除这条约复习计划？删除后不能恢复」。确认后 DeleteRecord，payload 为原始行号.toString()，成功后关闭抽屉并刷新列表与首页统计
		点击卡片空白处等同于查看计划
	「考前看板」页面
		左上标题：考前看板
		说明：从已有计划里看考试远近和课时分布，不新增记录
		上方三张摘要卡
			未过考期的计划数、已过考期的计划数、未填考试日期的计划数
			数据来自 GetTableCSV 的考试日期，与本地今天比较
		复习类型分布
			API名称:GetTableCSV,数据源:复习规划/默认表格,字段:[复习类型]
			四种类型各一块色签卡，显示数量和占比；总数为 0 时占比显示 0
		课时投入
			API名称:GetTableCSV,数据源:复习规划/默认表格,字段:[学科,复习类型,可用课时,考试日期]
			按学科汇总可用课时，用横向条形对比；同一学科多条计划要相加
		考试时间轴
			同一接口数据，只列出填写了考试日期的计划，按考试日期升序排成时间轴卡片
			每张卡显示考试日期、倒计时、学科、复习类型、复习范围、可用课时
			点击时间轴卡片打开与计划册相同的详情抽屉，并 GetCellValue 渲染该行复习计划
		没有考试日期时，时间轴显示：已有计划都还没写考试日期
	详情抽屉为各页共用
		标题为「学科 · 复习类型」
		关闭按钮、编辑按钮、删除按钮都要实现，行为与计划册一致
		首页最近卡片点进来也可以编辑和删除
		Markdown 区域可滚动，链接可点，不把 Markdown 当纯文本预格式化整段塞进代码框
	操作按钮对应的功能必须全部实现。所有列表在新建、保存、删除后立即重新 GetTableCSV 或 GetRecordCount。当前行初始为 0；只有 SubmitRecord 成功后才把当前行设为 1 并开始轮询。
