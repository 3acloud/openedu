# 独立教师工作台

这是一个独立教师工作台网页应用，只使用表“教学工作台”，不要新建其他表，不要编造字段。本表没有自动编号 ID，也没有创建日期，禁止自行添加 ID、创建日期、学员真名、发送状态等字段。应用按指定日期，只读汇总课表、课前准备、课后反馈、作业、家长沟通与课时包，依据记录识别需关注的学员，并展示有据可查的三项优先事项。页面不得提供修改教学空间记录、改作业、改课时或发送消息的功能；写操作只允许发生在“教学工作台”本表。

统一主题名“暖灯书案”：米纸背景 #F6F1E8，顶部导航墨蓝 #243056，主按钮与重点琥珀 #C9842A，卡片 #FFFCF7，安静辅助青灰 #5E7A72，优先事项视觉强调朱砂 #8C3A2F。标题用衬线字体，正文用无衬线字体。卡片圆角、浅阴影，悬停时轻微上浮；按钮有按下态。不需要登录页。所有出现的操作按钮都必须实现，不能只做外观。

页面顶部导航栏，墨蓝背景，底部一条细琥珀线。
	左侧显示台灯图标和“独立教师工作台”。
	右侧显示今天的日期，例如“2025年7月7日星期一”，以及标签：晨间概览、生成日工作台、工作台存档。当前标签用琥珀下划线。

表操作一律用对应桥接，数据源固定为“教学工作台/默认表格”，表名固定为“教学工作台”。字段名只能是：查看日期、工作空间文件、日工作台。
	GetTableCSV：callAppBridge({type:"GetTableCSV", data:"教学工作台/默认表格", payload:"查看日期,工作空间文件,日工作台"})，返回不含标题行的 csv。行序与表行一致，第 1 行文本对应行号 1。列表排序或筛选时必须保留原始行号，不能把显示序号当成行号。
	提交新建：callAppBridge({type:"SubmitRecord", data:"教学工作台", payload:"表单JSON文本"})。提交后当前行是 1。
	记录数：callAppBridge({type:"GetRecordCount", data:"教学工作台/默认表格"})。
	按值找行：callAppBridge({type:"GetRecordRow", data:"教学工作台/默认表格", payload:"字段名/值"})，行号从 1 开始。
	删除：callAppBridge({type:"DeleteRecord", data:"教学工作台/默认表格", payload:行号.toString()})。
	读单元格：callAppBridge({type:"GetCellValue", data:"教学工作台/默认表格", payload:"字段名/行"})。
	改单元格：callAppBridge({type:"SetCellValue", data:"教学工作台/默认表格", payload:"字段名/行/值"})。校正已有记录时依次 SetCellValue，禁止用 SubmitRecord 冒充修改。
	选择工作空间文件：callAppBridge({type:"SelectFile"})，返回全局文件名，写入“工作空间文件”。
	在浏览器打开文件：https://www.ithinkair.com:3031/private/全局文件名 。若文件名以 .html 或 .htm 结尾，用 iframe 打开该链接。
	下载文件：https://www.ithinkair.com:3031/download/全局文件名 。
	日工作台是指令流，不是手工输入。指令描述没有“以JSON格式输出”，因此提交后轮询“日工作台”本身，不要解析 JSON，不要另造输出字段。详情用 Markdown 主题渲染。

当前行初始是 0。当前行小于等于 1 时，“上一份”不可操作；当前行大于等于记录数或记录数为 0 时，“下一份”不可操作。

晨间概览
	主标题：独立教师工作台。说明：按指定日期汇总课表、课前准备、课后反馈、作业、家长沟通与课时包，标出有记录依据的优先事项。
	主按钮：生成今日工作台。点击进入“生成日工作台”，查看日期预填今天，清空文件与正文，当前行设为 0。
	并列三张统计卡，数字来自真实记录，没有记录显示 0。
		全部工作台
			API名称:GetRecordCount,数据源:教学工作台/默认表格
		本月已生成
			API名称:GetTableCSV,数据源:教学工作台/默认表格,字段:[查看日期,工作空间文件,日工作台]
			筛选查看日期属于当前月后计数
		今日汇总
			用同一份 csv 筛选查看日期等于今天
			有记录时显示份数，没有时显示“今日尚未生成”
	最近工作台：卡片列表，不是传统表格。按查看日期降序，取前 4 条；同一日期可有多条，都保留。每张卡片显示查看日期、工作空间文件名、日工作台开头约 80 字（去掉标题符号；为空则显示“暂无正文”）。
		API名称:GetTableCSV,数据源:教学工作台/默认表格,字段:[查看日期,工作空间文件,日工作台]
		点击卡片打开详情层，不是只跳转。详情用该卡片保存的原始行号调用 GetCellValue 读取查看日期、工作空间文件、日工作台。日工作台以 Markdown 显示。文件名提供“打开”和“下载”。详情层按钮：关闭、按此日期再次汇总、校正这条记录、删除。
	无记录时，最近区域显示“暂无记录”，并保留生成按钮。

生成日工作台
	左上标题：生成日工作台。说明：选定日期并附上工作空间文件，只读生成一份七区块日工作台。
	右上按钮：+ 新建一份。点击清空日期以外的选择、清空正文，查看日期回到今天，当前行设为 0。
	左侧“日期与文件夹”卡片
		查看日期：日期选择器，默认今天，可改任意日期。
		工作空间文件：按钮“选择工作空间文件”，调用 SelectFile。选中后显示全局文件名，并提供打开、下载、移除。未选择时显示“尚未选择文件”。
		若 GetRecordRow 能按“查看日期/所选日期”找到行，显示轻提示“该日期已有工作台”，按钮“查看已有”读取该行详情；不自动覆盖旧记录。
		按钮：汇总生成。查看日期或工作空间文件缺一则禁用。
	表单标题:教学工作台,表:教学工作台,字段:[{字段名:查看日期,类型:日期},{字段名:工作空间文件,类型:文本},{字段名:日工作台,类型:指令流,指令类型:任务智能体,文件字段:工作空间文件,输出类型:文本,指令描述:使用技能“0c04def7dcfd6ba3_xiaozhi-teach-solo-dashboard”，以{{查看日期}}为工作台日期，只读汇总教学工作空间记录，生成七区块日工作台：今日课表、课前准备、课后反馈、作业与复习跟进、家长沟通提醒、课时包与续课节点、今日最重要的三件事。风险标记须依据记录中的数值并写明依据；缺失记录须标明暂无记录；学员只使用化名；不得更改记录或发送消息。输出一份 Markdown 文本。}]
		日工作台不出现在填写区，禁止手工编辑，提交 JSON 不包含日工作台。
		SubmitRecord 的 payload 只含查看日期与工作空间文件，例如 {"查看日期":"2025-07-07","工作空间文件":"全局文件名"}。
		提交成功后当前行设为 1。
	轮询标题:教学工作台,表:教学工作台,字段:日工作台,输出到:日工作台正文,等待消息:正在按查看日期只读汇总课表、课前准备、课后反馈、作业、家长沟通与课时包，请稍候
		轮询 API名称:GetCellValue,数据源:教学工作台/默认表格,字段名:日工作台,行号:当前行
		约每 2 秒一次，直到返回非空文本。等待时显示等待消息，禁止把等待消息写进单元格。轮询期间禁用“汇总生成”。长时间仍为空时显示“仍在生成”，按钮“继续等待”恢复轮询，按钮“停止查看”只停止前端轮询，不伪造正文。
	右侧“今日七栏”结果区
		正文使用 Markdown 主题渲染，忠实呈现风险依据、暂无记录和学员化名，不补写学员、课次或优先级。
		正文上方有七个跳转签：今日课表、课前准备、课后待反馈、作业与复习跟进、家长沟通提醒、课时包与续课节点、今日最重要的三件事。正文含对应标题时点击滚动到该标题；不含则该签变淡并标“文中未出现”，不编造区块。
		结果区右上角按钮：上一份、下一份。用 GetRecordCount 控制可用性。点击后按相邻行号 GetCellValue 读取查看日期、工作空间文件、日工作台并刷新左右两侧；若日工作台为空，显示“暂无正文”并提供“继续轮询”。
		结果区底部一句说明：本页只展示汇总，不会更改教学记录，也不会发送消息。
		按钮：复制正文。把当前 Markdown 原文复制到剪贴板；没有正文时禁用。

工作台存档
	左上标题：工作台存档。说明：回看已生成的日工作台，可校正日期或文件，或另建一份新汇总。
	右上按钮：+ 生成新的一份，进入生成页并清空为今天、当前行 0。
	搜索框：按查看日期或工作空间文件名过滤。
	筛选：查看日期起止。清空筛选按钮要恢复完整列表。
	上方细条形图：近六个月生成份数。
		API名称:GetTableCSV,数据源:教学工作台/默认表格,字段:[查看日期,工作空间文件,日工作台]
		只按查看日期的年月计数，无数据的月份显示 0，不使用假数据。
	主体是卡片列表，字段与表单一致，以便点击后校正。
		API名称:GetTableCSV,数据源:教学工作台/默认表格,字段:[查看日期,工作空间文件,日工作台]
		默认按查看日期降序。每张卡片显示查看日期、文件名、正文摘要、原始行号不直接面对用户但必须内部保存。
		每张卡片的按钮：查看详情、校正、按此日期再次汇总、删除。点击卡片空白处等同查看详情。
	查看详情
		当前行设为该原始行号。
		API名称:GetCellValue,数据源:教学工作台/默认表格,字段名:查看日期,行号:当前行
		API名称:GetCellValue,数据源:教学工作台/默认表格,字段名:工作空间文件,行号:当前行
		API名称:GetCellValue,数据源:教学工作台/默认表格,字段名:日工作台,行号:当前行
		日工作台用 Markdown 主题显示。文件提供打开、下载；html 文件额外用 iframe 预览。
	校正这条记录
		只加载查看日期、工作空间文件到校正表单。日工作台在旁边只读展示，校正保存时禁止对日工作台调用 SetCellValue。
		更换文件必须重新 SelectFile。
		保存时依次：
			API名称:SetCellValue,数据源:教学工作台/默认表格,payload:查看日期/当前行/新日期
			API名称:SetCellValue,数据源:教学工作台/默认表格,payload:工作空间文件/当前行/新的全局文件名
		保存后重新 GetCellValue 刷新详情与列表。校正不会重新触发指令流；若要新汇总，使用“按此日期再次汇总”。
	按此日期再次汇总
		进入生成页，预填该条查看日期和已有全局文件名，当前行先保持 0。用户确认后点击“汇总生成”才 SubmitRecord，新建在第 1 行，不覆盖旧行。
	删除
		先确认。确认后 API名称:DeleteRecord,数据源:教学工作台/默认表格,payload:行号.toString()。成功后重新获取 csv 与记录数；若删的是当前行，当前行设为 0 并关闭详情。

各页面返回晨间概览时重新统计。空列表统一写“暂无记录”。加载中禁用会重复提交或重复删除的按钮。窄屏下导航可收起，生成页左右栏改为上下排列，七个跳转签可横向滑动。
