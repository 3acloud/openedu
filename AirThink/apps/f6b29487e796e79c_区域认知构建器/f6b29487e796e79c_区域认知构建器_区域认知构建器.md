# 区域认知构建器
	这是一个面向初高中地理学习的网页应用，帮助学生用同一套方法认识陌生区域：先定位，再归纳特征，需要时做区域比较或区域联系。应用包含首页、构建引导、认知档案三个页面，不包含登录页。
	统一主题为“现代地理图集”：深墨蓝导航、羊皮纸内容底、铜金点缀、海岸青绿主操作色。不要做成通用后台，也不要使用大面积纯绿色植物风。
		页面背景 #F4F0E6，叠极淡经纬网格，不干扰阅读
		导航与页脚细线 #16324F，强调金 #C4A46A，主按钮 #1F6F78，比较类标记 #C46B4A，正文 #1E2A32，卡片 #FFFCF7
		标题偏图集衬线气质，正文使用柔和无衬线；卡片、按钮、方法入口有悬停上浮与阴影，当前导航项用金色下划线
		窄屏时导航可折行，构建引导改为上表单、下引导，卡片改为单列
	本应用只有一张可写表，表名与数据源表名都是“区域认知”。字段必须严格使用表定义，禁止编造记录编号、创建日期、收藏、评分、笔记或其他字段。本表没有自动编号ID和创建日期，表单上不要添加隐藏ID。
		字段：区域（文本）、学段（单选项：初中、高中）、学习方式（单选项：完整认识、定位与特征、区域比较、区域联系）、另一区域（文本）、学习引导（指令流，任务智能体，后台异步生成，禁止用户手工填写）
		学习引导的指令已绑定技能 xiaozhi-geography-region-builder，前端只负责收集区域、学段、学习方式、另一区域并提交；不要在前端自行编写或替代学习引导正文
		指令描述要求输出中文 Markdown，且没有“以JSON格式输出”，因此提交后轮询字段就是“学习引导”，不要轮询其他字段
	数据接口约定（操作表必须使用这些调用，payload 形态不可改）
		获取不含标题行的 csv：callAppBridge({type:"GetTableCSV", data:"区域认知/默认表格", payload:"逗号分隔的字段名"})。字段名必须属于本表。返回按行号顺序，第1行是最新提交。解析时按请求字段顺序对应列，空列保留
		提交新建：callAppBridge({type:"SubmitRecord", data:"区域认知", payload:"表单JSON文本"})。只提交用户字段。提交成功后当前行设为1，然后轮询学习引导
		记录数：callAppBridge({type:"GetRecordCount", data:"区域认知/默认表格"})
		按值查行号（从1开始）：callAppBridge({type:"GetRecordRow", data:"区域认知/默认表格", payload:"字段名/值"})
		删除：callAppBridge({type:"DeleteRecord", data:"区域认知/默认表格", payload:行号.toString()})。payload 必须是文本
		单元格详情：callAppBridge({type:"GetCellValue", data:"区域认知/默认表格", payload:"字段名/行"})
		修改已有行：对当前行逐字段 callAppBridge({type:"SetCellValue", data:"区域认知/默认表格", payload:"字段名/行/值"})。修改禁止使用 SubmitRecord
		学习引导详情必须用 GetCellValue 获取，并用 Markdown 主题渲染，不要当纯文本倾倒
	页面顶部导航栏，深墨蓝背景，底部一条铜金细线
		左侧：指南针与经纬线组成的 Logo，旁注“区域认知构建器”
		右侧标签：首页、构建引导、认知档案。点击切换页面，当前页高亮
		不显示用户头像、登录、退出
	首页
		主标题：区域认知构建器
		说明：按定位、特征、比较、联系，带初高中学生认识一个陌生区域
		提示条常驻：涉及区域边界与疆域时以教材和标准地图为准；认识家乡只需到县（区）一级
		主按钮：开始认识一个区域。点击进入“构建引导”，清空表单，当前行设为0，学习方式不预选
		其下是四个方法入口卡片，横向排列，可点击。点击进入“构建引导”，当前行设为0，清空学习引导，并预选对应学习方式；区域与学段留空待填
			完整认识：走完定位、归纳特征、比较、联系
			定位与特征：先定位，再归纳区域特征
			区域比较：两个区域使用相同项目，并解释差异原因。卡片上标明需要另一区域
			区域联系：说明流动方向、内容及对双方的意义。卡片上标明需要另一区域
		接下来是三个统计卡片，数字来自实时接口，进入首页和从其他页返回时刷新
			认知记录：API名称:GetRecordCount,数据源:区域认知/默认表格
			初中记录：API名称:GetTableCSV,数据源:区域认知/默认表格,payload:"学段"。筛选值为“初中”后计数
			高中记录：API名称:GetTableCSV,数据源:区域认知/默认表格,payload:"学段"。筛选值为“高中”后计数
		方式分布：API名称:GetTableCSV,数据源:区域认知/默认表格,payload:"学习方式"。按完整认识、定位与特征、区域比较、区域联系分组计数，用四条比例条显示，无数据时比例为0并显示0
		最近认识：卡片列表，不是表格。API名称:GetTableCSV,数据源:区域认知/默认表格,payload:"区域,学段,学习方式,另一区域"。取前5条。每张卡片显示区域、学段徽章、学习方式徽章；另一区域有值时显示“对比/联系：另一区域”，为空显示“单一区域”
			点击最近卡片查看详情，打开详情层，不得只高亮不打开
			无记录时显示空状态文案和按钮“开始认识一个区域”
	构建引导页面
		采用左右分栏：左为认识任务单，右为学习引导阅读页。左上标题：构建引导。说明：填写区域与学段，选择认识方式，生成一份可跟随的中文学习引导
		右上文本按钮：认知档案，点击进入认知档案
		任务单字段与表单一致，单选项用分段按钮或下拉，不可自由输入选项外的值
			表单标题:区域认知,表:区域认知,字段:[{字段名:区域,类型:文本},{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:学习方式,类型:单选项,可选项:完整认识,定位与特征,区域比较,区域联系},{字段名:另一区域,类型:文本},{字段名:学习引导,类型:指令流}]
			区域必填，占位示例：长江三角洲、撒哈拉沙漠，或家乡所在县（区）
			学段必填，只能是初中或高中
			学习方式必填。选中后在字段下方展示该方法的引导步骤，只作为界面说明，不写入表，也不代替学习引导
				完整认识：1定位 2归纳特征 3用相同项目比较并解释差异原因 4说明联系的流向、内容与双方意义
				定位与特征：1定位 2归纳特征
				区域比较：1确定两个区域 2相同项目比较 3解释差异原因
				区域联系：1确定两个区域 2流动方向与内容 3对双方的意义
			另一区域：学习方式为区域比较或区域联系时显示且必填，占位示例：珠江三角洲；其他方式隐藏，提交空字符串
			学习引导不出现输入框，只在右栏展示
		任务单按钮
			生成学习引导：仅新建模式可用。区域、学段、学习方式未齐，或比较/联系缺少另一区域时禁用
				点击后 callAppBridge({type:"SubmitRecord", data:"区域认知", payload:JSON文本})
				JSON只含四个用户字段，例如 {"区域":"长江三角洲","学段":"高中","学习方式":"区域比较","另一区域":"珠江三角洲"}。不要提交学习引导
				提交后当前行=1。右栏进入等待态，等待消息：正在按定位、特征、比较与联系构建学习引导…
				轮询标题:区域认知,表:区域认知,字段:学习引导,输出到:右栏学习引导,等待消息:正在按定位、特征、比较与联系构建学习引导…
				轮询实现为反复 callAppBridge({type:"GetCellValue", data:"区域认知/默认表格", payload:"学习引导/1"})，直到内容非空，再用 Markdown 主题渲染。等待期间不清空左侧已填内容，不重复 SubmitRecord
			保存修改：仅编辑已有行时显示。依次 SetCellValue 当前行的区域、学段、学习方式、另一区域。比较或联系时另一区域必填，否则不允许保存。保存后用 GetCellValue 刷新左栏，不调用 SubmitRecord，不重新轮询，不改写学习引导。按钮旁注明：修改资料不会重新生成学习引导；需要新引导请新建
			新建一条：清空四个用户字段和右栏，当前行设为0，回到新建模式，按钮恢复为“生成学习引导”
		右栏学习引导
			顶栏显示当前区域、学段、学习方式；有另一区域时并列显示。无内容时显示所选方法的步骤说明和疆域提示，不要空白
			生成结果用 Markdown 主题呈现，支持标题、列表、表格、强调，保持图集阅读页宽度，不要套用聊天气泡
			右上角按钮 < 与 >
				API名称:GetRecordCount,数据源:区域认知/默认表格
				当前行初始为0。当前行<=1时 < 不可操作；当前行>=记录数或当前行为0时 > 不可操作
				点击 < 或 > 时，当前行加一或减一，再用 GetCellValue 按“字段名/当前行”读取区域、学段、学习方式、另一区域、学习引导并填充左右栏，进入查看已有记录状态
				等待轮询未结束时，< 与 > 不可操作
	认知档案页面
		左上标题：认知档案。说明：回顾已经生成的区域认识，按相同项目比较你学过的区域
		右上按钮：+ 新建认识。点击进入构建引导的新建模式，当前行=0并清空
		搜索框：按区域或另一区域包含匹配，输入即时筛选
		筛选器：学段（全部、初中、高中）、学习方式（全部、完整认识、定位与特征、区域比较、区域联系）。筛选与搜索同时生效，并提供“清除筛选”按钮，点击恢复全部
		主体用卡片列表展示，不用单独只读页。卡片字段与可编辑表单字段一致，以便点击后编辑
			API名称:GetTableCSV,数据源:区域认知/默认表格,payload:"区域,学段,学习方式,另一区域"
			行号=csv顺序索引+1。卡片显示区域、学段、学习方式、另一区域（空则显示“—”）
			不要在卡片中展开完整学习引导
			每张卡片的操作按钮都必须实现：查看引导、编辑、删除、以此区域再建
				查看引导：打开详情层
				编辑：进入构建引导编辑模式，当前行=该行号；逐字段 GetCellValue 填充区域、学段、学习方式、另一区域、学习引导；主按钮为“保存修改”
				删除：先确认，确认后 callAppBridge({type:"DeleteRecord", data:"区域认知/默认表格", payload:行号.toString()})，再重新 GetTableCSV 刷新。删除的是该行，不是固定删除第1行
				以此区域再建：进入构建引导新建模式，当前行=0，只预填该卡片的区域和学段，学习方式与另一区域留空，右栏清空，不自动提交
			点击卡片主体等同查看引导
		无匹配结果时显示空状态，并保留新建按钮
	详情层
		从首页最近卡片或档案“查看引导”打开，覆盖在当前页之上，不新增路由页面
		先确定行号，再 callAppBridge({type:"GetCellValue", data:"区域认知/默认表格", payload:"学习引导/行号"})，同时用 GetCellValue 读取区域、学段、学习方式、另一区域
		页眉展示这四个用户字段；正文用 Markdown 主题显示学习引导。内容为空时显示“学习引导尚未生成”，不要编造正文
		页脚小字：边界与疆域以教材和标准地图为准
		按钮：关闭、编辑。关闭只关层；编辑关闭层并按该行进入构建引导编辑模式。两个按钮都要实现
	全局约束
		所有出现的按钮、筛选、搜索、卡片点击、行切换都必须有对应实现，不能只做静态界面
		列表与最近记录都用卡片。统计、列表、详情在提交、保存、删除后立即刷新
		新建用 SubmitRecord，提交后当前行是1并轮询学习引导；修改只用 SetCellValue 逐字段写当前行
		GetTableCSV 的字段与任务单可编辑字段一致：区域,学段,学习方式,另一区域。学习引导一律 GetCellValue 后 Markdown 显示
		单选项只能提交“初中”“高中”和四种学习方式原文。比较、联系以外的方式，另一区域提交空字符串
		不要调用选择图片、录音、文件读写接口。不要出现登录、权限、支付或与区域认知无关的页面
