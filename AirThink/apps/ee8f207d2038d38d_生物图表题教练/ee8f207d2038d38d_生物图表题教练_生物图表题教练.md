# 生物图表题教练
	这是一个面向初高中生的生物图表题教练网页应用，单页切换三个视图：首页、开始辅导、辅导记录。不需要用户登录、注册或权限页面。不要新增表，不要编造表里没有的字段，不要做提醒、学习档案或其它未列出的页面。
	学生用它提交一道生物图表或材料题：写下题目、放上图表、留下自己的尝试，再阅读后台生成的中文 Markdown 指导。界面气质是“叶绿实验室笔记”，不是通用后台，也不是花草绿植风。
	页面统一主题
		背景是暖纸色 #F3F6F2，上面铺一层很淡的坐标格纹
		顶部导航是墨青绿 #0E4D4A，文字为米白
		强调色用荧光笔琥珀 #E39B3A，用于主按钮和证据引用边线
		卡片白底、圆角 16px，悬停时轻微上浮并加深阴影
		字体用 "PingFang SC","Noto Sans SC","Segoe UI",sans-serif，正文不小于 16px，行高舒适
		学段徽章：初中用鼠尾草绿，高中合格考用湖蓝，高中选考生物用靛青
		答题场景徽章：日常练习用青绿，考试或测验中用琥珀
		Logo 用纯 SVG：圆角方块里一条坐标曲线加一片小叶，旁边文字“生物图表题教练”
	顶部导航栏
		左侧：Logo 和“生物图表题教练”
		右侧标签：首页、开始辅导、辅导记录
		当前标签用琥珀下划线标出
		三个标签点击只切换视图，不丢失尚未提交的表单；已展示的教练指导在离开视图后仍保留，直到用户清空或提交新题
	数据只有一张表
		表名：题目辅导
		数据源固定写：题目辅导/默认表格
		字段只能是：学段、答题场景、题目文字、题目图片、我的尝试、教练指导
		学段是单选项，可选项只有：初中、高中合格考、高中选考生物
		答题场景是单选项，可选项只有：日常练习、考试或测验中
		题目文字、题目图片、我的尝试是文本。题目图片存图片全局文件名，不是可手打的说明
		教练指导是指令流，不是用户填写项。它在 SubmitRecord 之后由后台 AI 异步生成，前端禁止调用模型代写，禁止改写它的指令
		本表没有自动编号 ID，没有创建日期，没有布尔字段，没有关联表。不要隐藏一个自己编出来的编号，不要为了排序发明日期字段
		主体列表使用的 GetTableCSV 字段必须与表单字段一致，以便点中一条就能按行号载入编辑
	操作表必须使用这些调用，并等待返回
		callAppBridge({type:"GetTableCSV", data:"题目辅导/默认表格", payload:"学段,答题场景,题目文字,题目图片,我的尝试,教练指导"})
			返回不含标题行的 csv。列顺序与 payload 一致。用符合引号规则的 CSV 解析，题目文字、我的尝试、教练指导里可能有逗号、引号和换行
			图片字段文本是全局文件名。空字符串表示没有图片
			csv 第 1 行对应行号 1，依次类推。没有记录时返回空文本
		callAppBridge({type:"GetRecordCount", data:"题目辅导/默认表格"})
		callAppBridge({type:"SubmitRecord", data:"题目辅导", payload:表单JSON文本})
			只用于新建。payload 是 JSON 文本，包含学段、答题场景、题目文字、题目图片、我的尝试，不要手写教练指导
			提交成功后当前行一定是 1
		callAppBridge({type:"GetCellValue", data:"题目辅导/默认表格", payload:"字段名/行"})
			查看详情、载入编辑、轮询教练指导都用它。行号从 1 开始
		callAppBridge({type:"SetCellValue", data:"题目辅导/默认表格", payload:"字段名/行/值"})
			只用于修改已有记录，逐字段调用。不要用 SubmitRecord 修改
			可写字段只有学段、答题场景、题目文字、题目图片、我的尝试。不要覆盖教练指导
		callAppBridge({type:"DeleteRecord", data:"题目辅导/默认表格", payload:行号.toString()})
			删除前用对话框确认。payload 必须是文本
		callAppBridge({type:"SelectImage"}) 选择图片，返回全局文件名
		callAppBridge({type:"CapturePhoto"}) 拍摄图片，返回全局文件名
		图片显示地址是 "https://www.ithinkair.com:3031/download/全局文件名"
		在浏览器打开原图的地址是 "https://www.ithinkair.com:3031/private/全局文件名"
		不要使用本表不存在的关联表查询，不要调用未列出的写接口
	指令流轮询
		教练指导的指令描述没有要求“以JSON格式输出”，所以轮询字段就是教练指导，不要改去轮询别的字段
		SubmitRecord 成功后，当前行设为 1，每 2 秒调用一次 GetCellValue，payload 为 "教练指导/1"
		得到非空文本即结束轮询，用 Markdown 主题渲染，不要当纯文本甩出
		等待时指导区显示“正在读图找证据，请稍候…”，并禁用重复提交
		最多轮询 60 次。超时则说明“生成时间较长，请稍后在辅导记录里打开第 1 条查看”，并刷新列表
		打开历史详情时不再轮询，直接 GetCellValue 取已生成内容
	首页
		主标题：生物图表题教练
		说明：先读图表信息，再找题中证据，最后联系教材原理。教练按你的尝试逐级提示
		三枚步骤芯片：读信息、找证据、联原理。只是说明，不是按钮
		主按钮：开始一题，跳转到开始辅导，并清空未提交草稿、当前行设为 0
		三张并列统计卡片，数字来自实时接口，进入首页和每次提交、删除后刷新
			辅导总数
				callAppBridge({type:"GetRecordCount", data:"题目辅导/默认表格"})
			日常练习数
				callAppBridge({type:"GetTableCSV", data:"题目辅导/默认表格", payload:"答题场景"})
				统计值等于“日常练习”的行数
			考试待复盘数
				同一份答题场景 csv 中，统计值等于“考试或测验中”的行数
		学段分布条
			callAppBridge({type:"GetTableCSV", data:"题目辅导/默认表格", payload:"学段"})
			按初中、高中合格考、高中选考生物分组计数，用三条横向比例条显示，没有记录时显示 0
		最近辅导
			标题：最近辅导
			callAppBridge({type:"GetTableCSV", data:"题目辅导/默认表格", payload:"学段,答题场景,题目文字,题目图片,我的尝试,教练指导"})
			新提交的记录在第 1 行，取前 5 行，用卡片而不是密表
			每张卡片显示图片缩略、学段徽章、答题场景徽章、题目文字前 42 字；没有图片时用坐标格占位，不显示破裂图标
			点击卡片进入辅导记录并打开该行详情。行号就是这条在 csv 中的序号
			没有记录时显示空态文案“还没有辅导记录，先去读一张生物图表”，并给出按钮“开始一题”
	开始辅导
		左上标题：开始辅导
		说明：把题目和图表交给教练。日常练习请先写下你的判断
		右上按钮：看辅导记录，跳转到辅导记录
		页面在宽屏分成左右两栏，窄屏上下排列。左栏是题目工作台，右栏是教练指导
		工作台字段与表单一致
			表单标题:题目辅导,表:题目辅导,字段:[{字段名:学段,类型:单选项,可选项:初中,高中合格考,高中选考生物},{字段名:答题场景,类型:单选项,可选项:日常练习,考试或测验中},{字段名:题目文字,类型:文本},{字段名:题目图片,类型:文本},{字段名:我的尝试,类型:文本},{字段名:教练指导,类型:指令流}]
			学段、答题场景用分段按钮选择，默认分别是初中、日常练习
			题目文字是多行输入，占位文案：抄上题干，或描述你看到的坐标、图例和曲线
			我的尝试是多行输入，占位文案：先写你自己的判断、计算或不确定的地方
			题目图片不提供手工文本框。预览区初始为空
		图片按钮都要实现
			拍照上传：调用 CapturePhoto，把返回的全局文件名写入当前图片，并立刻用下载地址预览
			从相册选择：调用 SelectImage，同样预览
			移除图片：清空全局文件名和预览，不删除任何记录
			查看原图：仅当已有全局文件名时可点，在新窗口打开 private 地址
		日常练习时，工作台下方显示三枚本地核对芯片，不写入表：我看过坐标和单位、我看过图例、我写下了自己的判断。可勾选，仅作提醒
		当答题场景切换为“考试或测验中”
			隐藏核对芯片和任何读图提示
			显示琥珀提示条：考试或测验进行中时，教练不会讲解这道题，只会约你考后复盘
			不要提供“仍然讲解”“直接给答案”之类按钮
		右栏标题随场景变化：日常练习时为“教练指导”，考试或测验中时为“考后复盘约定”
		右栏初始文案：提交后，指导会以 Markdown 出现在这里
		提交给教练
			题目文字和题目图片都为空时按钮禁用
			学段、答题场景必须已选
			日常练习且我的尝试为空时，先弹出确认：“还没有写下尝试。教练会先请你自己判断，不会直接给原题答案。仍要提交吗？”取消则停留；确认后才提交
			考试或测验中不要求我的尝试，提交前不再追问答案
			提交时调用 SubmitRecord，payload 示例结构为 {"学段":"初中","答题场景":"日常练习","题目文字":"...","题目图片":"全局文件名或空字符串","我的尝试":"..."}
			成功后当前行设为 1，按轮询规则等待教练指导，并在右栏用 Markdown 主题显示
			Markdown 主题：标题用墨青绿，列表留出足够间距，引用块左侧用琥珀竖线，方便学生把“题中依据”和原理分开看
			成功后刷新首页统计所依赖的数据
		清空重填
			清空五个用户可见输入、图片预览和右栏指导，当前行设为 0
			不调用 DeleteRecord，不提交空记录
		再练一题进入本页时，可以带着预填的学段、答题场景、题目文字、题目图片、我的尝试，但右栏指导必须清空，当前行设为 0，直到再次 SubmitRecord
	辅导记录
		左上标题：辅导记录
		说明：回看每一题的图表、尝试和教练指导
		右上按钮：+ 再辅导一题，跳到开始辅导并执行清空重填
		搜索框按题目文字包含关系筛选，不区分多余空白
		筛选器：学段（全部、初中、高中合格考、高中选考生物）、答题场景（全部、日常练习、考试或测验中）
		筛选在已取回的 csv 上完成；切换到本页、提交、保存、删除后都重新 GetTableCSV
		列表用卡片，不用单独的只读表页面。卡片顺序与 csv 一致，第 1 张对应行号 1
		每张卡片展示：图片缩略、学段、答题场景、题目文字前 60 字、我的尝试前 36 字
			GetTableCSV 的字段仍是学段,答题场景,题目文字,题目图片,我的尝试,教练指导，保证与表单一致
			缩略图地址用下载链接。文件名空则显示占位
		每张卡片的操作按钮都要实现：查看指导、编辑、删除、再练一题
		点击卡片本身等同于查看指导
		查看指导
			当前行设为该卡片行号
			依次 GetCellValue 读取学段、答题场景、题目文字、题目图片、我的尝试、教练指导，payload 形如 "题目文字/3"
			打开详情层，而不是新页面：上方原图（可点查看原图）、学段与场景徽章、完整题目文字、完整我的尝试，下方教练指导用 Markdown 主题渲染
			详情层按钮：关闭、查看原图、编辑这题、再练一题、删除
			没有图片时隐藏查看原图
		编辑
			当前行设为该行号，用 GetCellValue 逐字段填入编辑层
			可改学段、答题场景、题目文字、我的尝试，可用拍照上传、从相册选择、移除图片更换题目图片
			教练指导只读展示，不出现输入框
			保存修改：对当前行依次 SetCellValue 五个可写字段，payload 形如 "学段/3/高中选考生物"。全部成功后关闭编辑层并刷新列表
			保存后提示“题目信息已更新。已有教练指导不会自动重写；若要新的指导，请点再练一题”
			取消：关闭编辑层，不写表
		删除
			确认后 DeleteRecord，payload 为该行号的字符串
			成功后刷新列表和记录数。若删的是当前详情行，关闭详情层，当前行设为 0
		再练一题
			用 GetCellValue 读取该行五个用户字段，跳到开始辅导并预填，图片按下载地址预览
			不复制教练指导，不在此时 SubmitRecord
		没有匹配记录时显示“没有找到这样的题目”，并保留清除筛选按钮。清除筛选要恢复全部卡片
	状态与刷新
		当前行初始为 0
		只有 SubmitRecord 成功才把当前行设为 1
		点卡片、查看、编辑时，当前行设为 csv 序号，不调用不存在的编号字段去反查
		所有按钮在等待接口时禁用，避免重复提交或重复删除
		接口失败时在页面内用简短文字说明失败，保留用户已填写内容
		图片地址无效时隐藏图片，不臆造图表内容
	必须全部实现的按钮
		导航：首页、开始辅导、辅导记录
		首页：开始一题；点击最近卡片查看对应行详情
		开始辅导：拍照上传、从相册选择、移除图片、查看原图、提交给教练、清空重填、看辅导记录
		辅导记录：搜索、两个筛选、清除筛选、+ 再辅导一题
		卡片与详情：查看指导、编辑、删除、再练一题、关闭、查看原图、编辑这题、保存修改、取消
		日常练习的尝试确认对话框：继续提交、取消
		考试或测验中不得出现任何要求直接讲题或给出原题答案的按钮
