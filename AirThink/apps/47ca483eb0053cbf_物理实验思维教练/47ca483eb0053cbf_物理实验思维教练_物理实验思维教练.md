# 物理实验思维教练

这是一个面向初中和高一学生的物理实验思维教练网页应用，包含首页、实验提问、辅导档案三个页面。不包含用户登录页。学生提交学段、实验问题、实验数据和实验图片后，由后台根据表里的指令流生成辅导说明；页面只负责收集问题、展示追问和回看记录。不要做「一键给出完整实验方案」「一键写数据结论」「代写实验报告」按钮。

页面统一使用「夜灯实验台」主题：背景是 #0E1A2B 到 #16324F 的纵向渐变，并叠加很淡的 24px 坐标网格。顶部导航是 #0B1524，底边一条 2px 铜金线 #C4A574。内容卡片像暖白实验记录纸 #F7F1E8，卡片文字 #1C2430，页面标题文字 #F4EFE6。主按钮为铜金底 #C4A574、深色字，悬停变为 #D4BC8E 并轻微上浮。次按钮为铜金描边。初中标签用青蓝 #2F6F8F，高中标签用赭石 #8C4A3A，删除用 #8E3B3B。圆角 16px，卡片有柔和阴影，悬停时出现细刻度线高光。字体用清晰的无衬线体。图标用弹簧、天平、坐标轴、烧杯等简洁实验意象。全站窄屏时改为单列，按钮不重叠。

本应用只有一张表，表名是「实验辅导」。字段只能使用这五个，不要自行编造 ID、编号、创建日期、状态或其他字段：学段（单选项，只能是「初中」或「高中」）、实验问题（文本）、实验数据（文本）、实验图片（图片）、辅导说明（指令流，不是用户手工填写的）。本表没有创建日期字段，也没有自动编号 ID 字段，表单上不要隐藏这类字段，主体列表上也不要显示。主体列表展示的字段、GetTableCSV 请求的字段、表单字段三者必须一致，都是：学段、实验问题、实验数据、实验图片、辅导说明。这样点击一条记录才能载入编辑表单。列表用卡片，不要用只读的单独页面。

数据接口必须按下面的方式调用，不要改参数名，不要换成其他请求库。
使用 callAppBridge({type:"GetTableCSV", data:"实验辅导/默认表格", payload:"学段,实验问题,实验数据,实验图片,辅导说明"}) 获取不含标题行的 csv 文本。返回顺序就是行顺序，第一条数据的行号是 1。图片字段的文本是图片全局文件名。必须按 CSV 标准解析引号、逗号和字段内换行，因为实验问题、实验数据和辅导说明里可能有逗号和换行。
使用 callAppBridge({type:"GetRecordCount", data:"实验辅导/默认表格"}) 获取记录数。
使用 callAppBridge({type:"GetCellValue", data:"实验辅导/默认表格", payload:"字段名/行"}) 获取单元格详情。查看详情和载入编辑表单时，五个字段都要分别调用 GetCellValue，不要只用 CSV 缓存填充。
使用 callAppBridge({type:"SetCellValue", data:"实验辅导/默认表格", payload:"字段名/行/值"}) 修改已有记录。payload 按「字段名/行号/值」拼接，行号是文本；值里如果含有斜杠，仍按前两段解析字段名和行号，余下全部作为值。
使用 callAppBridge({type:"SubmitRecord", data:"实验辅导", payload:"表单JSON文本"}) 新建记录。注意 SubmitRecord 的 data 是表名「实验辅导」，不是「实验辅导/默认表格」。提交后当前行是 1。
使用 callAppBridge({type:"DeleteRecord", data:"实验辅导/默认表格", payload:"行号文本"}) 删除记录。行号必须先 toString() 再传给 payload。
使用 callAppBridge({type:"SelectImage"}) 选择图片，返回图片全局文件名。
使用 callAppBridge({type:"CapturePhoto"}) 拍摄图片，返回图片全局文件名。
图片缩略图和大图链接是 "https://www.ithinkair.com:3031/download/全局文件名"。在浏览器新窗口打开原图的链接是 "https://www.ithinkair.com:3031/private/全局文件名"。没有图片时不要拼出空文件名链接。
辅导说明是指令流。新建时不要让用户填写，也不要放进 SubmitRecord 的 JSON。SubmitRecord 成功后要轮询等待后台异步生成结束。指令描述没有指定「以JSON格式输出」，所以轮询字段就是「辅导说明」。轮询标题:实验辅导,表:实验辅导,字段:辅导说明,输出到:辅导说明面板,等待消息:教练正在看你的装置和数据，准备用追问带你自己想通……。轮询实现为每 2 秒调用一次 GetCellValue，payload 为「辅导说明/当前行」，直到内容非空。超过 60 次仍为空，则停止并显示「教练还在想，可以继续等」，提供「继续等待」按钮，点击后从当前次数重新开始轮询。得到文本后用 Markdown 主题渲染，不执行其中的脚本。
接口失败时在页面上显示可读错误，并提供「重试」按钮，不要只在控制台打印。当前行初始是 0。筛选和搜索只改变显示，编辑、删除、详情必须使用 CSV 原始行号，不能使用筛选后的序号。

首页
	主标题：物理实验思维教练
	说明：用追问帮你自己弄懂实验设计、变量控制、数据处理、误差来源和结论表述。教练不直接给完整方案，也不代写结论。
	范围提示条：初中实验可以提问。高中只覆盖高一必修第一册的四个学生必做实验：测量做直线运动物体的瞬时速度、探究弹簧弹力与形变量的关系、探究两个互成角度的力的合成规律、探究加速度与物体受力及物体质量的关系。正在考试或测验中的题目，教练不讲。
	主按钮：开始一次实验追问，点击跳转到「实验提问」页，并清空上一题的表单、图片和辅导说明，当前行设为 0
	三个统计卡片并列，数字从接口实时计算，返回首页时刷新
		辅导记录卡片显示全部记录数
			API名称:GetRecordCount,数据源:实验辅导/默认表格
		初中提问卡片显示学段为「初中」的数量
			API名称:GetTableCSV,数据源:实验辅导/默认表格,字段:[学段,实验问题,实验数据,实验图片,辅导说明]
			筛选学段为「初中」后计数
		高中提问卡片显示学段为「高中」的数量
			同一份 CSV 中筛选学段为「高中」后计数
		记录数为 0 时三个数字都显示 0，不要报错
	接下来是「实验思维四格」，静态说明卡片，不读表，每张只写一句引导学生自己想的话，不写答案
		控制变量：先问自己，改变的量是哪一个，必须保持不变的量有哪些
		数据处理：先看单位、有效数字和图像，再决定用比值、差值还是斜率
		误差来源：先分清读数、操作和仪器，再判断结果会偏大还是偏小
		结论表述：结论要能指回数据和条件，不能先写结论再回头凑数
	接下来是「操作考试前自查」，本地勾选，不写入表
		标题旁显示已勾选数和总数，例如 3/7，下方用铜金进度条显示完成比例
		勾选项：
			能说出实验目的，而不是只背步骤
			能分清自变量、因变量和控制变量
			能说出测量工具、量程和读数时要注意的点
			能说明数据怎么记录、怎么处理
			能指出至少一个误差来源，并判断会使结果偏大还是偏小
			结论是从数据推出来的，不是先写好再凑数据
			知道正在考试或测验时，不要把试题交给教练
		勾选、取消勾选都要立刻更新进度条
		进度保存在 localStorage，刷新后仍在
		按钮：重新自查，点击清空全部勾选并更新进度
		全部勾选后显示一句：可以去操作了，记得用证据说话
	接下来是最近辅导，卡片形式，最多 4 张
		API名称:GetTableCSV,数据源:实验辅导/默认表格,字段:[学段,实验问题,实验数据,实验图片,辅导说明]
		新提交的记录在第 1 行，按 CSV 顺序取前 4 条，并记住原始行号
		每张卡片显示学段标签、实验问题（超过 42 字截断）、实验数据摘要（超过 36 字截断，空则显示「未附数据」）、图片缩略图或「无图片」、辅导说明摘要（去掉 Markdown 符号后取前 48 字，空则显示「追问生成中」）
		点击卡片打开该行的编辑表单：当前行设为该原始行号，跳到辅导档案页并载入表单
		卡片上还有「查看追问」按钮，打开详情模态，不进入编辑
		没有记录时不显示空卡片，改为说明「还没有提问」和按钮「去问第一个问题」，点击跳转实验提问

实验提问
	左栏是实验记录纸样式的提问表单，右栏是坐标纸样式的辅导说明面板。窄屏时上表单、下面板。
	左上标题：实验提问
	说明：把你卡壳的地方写清楚。教练会追问，不会直接替你做完。
	右上按钮：查看辅导档案，跳转到辅导档案
	表单标题:实验辅导,表:实验辅导,字段:[{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:实验问题,类型:文本},{字段名:实验数据,类型:文本},{字段名:实验图片,类型:图片},{字段名:辅导说明,类型:指令流}]
		学段用两个可选卡片呈现：初中、高中，必填，同一时间只能选一个
		选择高中时，在表单内展开范围说明，列出高一必修第一册四个学生必做实验的名称；超出范围仍允许提交，由教练在辅导说明里说明不讲
		实验问题是多行文本，必填，占位：写下你卡壳的实验问题，例如这个实验要控制哪些量
		实验数据是多行文本，可空，占位：如有表格或测量值，按原样贴上，先不要写结论
		实验图片可选
			按钮：拍摄装置，调用 CapturePhoto，把返回的全局文件名设为当前图片并显示预览
			按钮：选择图片，调用 SelectImage，把返回的全局文件名设为当前图片并显示预览
			按钮：清除图片，清空文件名和预览；没有图片时此按钮不可操作
			预览地址为 "https://www.ithinkair.com:3031/download/全局文件名"
		确认勾选：我确认现在不是在考试或测验中。未勾选时不能提交，并在勾选旁说明原因
		辅导说明不出现在可编辑输入里
	问题起步芯片，点击只填充学段和实验问题，不自动提交
		初中：测密度时我该先控制什么
		初中：这个电路实验里谁是自变量
		初中：数据忽大忽小，我该先从哪一类误差查
		高中：纸带上怎样找瞬时速度，我该先看哪一段
		高中：弹簧弹力和形变量的图像，我该先判断什么
		高中：两个力合成时，为什么要让结点保持不动
		高中：探究加速度与力、质量时，平衡摩擦力是在控制什么
	按钮：请教练追问我
		仅当已选学段、实验问题去掉空白后不为空、且已确认不是考试或测验时才可点击
		点击后禁用按钮，避免重复提交
		使用 SubmitRecord 提交，data 为「实验辅导」，payload 为 JSON 文本，只含四个键：学段、实验问题、实验数据、实验图片
		实验图片的值是当前全局文件名；没有图片时为空字符串
		实验数据为空时传空字符串
		不要把辅导说明放进 JSON
		提交成功后当前行设为 1，右栏开始轮询辅导说明
		提交失败则恢复按钮，保留表单内容，不开始轮询
	右栏标题：教练的追问
	未提交时显示引导：提交后，追问会出现在这里。先自己想一想变量和证据。
	等待时显示等待消息，并显示一个纯 CSS 的弹簧轻轻伸缩动画
	生成结束后，在右栏用 Markdown 渲染 GetCellValue 得到的辅导说明全文
	右栏不提供复制成实验报告、生成完整方案、直接给结论的操作
	右栏下方有一条瘦长的考前自查：五个本地勾选，分别对应变量、读数、处理、误差、结论。勾选状态独立于首页自查，只在本页使用，切换页面后仍保留在本次会话中
	按钮：再问一个新问题，位于表单底部。点击清空学段、实验问题、实验数据、图片预览、考试确认勾选和右栏辅导说明，当前行设为 0，停止正在进行的轮询。不删除已提交的记录
	若用户在轮询未完成时离开本页，停止本页轮询；之后可在辅导档案里对该行继续等待

辅导档案
	左上标题：辅导档案
	说明：回看每一次追问。点卡片可修改你写下的问题；要看教练全文，用查看追问。
	右上按钮：+ 新的追问，跳转到实验提问并清空表单，当前行设为 0
	搜索框：按实验问题或实验数据中的关键词筛选，输入时即时生效
	筛选器：学段，可选项为全部、初中、高中
	按钮：清空筛选，恢复全部卡片并清空搜索框
	数据
		API名称:GetTableCSV,数据源:实验辅导/默认表格,字段:[学段,实验问题,实验数据,实验图片,辅导说明]
		API名称:GetRecordCount,数据源:实验辅导/默认表格
		记录数为 0 时显示空状态和按钮「开始第一次追问」，点击跳转实验提问
		有记录但筛选后为空时，显示「没有符合的提问」，不要误显示成没有数据
	主体是卡片列表，不是单独的只读页。每张卡片都显示与表单一致的五个字段：学段、实验问题、实验数据摘要、实验图片缩略图或「无图片」、辅导说明摘要
		图片使用下载链接显示缩略图
		辅导说明摘要去掉 Markdown 符号，超过 80 字截断；内容为空时显示「追问生成中」
		卡片按 CSV 原始顺序排列，并在界面上不显示行号数字，但内部必须保存原始行号
		点击卡片主体：打开编辑表单并载入该行，不新开页面
		每张卡片的操作按钮都要实现：查看追问、编辑、删除、继续等待
	查看追问
		打开模态详情
		当前行设为该原始行号
		五个字段分别调用 GetCellValue 获取，不要只用列表缓存
		模态显示学段、实验问题全文、实验数据全文、图片大图、辅导说明
		实验数据用等宽预格式保留换行，方便看表格
		有图片时显示大图，并有按钮「在浏览器打开」，访问 "https://www.ithinkair.com:3031/private/全局文件名"
		辅导说明用 Markdown 渲染
		辅导说明为空时显示「教练还没有写完」，并显示「继续等待」按钮
		模态有关闭按钮
	继续等待
		对当前原始行轮询 GetCellValue，payload 为「辅导说明/行号」
		等待消息与实验提问页相同
		得到非空内容后刷新模态或卡片上的辅导说明，并用 Markdown 显示
		列表上的「继续等待」只在该行辅导说明为空时可点；已有内容时按钮不可操作
	编辑
		在本页展开编辑表单，不跳到新页面
		表单标题:编辑实验提问,表:实验辅导,字段与新建相同
		打开时当前行设为该原始行号
		用 GetCellValue 逐字段填充学段、实验问题、实验数据、实验图片、辅导说明
		学段、实验问题、实验数据可改
		实验图片显示当前图，可用拍摄装置、选择图片、清除图片更换；新图来自 CapturePhoto 或 SelectImage
		辅导说明在编辑表单中只读，用 Markdown 显示，并提示：修改这里的问题不会让教练自动重写追问；若要按新问题重新追问，请新建一次提问
		按钮：就此问题重新提问。把当前学段、实验问题、实验数据和图片带入实验提问页的新建表单，当前行设为 0，不调用 SubmitRecord，由学生自己确认后提交
		按钮：保存修改。依次用 SetCellValue 更新当前行的学段、实验问题、实验数据、实验图片，不要调用 SubmitRecord，也不要 SetCellValue 改辅导说明
		四个字段都保存成功后关闭表单、刷新卡片列表，并显示「已保存」
		任一字段保存失败则停止后续字段并显示错误，已成功的字段不回滚声称
		按钮：取消，关闭表单且不写回
		实验问题为空或学段不是「初中」「高中」时，保存按钮不可完成保存，并显示原因
	删除
		先弹出确认：删除后这次提问和辅导说明都不能恢复
		确认后调用 DeleteRecord，data 为「实验辅导/默认表格」，payload 为该原始行号的 toString()
		取消则不删除
		删除成功后刷新 GetTableCSV 和记录数；若删除的是正在编辑的行，关闭编辑表单，当前行设为 0
		删除失败时保留卡片并显示错误

各页面共同要求
	所有出现的按钮都要实现对应功能，不能只有样式
	导航、跳转、统计、搜索、筛选、清空、提交、轮询、继续等待、查看、编辑、保存、取消、删除、图片拍摄、图片选择、清除图片、起步芯片、自查勾选、重新自查、在浏览器打开图片，都必须可用
	从首页最近卡片进入编辑时，使用该卡片的原始行号
	编辑保存用 SetCellValue；只有「请教练追问我」使用 SubmitRecord
	布尔值在本表中不存在，不要添加是否字段
	本表没有关联表，不要请求其他数据源
	不要做登录、注册、权限或用户中心
	页面文案保持教练口吻：追问、让学生自己想，不承诺给出标准答案或完整实验报告
