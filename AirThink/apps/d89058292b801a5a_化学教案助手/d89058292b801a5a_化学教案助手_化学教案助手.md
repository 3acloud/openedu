# 化学教案助手
	这是一个面向化学教师的备课网页应用，单页内切换「备课台」「起草教案」「教案库」，不含登录页。用暖色实验笔记纸主题，而不是绿色后台风：纸色背景#F4F0E6，淡六边形晶格底纹，卡片#FFFCF7，主色钴蓝#0F4C5C，强调铜橙#C46B3A与青绿#1F8A70，标题用衬线、正文用柔和无衬线。卡片悬停轻轻上浮，左侧露出对应色条。所有数字、列表、详情必须来自接口，禁止假数据。本表没有自动编号ID、没有创建日期、没有状态字段，禁止自行编造字段。
	页面顶部固定导航
		左侧：六边形分子环Logo + 「化学教案助手」
		右侧标签：备课台、起草教案、教案库
		窄屏时标签收成同一导航，三个入口都可点
	数据源一律写作：化学教案/默认表格。表名：化学教案。字段只允许：设计类型、课题或单元、年级、教材版本、每节课分钟数、可用课时数、班额、班级学情、参考文件、教案草稿。
	通用接口
		取表：callAppBridge({type:"GetTableCSV", data:"化学教案/默认表格", payload:"设计类型,课题或单元,年级,教材版本,每节课分钟数,可用课时数,班额,班级学情,参考文件"})。返回不含标题行的csv。必须按标准CSV解析，班级学情可能含逗号、引号和换行，禁止简单split。教案草稿含大量逗号和换行，禁止放进GetTableCSV。解析后的每一行记住原始行号，行号从1开始，筛选和搜索不得改写行号。
		记录数：callAppBridge({type:"GetRecordCount", data:"化学教案/默认表格"})
		按值查行：callAppBridge({type:"GetRecordRow", data:"化学教案/默认表格", payload:"字段名/值"})，仅作辅助；重复课题时以CSV原始行号为准
		单元格：callAppBridge({type:"GetCellValue", data:"化学教案/默认表格", payload:"字段名/行"})
		删行：callAppBridge({type:"DeleteRecord", data:"化学教案/默认表格", payload:行号.toString()})
		改值：callAppBridge({type:"SetCellValue", data:"化学教案/默认表格", payload:"字段名/行/值"})。只按前两个斜杠切分，其余斜杠属于值。禁止对教案草稿调用SetCellValue。
		新建：callAppBridge({type:"SubmitRecord", data:"化学教案", payload:表单JSON文本})。提交成功后当前行固定为1。
		选参考文件：callAppBridge({type:"SelectFile"})，返回全局文件名，写入参考文件。
		图片链接：https://www.ithinkair.com:3031/download/全局文件名
		下载文件：https://www.ithinkair.com:3031/download/全局文件名
		浏览器打开：https://www.ithinkair.com:3031/private/全局文件名
		html/htm用private链接放进iframe。jpg/jpeg/png/gif/webp用download链接做缩略图。txt/md可用callAppBridge({type:"ReadFile", data:全局文件名})预览文本。参考文件为空时不拼接链接。
	教案草稿是指令流，不是输入框。指令在提交后由后台异步生成，界面不调用技能、不手写草稿。指令描述未要求JSON，因此轮询教案草稿本身，不轮询别的字段。
	表单标题:化学教案,表:化学教案,字段:[{字段名:设计类型,类型:单选项,可选项:课时教案,单元统筹,初高衔接},{字段名:课题或单元,类型:文本},{字段名:年级,类型:文本},{字段名:教材版本,类型:文本},{字段名:每节课分钟数,类型:数值},{字段名:可用课时数,类型:数值},{字段名:班额,类型:数值},{字段名:班级学情,类型:文本},{字段名:参考文件,类型:文本},{字段名:教案草稿,类型:指令流,指令描述:使用技能 e4c66981f5c77ead_xiaozhi-teach-chemistry-lesson-planner，为化学教师生成中文 Markdown 教案草稿。设计类型：{{设计类型}}；课题或单元：{{课题或单元}}；年级：{{年级}}；教材版本：{{教材版本}}；每节课分钟数：{{每节课分钟数}}；可用课时数：{{可用课时数}}；班额：{{班额}}；班级学情（含薄弱点、分层及上节课反馈）：{{班级学情}}。围绕宏观现象、微观解释、化学符号及回到宏观的闭环，按实际课时安排目标、环节、提问链和板书；涉及实验时仅规划实验位、观察点和安全等级，不提供操作流程。生成的题目与素材标注需人工验算，并注明教案须由教师复核。,文件字段:参考文件}]
		列表、最近卡片和GetTableCSV只使用前9个可编辑字段，与表单输入项一致，以便点一行就能编辑。教案草稿只在详情和预览区用GetCellValue读取，并用Markdown主题渲染。
		提交JSON只含这9个字段，不含教案草稿。未选文件时参考文件为""。数值用JSON数字。
	当前行初始为0。当前行<=1时「上一份」不可用；当前行为0或当前行>=记录数时「下一份」不可用。
	备课台
		主标题：化学教案助手。说明：把宏观现象、微观解释和化学符号串成可复核的教案草稿，兼顾课时、单元与初高衔接。
		按钮：起草新教案。点击进入起草教案，清空表单与预览，当前行设为0。
		按钮：浏览教案库。点击进入教案库。
		其下一条三色闭环说明，不是统计：宏观现象（铜橙）、微观解释（钴蓝）、化学符号（青绿），末端回到宏观。
		四个统计卡，点击后进入教案库并带上筛选
			全部教案：callAppBridge({type:"GetRecordCount", data:"化学教案/默认表格"})。点击不筛选。
			课时教案、单元统筹、初高衔接：同一次GetTableCSV只取设计类型，前端计数。
				callAppBridge({type:"GetTableCSV", data:"化学教案/默认表格", payload:"设计类型"})
		最近教案：卡片列出CSV前5行，不做假排序。每张卡显示设计类型色标、课题或单元、年级、教材版本、每节课分钟数×可用课时数、班额、班级学情前40字。有参考文件则显示小回形针。点击卡片打开详情，行号用该行原始行号。
			callAppBridge({type:"GetTableCSV", data:"化学教案/默认表格", payload:"设计类型,课题或单元,年级,教材版本,每节课分钟数,可用课时数,班额,班级学情,参考文件"})
		无记录时显示空状态文案「还没有教案。先从一次看得见的宏观现象开始。」并保留起草按钮。
	起草教案
		左栏表单，右栏教案预览。小屏改为上下排列。
		左上标题：起草教案。说明：写清课题、课时和班级学情；草稿生成后必须由教师复核。
		设计类型做成三张可选卡，提交值只能是「课时教案」「单元统筹」「初高衔接」
			课时教案：按一节课的分钟安排目标、环节、提问链和板书
			单元统筹：把若干课时连成宏观—微观—符号进阶
			初高衔接：对照初中基础与高中新要求安排过渡
		课题或单元：单行文本，必填
		年级：文本，必填。快捷芯片只负责填入，不限制手输：九年级、高一、高二、高三
		教材版本：文本，必填。快捷芯片：人教版、鲁科版、苏教版、沪科版，允许手输其他版本
		每节课分钟数、可用课时数、班额：数字，必填，必须大于0
		班级学情：多行文本，占位「写明薄弱点、分层和上节课反馈」。允许为空，但空时在生成前提示建议填写
		参考文件
			按钮：选择参考文件。调用SelectFile，成功后显示全局文件名
			按钮：清除参考文件。只清空本地字段，不删历史行
			若是图片，显示download链接缩略图；若是网页文件，显示「将在详情中用内嵌页打开」
		按钮：生成教案草稿。仅当前行为0时显示。校验失败则停在表单并指出字段。通过后SubmitRecord，当前行设为1，右栏进入等待。
		按钮：保存修改。仅当前行>=1时显示。依次SetCellValue写回9个可编辑字段，不提交、不轮询、不改教案草稿。完成后提示「基本信息已保存，原草稿未重算」。
		按钮：按当前内容重新生成。仅当前行>=1时显示。先说明这将新建一份教案，旧记录保留。确认后用当前表单SubmitRecord，当前行设为1，并轮询新草稿。
		右栏标题：教案草稿。右上角按钮：上一份、下一份。
			上一份：当前行减1，再用GetCellValue逐字段读回左栏，并读取该行教案草稿
			下一份：当前行加1，同样读回
			越界按钮不可点。读行前先GetRecordCount。
		等待：提交后每2秒调用callAppBridge({type:"GetCellValue", data:"化学教案/默认表格", payload:"教案草稿/"+当前行})。空文本继续等，最长120秒。等待文案：「正在生成教案草稿。生成后请教师复核；题目和素材要人工验算；实验只保留实验位、观察点和安全等级。」超时后显示「仍在生成」并给出按钮：继续等待、刷新这一份。
		得到非空文本后，用Markdown主题显示。预览上方固定复核条：草稿须教师复核；不得把实验位扩写成操作流程。
		按钮：复制教案。复制当前Markdown原文。无正文时不可点。
		按钮：打印。只打印课题、基本信息和Markdown草稿。
		右下浮动按钮：+ 新备课。清空表单、参考文件、预览和等待状态，当前行设为0。
	教案库
		左上标题：教案库。说明：复核、修改基本信息或删除草稿。
		右上按钮：+ 起草新教案。进入起草页并执行新备课清空。
		按钮：刷新。重新GetTableCSV和GetRecordCount。
		搜索框：匹配课题或单元、年级、教材版本、班级学情，前端筛选，保留原始行号。
		筛选：全部、课时教案、单元统筹、初高衔接。可承接备课台统计卡带来的筛选。
		主体用卡片，不用另做只读页。每张卡字段与表单一致：设计类型、课题或单元、年级、教材版本、每节课分钟数、可用课时数、班额、班级学情（最多两行）、参考文件名。
		每张卡的按钮都必须可用
			查看教案：打开详情层
			编辑：进入起草页，当前行设为该原始行号，9个字段全部用GetCellValue填入；教案草稿用GetCellValue显示在右栏，不放进输入框
			删除：确认后DeleteRecord，payload为行号字符串，然后刷新。若删的是当前行，当前行设为0
		点击卡片本身等同查看教案。
		详情层
			用GetCellValue读取全部字段。教案草稿用Markdown显示。
			显示复核条，内容同预览区。
			有参考文件时：下载、在浏览器打开。图片显示大图；html/htm用iframe打开private链接；txt/md可ReadFile预览。
			按钮：编辑此教案。同卡片编辑。
			按钮：删除此教案。同卡片删除，成功后关闭详情。
			按钮：复制教案、打印。
			按钮：关闭。
		无匹配时显示「没有符合条件的教案」，并提供清空筛选。
	编辑与新建的分界
		当前行为0：只能生成，不能保存修改。
		当前行>=1：保存修改只走SetCellValue；要更新草稿必须重新生成并因此产生新记录。
		点卡片或最近教案进入编辑时，以原始行号加载，保证列表字段与表单字段一致。
	失败时显示轻提示，不伪造教案、不补示例化学方程式、不补实验步骤。界面任何位置都不要提供实验操作流程、配方或危险品制取入口。
