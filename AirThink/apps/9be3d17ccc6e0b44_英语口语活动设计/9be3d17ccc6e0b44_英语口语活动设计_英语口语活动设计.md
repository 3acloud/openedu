# 口语课桌 · 英语口语活动设计
	这是一个供教师课前设计英语口语课堂活动的网页应用，包含首页、设计台、方案库三个页面。不做用户登录。本表没有自动编号 ID、创建日期或其他未定义字段，不要编造字段。不对学员自动评分，方案只供教师审定后使用。
	页面统一主题：课桌纸感，不是管理系统绿。背景为暖纸色 #F6F1E7，标题用衬线、正文用「PingFang SC」「Noto Sans SC」。顶部导航为墨蓝 #1E3A5F，主按钮与当前标签为珊瑚 #E26D5A，次级信息为松绿 #2A9D8F，提示芯片为暖金 #E9C46A。卡片圆角，悬停轻微上浮并加深阴影；学段、目标侧重、口语水平用不同颜色芯片区分。Logo 为对话气泡里的课桌图标，旁侧文字「口语课桌」，英文小字 Speaking Studio。
	页面顶部导航栏
		左侧：Logo 和「口语课桌」
		右侧标签：首页、设计台、方案库
		当前页标签用珊瑚下划线

	首页
		主标题：口语课桌，说明：按学段、班额和课时，设计有情境、可分层、可审定的英语口语活动
		主按钮：设计一份口语活动，点击进入「设计台」
		并列四张统计卡片，数字来自同一份数据，进入页面和从其他页返回时刷新
			方案总数
				API名称:GetRecordCount,数据源:口语活动设计/默认表格
				callAppBridge({type:"GetRecordCount", data:"口语活动设计/默认表格"})
			小学高段、初中、高中各一张，显示该学段方案数
				API名称:GetTableCSV,数据源:口语活动设计/默认表格,字段:[学段]
				callAppBridge({type:"GetTableCSV", data:"口语活动设计/默认表格", payload:"学段"})
				csv 无标题行，按行统计「小学高段」「初中」「高中」
		目标侧重细条：同一 csv 再取目标侧重，展示流利、准确、得体的数量比例，不做成独立页面
			callAppBridge({type:"GetTableCSV", data:"口语活动设计/默认表格", payload:"目标侧重"})
		最近方案：卡片列表，最多 4 张，按表格行号从 1 起取前 4 条（新提交在最前）。无记录时显示空状态「还没有口语活动，去设计台生成第一份」和按钮「去设计台」
			API名称:GetTableCSV,数据源:口语活动设计/默认表格,字段:[口语主题,学段,班额,课时分钟,目标侧重,学员口语水平]
			callAppBridge({type:"GetTableCSV", data:"口语活动设计/默认表格", payload:"口语主题,学段,班额,课时分钟,目标侧重,学员口语水平"})
			每张卡片显示口语主题、学段芯片、目标侧重芯片、学员口语水平芯片，以及「班额人 · 课时分钟分钟」
			csv 第 n 行的行号就是 n。点击卡片进入方案库并打开该行详情，不在首页单独做只读页

	设计台
		左上标题：设计台，说明：填好课情再生成；生成结果请教师验算分组和时间后再用
		右上按钮：+ 新建设计。点击清空左侧草稿和右侧画布，当前行设为 0，不删除任何记录
		左侧是「备课纸条」表单，只出现可填写字段，版式不要做成普通后台长表单
			口语主题：大号横线输入，必填
			学段：三张选择卡，只能是「小学高段」「初中」「高中」
			班额、课时分钟：并排数字步进器，必须是正整数
			目标侧重：三枚胶囊，只能是「流利」「准确」「得体」
			学员口语水平：四枚胶囊，只能是「基础」「中等」「提升」「差异较大」
			表单标题:口语活动设计,表:口语活动设计,字段:[{字段名:口语主题,类型:文本},{字段名:学段,类型:单选项,可选项:小学高段,初中,高中},{字段名:班额,类型:数值},{字段名:课时分钟,类型:数值},{字段名:目标侧重,类型:单选项,可选项:流利,准确,得体},{字段名:学员口语水平,类型:单选项,可选项:基础,中等,提升,差异较大}]
			口语活动方案是指令流，不放进表单，不由用户填写，不放进 SubmitRecord
		主按钮：生成新方案。必填未齐或正在轮询时不可点
			校验通过后 callAppBridge({type:"SubmitRecord", data:"口语活动设计", payload:"表单JSON"})
			payload 示例：{"口语主题":"校园跳蚤市场","学段":"初中","班额":42,"课时分钟":45,"目标侧重":"得体","学员口语水平":"差异较大"}
			班额、课时分钟在 JSON 里用数字。提交成功后当前行固定为 1
		提交后轮询指令流，直到生成结束。指令描述要求以 Markdown 文本输出，没有「以JSON格式输出」，因此轮询字段就是口语活动方案，不要另找 JSON 字段
			轮询标题:口语活动设计,表:口语活动设计,字段:口语活动方案,输出到:方案画布,等待消息:正在按学段、班额和课时编排活动，请稍候
			每 2 秒 callAppBridge({type:"GetCellValue", data:"口语活动设计/默认表格", payload:"口语活动方案/1"})
			空内容视为未完成，继续轮询；非空则停止并刷新首页统计与方案库
			等待时画布显示等待消息和审定提示，禁止把空白当成生成完成
			若教师离开设计台，记录已保存；回到设计台且当前行为 1、方案仍空时，自动继续轮询
		右侧方案画布
			未生成且当前行为 0：占位文案「生成后，这里会铺开一份可审定的口语活动方案」
			有内容时用 Markdown 主题渲染 GetCellValue 得到的口语活动方案，标题、列表、表格、示例对话都要可读
			画布顶部固定审定条：【AI 生成，入库前请人工验算】内容供教师审定后使用，不对学员自动评分
			画布底部核对条只作界面提醒，不写入表：分组是否按班额算得开；各环节分钟之和是否落在课时内；支架是否匹配学段和口语水平；评价只给教师观察，不自动给学生打分
			按钮：复制方案。无方案时不可点；有方案时复制当前 Markdown 原文，并提示已复制
			按钮：打印审定稿。无方案时不可点；有方案时只打印画布与审定条
		画布右上角浏览已保存方案
			按钮 < 和 >
			API名称:GetRecordCount,数据源:口语活动设计/默认表格
			当前行初始为 0。当前行<=1 时 < 不可操作；当前行为 0 或当前行>=记录数时 > 不可操作
			点击后按方向改变当前行，并用 GetCellValue 读取该行全部字段，填入左侧纸条，同时把口语活动方案渲染到画布
				callAppBridge({type:"GetCellValue", data:"口语活动设计/默认表格", payload:"口语主题/行号"})
				同样读取学段、班额、课时分钟、目标侧重、学员口语水平、口语活动方案
			浏览旧记录时显示提示：点「生成新方案」会另存一条新记录，不会覆盖正在查看的记录。若只改信息、保留原方案，请到方案库编辑
			< > 不调用 SubmitRecord，也不调用 SetCellValue

	方案库
		左上标题：方案库，说明：审定、改课情、删除已保存的口语活动
		右上按钮：+ 设计新活动，进入设计台并执行「+ 新建设计」的清空逻辑
		搜索框：按口语主题包含匹配，输入即筛选，不清空表格数据源
		筛选器：学段、目标侧重、学员口语水平，均可选「全部」或对应可选项。筛选在已取回的 csv 上完成，并保留原始行号
		主体用卡片，不用单独只读页，不用数据表格硬铺长方案
			列表字段与设计台可填写字段一致，便于点卡片后编辑
			API名称:GetTableCSV,数据源:口语活动设计/默认表格,字段:[口语主题,学段,班额,课时分钟,目标侧重,学员口语水平]
			callAppBridge({type:"GetTableCSV", data:"口语活动设计/默认表格", payload:"口语主题,学段,班额,课时分钟,目标侧重,学员口语水平"})
			无标题行；展示顺序即行号顺序，行号从 1 开始。本表无日期字段，不编造排序日期
			每张卡片显示口语主题、学段、班额、课时分钟、目标侧重、学员口语水平
			无记录：空状态和「去设计台」。有记录但筛选为空：显示「没有符合的方案」和「清除筛选」
			点击卡片打开详情抽屉。每张卡片的按钮都要实现：查看方案、编辑、删除
		查看方案
			抽屉标题为该行口语主题
			先展示六项课情，再展示方案
			课情与方案都调用 GetCellValue，不从卡片文本反推方案
				callAppBridge({type:"GetCellValue", data:"口语活动设计/默认表格", payload:"字段名/行号"})
				字段名依次为口语主题、学段、班额、课时分钟、目标侧重、学员口语水平、口语活动方案
			口语活动方案用 Markdown 主题显示。为空时写「方案仍在生成或尚未产生」，并提供「回设计台继续等」：跳转设计台，当前行设为该行，若行号是 1 且内容为空则继续轮询
			抽屉按钮：复制方案、打印审定稿、编辑这份、删除，行为与对应按钮一致。顶部同样显示审定条
		编辑
			从卡片或抽屉进入，当前行=该卡片行号。不新开只读页
			用 GetCellValue 逐字段填入编辑表单，字段与设计台可填写字段相同，不含口语活动方案输入框
			保存修改：依次 SetCellValue，不用 SubmitRecord，不触发重新生成，原口语活动方案保留
				callAppBridge({type:"SetCellValue", data:"口语活动设计/默认表格", payload:"口语主题/行号/值"})
				再依次写入学段、班额、课时分钟、目标侧重、学员口语水平
				单选项只能写入规定可选项；班额、课时分钟写入正整数字符串
			保存后关闭表单、刷新卡片，并提示：课情已更新，原活动方案未重算。若要按新课情重做，请用「按此课情新生成」
			取消：放弃未保存修改，不调用接口
			按钮：按此课情新生成。用当前表单六字段 SubmitRecord 另存新记录，当前行变为 1，关闭抽屉并进入设计台轮询口语活动方案。不覆盖旧行
		删除
			先确认「删除后不能恢复」。确认后 callAppBridge({type:"DeleteRecord", data:"口语活动设计/默认表格", payload:行号.toString()})
			payload 必须是文本。成功后重新 GetTableCSV 和 GetRecordCount，行号按新 csv 重算。若删的是当前行，当前行设为 0

	全局数据规则
		数据源一律写「口语活动设计/默认表格」；SubmitRecord 的 data 写表名「口语活动设计」
		GetTableCSV 的 payload 只能是本表字段名，逗号分隔，无空格，无标题行。列表、统计、点卡片编辑所用的可见字段都是：口语主题、学段、班额、课时分钟、目标侧重、学员口语水平
		指令流「口语活动方案」只在提交后由后台异步生成。显示详情必须先 GetCellValue，再用 Markdown 显示
		新建只用 SubmitRecord；修改已有记录只用 SetCellValue。布尔值本表没有，不要写是/否字段
		任何增删改和生成结束后都刷新记录数、统计和卡片。操作按钮除禁用条件外都必须真正完成上述动作，不能只做跳转空壳
		不使用图片、文件、语音接口，本表没有这些字段。不显示登录、不显示未定义列
