# 化学粒子图景

这是一个面向化学学习者的粒子图景网页应用，包含首页、粒子工坊、图景长卷三个页面。不需要用户登录页面。用单页切换实现，所有操作按钮对应的功能都必须实现。

页面统一主题：清透的粒子实验室。背景是雾青到浅紫的柔和渐变（#E7F6F3 到 #F3F0FF），导航栏为深青（#0B3D45），主色是湖青（#0E7C86），点缀色是暖铜（#E07A3D），用来表示原子核与键。卡片为白底玻璃感，细边框带淡青光，悬停时浮起并出现细小粒子点。标题用柔和无衬线字体。装饰只用圆点与短键线，不要写实危险实验器材。空状态用“粒子还在远处”一类温和文案。

页面顶部导航栏，深青背景，白色文字
	左侧显示由三个圆点与两条键线组成的粒子 Logo，以及「化学粒子图景」
	右侧标签：首页、粒子工坊、图景长卷
	当前标签用暖铜下划线标出，点击切换页面

数据约定
	表名：粒子讲解
	数据源：粒子讲解/默认表格
	只使用表中已有字段：学段、化学疑问、已有想法、粒子图解
	不要编造编号、创建日期或其他字段
	学段可选项只有：尚未学习化学、初中、高中
	粒子图解是指令流，不是用户填写项；不要把它放进提交 JSON，也不要用 SetCellValue 改写它
	新建使用 SubmitRecord；提交后当前行是 1；随后轮询粒子图解
	修改已有记录只依次 SetCellValue 学段、化学疑问、已有想法，不用 SubmitRecord
	布尔值本应用不使用；若出现，用「是」或「否」
	GetTableCSV 返回的 csv 不含标题行，第 1 行对应行号 1，依此类推；筛选和搜索后仍使用原始行号
	删除时行号必须 toString() 后传入 payload
	粒子图解详情必须用 GetCellValue 获取，并用 Markdown 渲染
	全局文件与图片本应用不使用

首页
	主标题：化学粒子图景
	说明：从看得见的现象出发，用文字粒子图连上微观过程；符号只在学段适用时出现
	三条路径小卡片并列：看见现象、画出粒子、连上符号
		看见现象：先说你观察到什么
		画出粒子：看粒子如何排列、运动、分开或重新组合
		连上符号：初中和高中再把粒子变化对上适用的化学符号；尚未学习化学时不展开化学式
	中央按钮：开始一次粒子讲解，点击进入粒子工坊，并清空表单、清空图景、当前行设为 0
	接下来并列四张统计卡片，悬停抬起
		总讲解数
			API名称:GetRecordCount,数据源:粒子讲解/默认表格
		尚未学习化学
			API名称:GetTableCSV,数据源:粒子讲解/默认表格,payload:学段,化学疑问,已有想法
			筛选学段为「尚未学习化学」后计数
		初中
			同一份 csv 中筛选学段为「初中」后计数
		高中
			同一份 csv 中筛选学段为「高中」后计数
		点击某一学段卡片，进入图景长卷并套用该学段筛选
	最近图景：卡片列表，取 csv 前 4 行（新提交在第 1 行）
		API名称:GetTableCSV,数据源:粒子讲解/默认表格,payload:学段,化学疑问,已有想法
		每张卡片显示学段徽章、化学疑问、已有想法摘要（没有则写「还没有形成想法」，过长截断）
		点击卡片进入粒子工坊，当前行设为该原始行号，并读取该行详情

粒子工坊
	左上大标题：粒子工坊
	说明：选择学段，写下疑问和已有想法。图景由后台生成，请用粒子语言阅读，而不是背结论
	右上按钮：查看图景长卷，点击进入图景长卷
	左侧为提问面板，右侧为粒子图景画布；窄屏时上下排列
	学段用三枚可选芯片，而不是普通下拉，必选其一
		尚未学习化学：提示「只用粒子说话，不展开化学式」
		初中：提示「可以连上初中适用的化学符号」
		高中：提示「可以连上更细的过程与符号，仍不代替计算、配平或实验教练」
	化学疑问：多行文本，必填
	已有想法：多行文本，可空；空时界面提示「可以写下你以为发生了什么，也可以先留空」
	按钮：生成粒子图景
		未选学段或化学疑问为空时不可点击，并在按钮旁温和提示
		表单标题:粒子讲解,表:粒子讲解,字段:[{字段名:学段,类型:单选项,可选项:尚未学习化学,初中,高中},{字段名:化学疑问,类型:文本},{字段名:已有想法,类型:文本}]
		payload 为 json 文本，只含学段、化学疑问、已有想法；已有想法为空则传空字符串
		使用 callAppBridge({type:"SubmitRecord", data:"粒子讲解", payload:"表单JSON"})
		提交后当前行设为 1
		轮询标题:粒子讲解,表:粒子讲解,字段:粒子图解,输出到:粒子图景画布,等待消息:粒子正在聚集成图……
		轮询使用 callAppBridge({type:"GetCellValue", data:"粒子讲解/默认表格", payload:"粒子图解/1"})，间隔重复，直到得到非空 Markdown；等待时画布显示等待消息和缓慢移动的三个粒子点
		得到内容后用 Markdown 主题渲染，不要当纯文本预格式化全部挤成一行
	按钮：清空，点击清空学段、化学疑问、已有想法和画布，当前行设为 0，不删除记录
	画布右上角按钮：< 与 >
		API名称:GetRecordCount,数据源:粒子讲解/默认表格
		当前行初始为 0
		当前行小于等于 1 时，< 不可操作
		当前行大于等于记录数，或记录数为 0 时，> 不可操作
		点击 < 或 > 后，用 GetCellValue 读取该行的学段、化学疑问、已有想法、粒子图解并填入面板与画布
			callAppBridge({type:"GetCellValue", data:"粒子讲解/默认表格", payload:"学段/当前行"})
			callAppBridge({type:"GetCellValue", data:"粒子讲解/默认表格", payload:"化学疑问/当前行"})
			callAppBridge({type:"GetCellValue", data:"粒子讲解/默认表格", payload:"已有想法/当前行"})
			callAppBridge({type:"GetCellValue", data:"粒子讲解/默认表格", payload:"粒子图解/当前行"})
		若粒子图解仍为空，继续按该行号轮询，等待消息不变
	Markdown 渲染要让层次清楚：现象、粒子文字图、化学符号、类比失效边界、检验问题分层显示；引用块用暖铜左边线
	画布下方有一块仅本页使用、不写入表的「用粒子语言复述」草稿框和「对照图景」按钮
		对照图景只在本地把草稿框滚到可见，并轻提示「试着说清粒子变了什么，不必追求标准答案」
		不要把草稿 SubmitRecord 或 SetCellValue
	若当前是已有行，显示按钮：保存修改
		依次调用 SetCellValue 更新当前行的学段、化学疑问、已有想法
		callAppBridge({type:"SetCellValue", data:"粒子讲解/默认表格", payload:"学段/当前行/值"})
		callAppBridge({type:"SetCellValue", data:"粒子讲解/默认表格", payload:"化学疑问/当前行/值"})
		callAppBridge({type:"SetCellValue", data:"粒子讲解/默认表格", payload:"已有想法/当前行/值"})
		保存后提示「想法已更新；已生成的粒子图解不会自动重写」
	按钮：据此再讲一次
		用当前面板的三个字段 SubmitRecord 新建一条，当前行变为 1，并按新建流程轮询粒子图解
		不要覆盖旧行的粒子图解

图景长卷
	左上大标题：图景长卷
	说明：回看每一次从现象走到粒子的讲解
	右上按钮：+ 新的粒子讲解，进入粒子工坊并执行清空
	搜索框：按化学疑问包含文字筛选
	筛选芯片：全部、尚未学习化学、初中、高中
	列表用卡片，不用单独的只读页面
	API名称:GetTableCSV,数据源:粒子讲解/默认表格,payload:学段,化学疑问,已有想法
	卡片显示与表单一致的字段：学段、化学疑问、已有想法
	每张卡片操作：查看图景、编辑、删除
		查看图景：展开该卡片下方详情，callAppBridge({type:"GetCellValue", data:"粒子讲解/默认表格", payload:"粒子图解/原始行号"})，Markdown 渲染；内容为空则轮询该行直到生成结束
		编辑：当前行设为原始行号，打开同一页右侧或下方表单，字段为学段、化学疑问、已有想法；用三次 GetCellValue 填入；保存时只用三次 SetCellValue，不用 SubmitRecord
		删除：先确认「这张粒子图景会被拿掉」，确认后 callAppBridge({type:"DeleteRecord", data:"粒子讲解/默认表格", payload:行号.toString()})，然后重新 GetTableCSV 与 GetRecordCount
	点击卡片主体同样进入编辑填充，便于整行修改
	没有匹配记录时显示空卡片：还没有这样的粒子图景，按钮「去粒子工坊」可跳转
	列表顺序保持 csv 原始顺序，不另造日期排序

各页面切换后保留已加载数据，生成、保存、删除、筛选后立即刷新相关计数与卡片。导航、生成、清空、上一条、下一条、保存修改、据此再讲一次、查看图景、编辑、删除、搜索、筛选和统计卡片跳转都必须可用。
