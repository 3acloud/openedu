# 学习协调助手

这是一个学习协调网页应用，面向学生把学习诉求交给协调技能，串联错题、理解、笔记、计划与专注，并在用户明确提出且已写明授权时，展示由后台生成的五维全景月报。页面只有首页、协调台、学习档案。不需要登录页。本表没有自动编号 ID，也没有创建日期，不要编造任何表外字段。

统一主题为「暖灯纸页」：背景是暖米色纸面 `#F3EEE4`，顶栏是深夜蓝 `#1B2A4A`，强调色是旧金 `#C4A35A`，正文墨色 `#2C2416`，辅助石板蓝 `#5C6B8A`。标题用衬线中文，正文用柔和无衬线。卡片白纸底、细金边、轻阴影，悬停时轻微上浮并加深金边。五个环节用低饱和色点区分：错题墨蓝、理解苔绿、笔记琥珀、计划陶土、专注暮紫。所有页面共用这一主题。

页面顶部导航栏，深夜蓝背景
	左侧是台灯与打开的书组成的 Logo，以及「学习协调助手」
	右侧标签：首页、协调台、学习档案
	当前页标签用旧金下划线，点击切换页面，不刷新丢失未保存提示：协调台表单有未提交改动时先确认

首页
	主标题：学习协调助手
	说明：说出这次想解决的学习问题。助手只根据已授权的必要信息判断接手错题、理解、笔记、计划或专注，不补造缺失内容；只有你提出并写明授权时，才汇总现有学习摘要生成五维全景月报
	主按钮：开始一次协调，点击进入协调台，清空表单，当前行设为 0
	次按钮：查看学习档案，点击进入学习档案
	接下来是三张统计卡片，颜色各不相同
		协调总数
			API名称:GetRecordCount,数据源:学习协调/默认表格
			callAppBridge({type:"GetRecordCount", data:"学习协调/默认表格"})
		已生成结果
			callAppBridge({type:"GetTableCSV", data:"学习协调/默认表格", payload:"协调结果"})
			返回不含标题行。按标准 CSV 解析。非空单元格计数。此调用只用于统计，不把协调结果放进可编辑表单
		学段覆盖
			callAppBridge({type:"GetTableCSV", data:"学习协调/默认表格", payload:"学段"})
			只按「小学中段、小学高段、初中、高中」分组计数，不新增类别
	接下来是五个环节入口卡片，横向排列，可换行。它们不是数据表，不单独建页
		错题复盘、概念理解、笔记整理、学习计划、专注支持
		每张卡片一行说明：该环节负责什么，最终仍由协调结果决定是否接手
		点击某张卡片：进入协调台，当前行设为 0，只预填学习诉求开头，不自动提交
			错题复盘预填：请判断是否接手错题环节，并说明下一步
			概念理解预填：请判断是否接手理解环节，并说明下一步
			笔记整理预填：请判断是否接手笔记环节，并说明下一步
			学习计划预填：请判断是否接手计划环节，并说明下一步
			专注支持预填：请判断是否接手专注环节，并说明下一步
		第六张强调卡片：生成五维全景月报
			点击进入协调台，当前行设为 0，预填学习诉求：请在本次授权范围内，仅根据我提供的学习摘要生成五维全景月报；信息不足时请直接提问，不要编造
			同时把「授权与限制」「学习摘要」输入框高亮，不自动提交
	最近协调
		标题：最近协调
		无记录时显示空状态，按钮「发起第一次协调」进入协调台
		有记录时用卡片显示前 5 条，不用宽表格
		callAppBridge({type:"GetTableCSV", data:"学习协调/默认表格", payload:"学习诉求,学段,授权与限制,学习摘要"})
		CSV 无标题行，第 1 行对应行号 1。提交后当前行是 1，故取 CSV 前 5 条作为最近记录，并记住原始行号
		每张卡片显示学段徽章、学习诉求前 36 字、学习摘要前 40 字
		点击卡片必须查看详情，不能只跳到空白页
			打开详情层
			依次 callAppBridge({type:"GetCellValue", data:"学习协调/默认表格", payload:"字段名/行号"})
			字段名为学习诉求、学段、授权与限制、学习摘要、协调结果
			协调结果用 Markdown 主题渲染；为空则显示「协调结果尚未生成」，并提供「刷新结果」按钮，再次 GetCellValue
			详情层按钮：在档案中编辑、关闭
			「在档案中编辑」进入学习档案，载入该原始行号到编辑表单

协调台
	左侧是诉求纸页，右侧是协调结果
	左上标题：协调台
	说明：填写学习诉求和学段；授权与限制写清允许使用什么、禁止推断什么。学习摘要只粘贴已获授权的必要内容
	右上按钮：学习档案，进入学习档案
	表单标题:学习协调,表:学习协调,字段:[{字段名:学习诉求,类型:文本},{字段名:学段,类型:单选项,可选项:小学中段,小学高段,初中,高中},{字段名:授权与限制,类型:文本},{字段名:学习摘要,类型:文本}]
		不要出现记录编号、创建日期或其他自造字段
		学习诉求：多行文本，必填
		学段：四选一的分段按钮，必填，不能手输别的值
		授权与限制：多行文本，占位提示「写明可使用的摘要范围，以及禁止外传、禁止推断的内容」
		学习摘要：多行文本，占位提示「只粘贴已授权的错题、理解、笔记、计划或专注摘要」
		协调结果不是表单输入项，不出现在提交 JSON 里
	按钮：提交协调
		学习诉求为空或学段未选时按钮不可用，并提示缺什么
		可用时 callAppBridge({type:"SubmitRecord", data:"学习协调", payload:"表单JSON"})
		JSON 只含学习诉求、学段、授权与限制、学习摘要
		提交后当前行设为 1
		右侧进入等待态，文案：正在判断接手技能，请稍候
		指令描述没有「以JSON格式输出」，所以轮询协调结果，不要轮询别的字段
		每 2 秒 callAppBridge({type:"GetCellValue", data:"学习协调/默认表格", payload:"协调结果/1"})
		得到非空文本后停止轮询，用 Markdown 主题显示
		超过约 60 秒仍为空则停止自动轮询，显示「尚未生成，可稍后刷新」，不要用前端文字冒充协调结果或月报
	按钮：刷新结果
		仅当前行大于等于 1 时可点
		callAppBridge({type:"GetCellValue", data:"学习协调/默认表格", payload:"协调结果/当前行"})
		用 Markdown 更新右侧；仍为空就保持未生成提示
	按钮：重新发起
		用当前表单内容再 SubmitRecord 一条新记录，不调用 SetCellValue
		成功后当前行设为 1，并按上面的规则重新轮询协调结果
	按钮：保存修改
		当前行小于 1 时不可用
		当前行大于等于 1 时，依次修改已有记录，不用 SubmitRecord
		callAppBridge({type:"SetCellValue", data:"学习协调/默认表格", payload:"学习诉求/行号/值"})
		再同样设置学段、授权与限制、学习摘要
		payload 按前两段分隔，字段名和行号之后的全部文本都是值，避免诉求里的斜杠被截断
		不设置协调结果
		保存后提示「已保存字段。协调结果不会因此重算；需要新的接手判断请点重新发起」
	按钮：清空
		清空四个输入和右侧 Markdown，当前行设为 0，停止轮询
	结果区右上角是浏览按钮 < 和 >
		callAppBridge({type:"GetRecordCount", data:"学习协调/默认表格"})
		当前行初始是 0
		当前行小于等于 1 时，< 不可用
		当前行大于等于记录数时，> 不可用
		点击 < 或 > 时，当前行加减 1，停止进行中的轮询
		用 GetCellValue 读取该行的学习诉求、学段、授权与限制、学习摘要、协调结果
		前四项填入表单，协调结果用 Markdown 显示
	结果区下方固定提示：若结果在提问，说明信息不足；补充授权或摘要后点重新发起。前端不得编造摘要、授权或月报

学习档案
	左上标题：学习档案
	说明：回看每一次协调。点卡片看详情，编辑只改已填写字段
	右上按钮：+ 新的协调，进入协调台并清空，当前行设为 0
	搜索框：按学习诉求、授权与限制、学习摘要包含匹配，不区分大小写
	筛选器：全部学段，以及小学中段、小学高段、初中、高中
	筛选和搜索只影响显示，删除和编辑必须用 CSV 原始行号，不能用筛选后的序号
	列表用卡片，不用单独的只读页
		callAppBridge({type:"GetTableCSV", data:"学习协调/默认表格", payload:"学习诉求,学段,授权与限制,学习摘要"})
		卡片字段与表单字段一致：学段、学习诉求、授权与限制、学习摘要
		长文本卡片内截断，编辑和详情仍读取全文
		无匹配时显示空状态，不伪造记录
	每张卡片的操作都要实现
		查看详情：打开详情层，GetCellValue 读取五个字段；协调结果 Markdown 显示；为空时可刷新结果
		编辑：把该原始行设为当前行，GetCellValue 把四个用户字段填入本页编辑表单，协调结果只读展示在表单下方
		删除：先确认，再 callAppBridge({type:"DeleteRecord", data:"学习协调/默认表格", payload:行号.toString()})，成功后刷新列表和首页统计；若删的是当前行，当前行设为 0 并清空编辑表单
	点击卡片主体等同查看详情
	编辑表单标题:学习协调,表:学习协调,字段与协调台相同
		按钮：保存修改
			依次 SetCellValue 更新当前行的学习诉求、学段、授权与限制、学习摘要
			不提交协调结果，不用 SubmitRecord
			保存后刷新卡片
		按钮：作为新协调重新发起
			用表单当前值 SubmitRecord，当前行变为 1，跳到协调台并开始轮询协调结果
		按钮：取消编辑，清空表单，当前行设为 0
	从首页「在档案中编辑」进入时，直接按传入的原始行号执行编辑载入

数据规则
	数据源一律写作学习协调/默认表格
	SubmitRecord 的 data 是表名学习协调，payload 是 JSON 文本
	GetTableCSV 的 payload 是逗号分隔字段名，返回值没有标题行；文本里可能有逗号、引号和换行，必须按标准 CSV 解析
	查看任一字段详情都用 GetCellValue，不用 CSV 缓存代替详情
	指令流字段协调结果由后台在 SubmitRecord 之后异步生成；详情和结果区都用 Markdown 主题显示
	布尔值才用「是」或「否」；本表没有布尔字段，不要把学段写成是或否
	全局文件名图片链接、下载链接、浏览器打开链接、HTML iframe 链接本应用用不到，不要增加图片、文件或语音字段
	所有操作按钮都必须真正完成上述调用或页面动作，不能只有样式
	加载失败时显示一句中文错误，保留重试按钮；重试只重复刚才的读取，不新增记录
