# 分层作业任务卡
	这是一个给教师核验后使用的分层作业任务卡网页应用，包含工作台、设计任务卡、任务卡库三个页面。不要用户登录页。不要增删字段，不要编造创建日期、自动编号ID或关联表。本表没有这类字段。前端不得本地编造作业正文，作业任务卡只来自后台指令流。
	数据源固定为：任务卡/默认表格。表名：任务卡。
	字段仅限：学段（单选项：小学中段、小学高段、初中）、学科（文本）、知识点（文本）、作业类型（单选项：单课时、单元复习、考前冲刺、原作业改写）、学情摘要（文本）、参考文件（文本，存文件全局文件名）、作业任务卡（指令流，任务智能体，文件字段为参考文件，输出类型为文本；指令描述为使用技能 xiaozhi-teach-assignment-designer，按学段、学科、知识点、作业类型和学情摘要生成任务卡；仅在学情有明确分层依据时生成分层任务卡，否则生成注明无学情的基础版；以 Markdown 文本输出任务卡、每题预计用时与总用时、逐题评分标准、批改指南及简明反馈模板；AI 生成题须标注‘AI 生成，入库前请人工验算’）。
	作业任务卡不是手工填写项。新建只用 SubmitRecord。修改已有记录只用 SetCellValue 更新可编辑字段，不要 SetCellValue 作业任务卡，也不要用 SubmitRecord 冒充修改。
	统一主题「墨蓝备课笺」：背景 #F3EDE2，侧栏 #1E3348，卡片 #FFFBF5，主文字 #1E3348，次文字 #6B6256，主按钮 #C46B4A，铜金点缀 #C4A46A，成功色 #2F6F5E。标题用 "Songti SC","Noto Serif SC",serif，正文用 "PingFang SC","Noto Sans SC",sans-serif。卡片圆角、浅纸影，悬停上移 2px 并显铜金边。学段色签：小学中段杏黄、小学高段青绿、初中墨蓝。作业类型用不同小图标：单课时、单元复习、考前冲刺、原作业改写。窄屏时侧栏收为顶部条。
	左侧导航栏，墨蓝底
		上方是打开的书页 Logo 和「备课笺」，其下小字「分层作业任务卡」
		导航项：工作台、设计任务卡、任务卡库。当前项用朱砂左边线高亮
	工作台
		主标题：分层作业任务卡。说明：教师填写学段、学科、知识点和作业类型，按可用学情生成时长可控的任务卡，附逐题评分标准与反馈模板，供教师核验后使用。
		主按钮：设计新任务卡，点击进入「设计任务卡」页面
		四张并列统计卡，数字来自一次列表数据，在本地计算
			任务卡总数
				callAppBridge({type:"GetRecordCount", data:"任务卡/默认表格"})
			单课时、单元复习、考前冲刺三张卡改为：四张小卡分别是四种作业类型的数量，外加总数卡共五张
				callAppBridge({type:"GetTableCSV", data:"任务卡/默认表格", payload:"学段,学科,知识点,作业类型,学情摘要,参考文件"})
				无标题行。按标准 CSV 解析，不要裸 split 逗号。按作业类型计数
			点击某一作业类型统计卡，进入任务卡库并套用该作业类型筛选
		最近任务卡：卡片列表，取上述 CSV 前 4 条（新提交后当前行是 1，默认行序即最新在前）。没有日期字段，不要编造时间排序
			每张卡片显示学段色签、学科、知识点、作业类型、学情摘要前 40 字；参考文件非空时显示回形针和文件名
			点击卡片查看详情，不要在工作台直接编辑
			无记录时显示空状态和「设计第一张任务卡」按钮，点击进入设计页
	设计任务卡
		左上标题：设计任务卡。说明：有明确分层依据才指望分层结果；学情为空或依据不清时，后台会生成注明无学情的基础版。
		右上按钮：去任务卡库
		表单标题:设计任务卡,表:任务卡,字段:[{字段名:学段,类型:单选项,可选项:小学中段,小学高段,初中},{字段名:学科,类型:文本},{字段名:知识点,类型:文本},{字段名:作业类型,类型:单选项,可选项:单课时,单元复习,考前冲刺,原作业改写},{字段名:学情摘要,类型:文本},{字段名:参考文件,类型:文本},{字段名:作业任务卡,类型:指令流}]
			只展示前六个可填项。作业任务卡不出现输入框
			学段、学科、知识点、作业类型必填。学科、知识点去首尾空格后不能为空
			学情摘要为多行文本，占位提示：可写掌握差异、典型错因、目标层级；没有明确分层依据请留空
			参考文件可选。三个按钮都必须实现：选择文件调用 callAppBridge({type:"SelectFile"})；拍摄参考资料调用 callAppBridge({type:"CapturePhoto"})；从相册选择调用 callAppBridge({type:"SelectImage"})。返回的全局文件名写入参考文件，后选覆盖先选。另有清除参考文件按钮，把该值清为空
			参考文件预览组件：jpg/jpeg/png/gif/webp/bmp 用图片链接 https://www.ithinkair.com:3031/download/全局文件名；html/htm 用 iframe 打开 https://www.ithinkair.com:3031/private/全局文件名；其他文件显示文件名，并给「浏览器打开」「下载」——打开走 https://www.ithinkair.com:3031/private/全局文件名 ，下载走 https://www.ithinkair.com:3031/download/全局文件名。空文件名时两个链接不可用
		按钮：生成任务卡。必填不齐或正在轮询时禁用
			callAppBridge({type:"SubmitRecord", data:"任务卡", payload:"表单JSON"})
			JSON 只含学段、学科、知识点、作业类型、学情摘要、参考文件。参考文件可为空字符串。不要把作业任务卡写进 JSON。正确转义引号和换行
			提交成功后当前行设为 1
		按钮：清空重填。清空六个可填项、预览和任务卡正文，当前行设为 0，停止轮询
		提交成功后轮询作业任务卡，不要轮询别的字段（指令描述不是以JSON格式输出）
			轮询标题:分层作业任务卡,表:任务卡,字段:作业任务卡,输出到:任务卡正文,等待消息:正在按学情生成任务卡，请稍候…
			每 2 秒 callAppBridge({type:"GetCellValue", data:"任务卡/默认表格", payload:"作业任务卡/当前行"})，当前行是 1
			得到非空文本后停止，用 Markdown 主题渲染到「任务卡正文」
			最多 60 次仍为空，则提示稍后到任务卡库刷新查看，并停止转圈
		任务卡正文下方固定核验条：请教师核对学段学科知识点、每题用时与总用时、评分标准；AI 生成题入库前请人工验算。此条是界面提示，不要改写后台正文
		正文就绪后三个按钮都要实现：复制任务卡（复制 GetCellValue 原文）、打印任务卡（只打印正文区）、查看刚入库的记录（打开详情，行号 1）
	任务卡库
		左上标题：任务卡库。说明：查阅、改条件、删除已生成的任务卡。改条件不会重新触发生成。
		右上按钮：+ 设计任务卡，进入设计页并清空表单，当前行设为 0
		搜索框：匹配学科、知识点、学情摘要，即时过滤
		筛选：学段（全部+三个可选项）、作业类型（全部+四个可选项）。统计卡跳转过来时带上对应作业类型
		重置按钮：清空搜索和筛选
		列表用卡片，不用单独表格页。数据调用 callAppBridge({type:"GetTableCSV", data:"任务卡/默认表格", payload:"学段,学科,知识点,作业类型,学情摘要,参考文件"})
			按返回行序展示，并为每条保留原始行号，从 1 开始。筛选只隐藏卡片，不改变行号
			卡片字段与可编辑表单字段一致：学段、学科、知识点、作业类型、学情摘要（前 80 字）、参考文件名
			每张卡片按钮都要实现：查看详情、编辑、删除。点按钮不要冒泡成点卡片
			点击卡片主体等同查看详情
		删除：先确认「确定删除这条任务卡？删除后不可恢复」。确认后 callAppBridge({type:"DeleteRecord", data:"任务卡/默认表格", payload:行号.toString()})，然后刷新列表和统计。若删的是当前行，当前行设为 0
		编辑表单标题:编辑任务卡,表:任务卡,字段与设计表单相同
			打开时当前行设为该卡片行号。逐字段 callAppBridge({type:"GetCellValue", data:"任务卡/默认表格", payload:"字段名/当前行"}) 回填学段、学科、知识点、作业类型、学情摘要、参考文件
			作业任务卡只读，同一方式取回后用 Markdown 显示，并有刷新按钮重新 GetCellValue
			参考文件可重新选择、拍摄、相册选择或清除，预览组件与设计页相同
			保存按钮：依次 SetCellValue 六个可编辑字段，payload 为「字段名/当前行/值」
				callAppBridge({type:"SetCellValue", data:"任务卡/默认表格", payload:"字段名/当前行/值"})
				不要提交作业任务卡，不要调用 SubmitRecord
			保存成功后刷新卡片列表，留在编辑态并提示「条件已更新。作业任务卡不会因此重生成；要新内容请回到设计页新建」
			取消按钮：关闭编辑，不写表
	详情层（工作台、库、生成后共用，不是独立只读页）
		打开时对应该行号，依次 GetCellValue 取学段、学科、知识点、作业类型、学情摘要、参考文件、作业任务卡
		上方显示学段色签、学科、知识点、作业类型。中部显示完整学情摘要和参考文件预览组件
		作业任务卡用 Markdown 主题显示。空则显示「尚未生成或仍在生成」，并提供刷新按钮再取一次
		按钮都要实现：编辑（载入该行编辑表单）、删除（同库删除）、复制任务卡、打印任务卡、关闭
		参考文件为空时，打开和下载按钮禁用
	通用实现
		所有表操作走 callAppBridge，数据源用「任务卡/默认表格」，SubmitRecord 的 data 用「任务卡」
		GetTableCSV 的 payload 必须是逗号分隔字段名，且只能是本表字段：学段,学科,知识点,作业类型,学情摘要,参考文件
		GetRecordRow 仅在需要按「字段名/值」查行号时使用；列表以 CSV 行序行号为准
		GetCellBullet 本应用不使用
		布尔值本表没有，不要出现是/否字段
		指令流详情必须先 GetCellValue，再用 Markdown 显示，不要把作业任务卡放进卡片摘要
		图片全局文件名的展示链接是 https://www.ithinkair.com:3031/download/全局文件名
		接口失败时用页面内提示说明失败，不要静默。选择文件、拍照、相册若返回空，保持原值
		当前行初始为 0。设计页生成成功后为 1。编辑时为被点卡片的行号
		每个写明的按钮、筛选、搜索、跳转、预览、轮询、复制、打印、删除确认都必须真正可用
