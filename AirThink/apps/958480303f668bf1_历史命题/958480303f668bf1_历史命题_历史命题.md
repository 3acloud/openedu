# 青史命题台

这是一个供历史教师审定命题草稿的单页网页应用，包含首页、命题工坊、命题库。不设登录页。页面只使用表「历史命题」中已定义的字段，不得编造记录编号、创建日期或其他字段。前端不得预置或编造史料、题干、答案与出处；试题正文只展示后台异步生成的「命题草稿」。

全站主题为宣纸墨卷，不要使用绿色工业风或植物风。背景为暖宣纸色 `#F3EBDD`，顶部导航为墨蓝 `#1E2A3A`，强调色为朱砂 `#B23A2F`，辅助色为鎏金 `#B8956A` 与松绿 `#3D6B5A`。标题用衬线宋体，正文用无衬线黑体。卡片白底、细金边，悬停时轻微上浮并露出左侧朱砂边线。难度用印鉴：基础为青印、中等为赭印、较难为朱印。学段用小标签。列表用卡片，不用只读表单独占一页。

页面顶部导航栏，墨蓝底
	左侧为朱砂圆印「史」与「青史命题台」
	右侧标签：首页、命题工坊、命题库
	当前页标签用鎏金下划线

首页
	主标题：青史命题台
	说明：按课程标准确定考查目标，核验史料出处，生成试题、参考答案与分层评分标准草稿，入库前须人工核对史实与出处
	主按钮：开始新命题，跳转命题工坊，清空表单，当前行设为 0
	次按钮：进入命题库
	提示条：请勿上传尚未启用的统考原题。生成稿标注仅供审定，不能代替教师核对。
	并列四张统计卡片，点击后跳转命题库并带上对应筛选
		命题总数
			API名称:GetRecordCount,数据源:历史命题/默认表格
			callAppBridge({type:"GetRecordCount", data:"历史命题/默认表格"})
		初中命题数、高中命题数
			API名称:GetTableCSV,数据源:历史命题/默认表格,字段:[学段]
			callAppBridge({type:"GetTableCSV", data:"历史命题/默认表格", payload:"学段"})
			按标准 CSV 解析后分别计数
		较难命题数
			同一份数据再取字段难度；callAppBridge({type:"GetTableCSV", data:"历史命题/默认表格", payload:"难度"})
			筛选难度为「较难」的记录计数
	素养印鉴：五枚印章横排，分别为唯物史观、时空观念、史料实证、历史解释、家国情怀，印中显示涉及该素养的命题数
		API名称:GetTableCSV,数据源:历史命题/默认表格,字段:[核心素养]
		callAppBridge({type:"GetTableCSV", data:"历史命题/默认表格", payload:"核心素养"})
		多选值按英文逗号拆开后累计，一项可同时计入多枚印章
	最近命题：卡片列出前 5 条。新提交记录位于第 1 行，故取返回顺序前 5 条。点击卡片打开详情层，不跳到只读新页面
		API名称:GetTableCSV,数据源:历史命题/默认表格,字段:[学段,考查内容,核心素养,题型,难度,设问要求,史料出处,史料文件,分值]
		callAppBridge({type:"GetTableCSV", data:"历史命题/默认表格", payload:"学段,考查内容,核心素养,题型,难度,设问要求,史料出处,史料文件,分值"})
		卡片显示学段、考查内容、题型、难度印鉴、分值、核心素养标签、史料出处摘要
		卡片按钮：查看草稿、继续编辑。查看草稿打开详情层；继续编辑跳转命题工坊并载入该行

命题工坊
	左上标题：命题工坊
	说明：先写考查目标与设问，再附可信史料，生成后在右侧审定草稿
	右上按钮：命题库，跳转命题库
	左侧为表单，右侧为命题草稿审阅区。窄屏时上下排列
	表单上方有五步条，仅作进度提示，不写库：确定考查目标、核查史料、设计设问、预估难度、审定草稿。已填项点亮
	表单标题:历史命题,表:历史命题,字段:[{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:考查内容,类型:文本},{字段名:核心素养,类型:多选项,可选项:唯物史观,时空观念,史料实证,历史解释,家国情怀},{字段名:题型,类型:单选项,可选项:选择题,材料解析题,开放性试题},{字段名:难度,类型:单选项,可选项:基础,中等,较难},{字段名:设问要求,类型:文本},{字段名:史料出处,类型:文本},{字段名:史料文件,类型:文本},{字段名:分值,类型:数值}]
		命题草稿是指令流，不出现在可编辑控件中，不放入提交 JSON，不用 SetCellValue 写入
		学段、考查内容、题型、难度、分值为必填；核心素养至少选一项；分值须为正数
		史料出处与史料文件都空时，允许生成，但在按钮旁显示「建议附上可核对的出处或史料文件」
		核心素养用复选框；提交与保存时用英文逗号连接选中项原文
		史料文件不是手工输入框
			按钮：选择史料，调用 callAppBridge({type:"SelectFile"})，返回值写入史料文件全局文件名
			按钮：移除史料，仅清空当前表单中的文件名，不立即写库
			有文件时显示文件名。图片扩展名 jpg、jpeg、png、gif、webp 用 https://www.ithinkair.com:3031/download/全局文件名 显示缩略图
			按钮：浏览器打开，访问 https://www.ithinkair.com:3031/private/全局文件名 ；若扩展名为 html 或 htm，在详情层用 iframe 打开该链接
			按钮：下载史料，访问 https://www.ithinkair.com:3031/download/全局文件名
	按钮：生成命题
		仅当前行为 0 且必填通过时可点
		callAppBridge({type:"SubmitRecord", data:"历史命题", payload:表单JSON文本})
		JSON 只含学段、考查内容、核心素养、题型、难度、设问要求、史料出处、史料文件、分值
		提交后当前行设为 1
		轮询标题:历史命题,表:历史命题,字段:命题草稿,输出到:命题草稿审阅区,等待消息:正在按课标生成命题草稿，请稍候核对史实与出处
		每 2 秒调用 callAppBridge({type:"GetCellValue", data:"历史命题/默认表格", payload:"命题草稿/1"})
		得到非空文本后停止轮询，用 Markdown 主题渲染；轮询中禁用生成按钮。超过约 2 分钟仍为空，则提示稍后到命题库刷新查看，并提供「重新读取草稿」按钮再次 GetCellValue
	按钮：保存修改
		仅当前行大于等于 1 时可点。依次 SetCellValue 写当前行的九个可编辑字段，不调用 SubmitRecord，不写命题草稿
		callAppBridge({type:"SetCellValue", data:"历史命题/默认表格", payload:"字段名/行号/值"})
		行号用当前行的数字文本。值中若含「/」，从左侧只切分字段名与行号，余下整段作为值
		保存后刷新列表与首页统计，草稿区仍用 GetCellValue 读取原命题草稿，并提示修改条件不会自动重写草稿；要重出题须先点「另起一题」再生成
	按钮：另起一题，位置在表单底部。清空全部可编辑项与草稿区，当前行设为 0
	草稿区右上角按钮：上一条、下一条
		API名称:GetRecordCount,数据源:历史命题/默认表格
		callAppBridge({type:"GetRecordCount", data:"历史命题/默认表格"})
		当前行初始为 0
		当前行小于等于 1 时，上一条不可操作
		当前行为 0 且记录数大于 0 时，下一条可点并载入第 1 行
		当前行大于等于记录数或记录数为 0 时，下一条不可操作
		换行时对九个可编辑字段及命题草稿逐个 GetCellValue 填入表单与 Markdown 区，不自动轮询
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:学段,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:考查内容,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:核心素养,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:题型,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:难度,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:设问要求,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:史料出处,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:史料文件,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:分值,行号:当前行
		API名称:GetCellValue,数据源:历史命题/默认表格,字段名:命题草稿,行号:当前行
	草稿区下方固定提醒：AI 生成，入库前请人工核对史实与出处
	按钮：复制草稿，把当前 Markdown 原文写入剪贴板；无草稿时不可点
	按钮：重新读取草稿，按当前行 GetCellValue 刷新命题草稿

命题库
	左上标题：命题库
	说明：检索、筛选并审定已生成的历史命题
	右上按钮：+ 新建命题，跳转命题工坊，清空表单，当前行设为 0
	搜索框：按考查内容、设问要求、史料出处包含匹配，输入即筛选
	筛选器：学段、题型、难度、核心素养。核心素养为「包含所选素养」。按钮：重置筛选
	排序：按分值高低，或按难度基础、中等、较难
	数据与卡片字段必须与表单可编辑字段一致，以便点卡片编辑
		API名称:GetTableCSV,数据源:历史命题/默认表格,字段:[学段,考查内容,核心素养,题型,难度,设问要求,史料出处,史料文件,分值]
		callAppBridge({type:"GetTableCSV", data:"历史命题/默认表格", payload:"学段,考查内容,核心素养,题型,难度,设问要求,史料出处,史料文件,分值"})
		用标准 CSV 解析引号与逗号，禁止按裸逗号切分行
		返回顺序与表行号一致，第 i 条（从 0 计）的行号为 i+1
	主体为卡片列表，每张卡片展示学段、考查内容、核心素养、题型、难度、设问要求、史料出处、史料文件、分值
		设问要求与史料出处过长时折叠，详情层看全文
		史料文件显示文件名；有图则显示下载链接缩略图
		每张卡片按钮都必须实现：查看草稿、编辑、删除、浏览器打开、下载史料
		查看草稿：打开详情层，并用 GetCellValue 读取该行命题草稿，Markdown 渲染
		编辑：当前行设为该行号，跳转命题工坊，逐字段 GetCellValue 填表并读取命题草稿
		删除：确认后 callAppBridge({type:"DeleteRecord", data:"历史命题/默认表格", payload:行号.toString()})，随后刷新卡片、统计与记录数；若删的是当前行，当前行设为 0 并清空工坊
		浏览器打开、下载史料的链接规则与命题工坊相同；无文件时按钮不可用
	空列表时显示空宣纸插画与「开始新命题」按钮

详情层
	从首页最近卡片或命题库「查看草稿」打开，覆盖在当前页上，不单独做只读表页面
	展示九个可编辑字段全文，以及命题草稿 Markdown
	命题草稿先 callAppBridge({type:"GetCellValue", data:"历史命题/默认表格", payload:"命题草稿/行号"})
	若草稿为空，显示「草稿尚未生成或仍在写入」，并提供重新读取按钮
	按钮：关闭、编辑此题、删除、浏览器打开、下载史料、复制草稿
	编辑此题与删除的行为与命题库卡片相同

全局规则
	操作按钮对应的功能必须全部实现，不能只做样式
	布尔值若出现，只用「是」或「否」；本表无布尔字段，不要另造
	没有自动编号字段，不要生成随机 ID，也不要在表格或表单上增加隐藏 ID
	主体卡片显示字段、GetTableCSV 的 payload 字段、表单可编辑字段三者保持一致
	指令流「命题草稿」只读。新建走 SubmitRecord 后轮询该字段；修改走逐字段 SetCellValue
	GetTableCSV 的 data 用「历史命题/默认表格」，payload 为逗号分隔字段名且必须是本表字段
	SubmitRecord 的 data 用「历史命题」，payload 为 JSON 文本
	GetCellValue、SetCellValue、DeleteRecord、GetRecordCount 的 data 用「历史命题/默认表格」
	DeleteRecord 的 payload 必须是行号字符串
	单元格详情用 GetCellValue，不要用卡片摘要代替草稿全文
	接口失败时在页面显示可重试的简短错误，不要静默失败
	从任一页进入时刷新记录数与列表。生成、保存、删除成功后同步刷新首页统计、最近卡片与命题库
