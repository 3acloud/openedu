# 遗忘提醒
	这是一个依据艾宾浩斯遗忘曲线的学习回访网页应用，包含首页、编排方案、提醒书架、曲线图鉴。不包含登录页。不要编造表中没有的字段，没有自动编号，也没有创建日期。
	主题叫「夜读琥珀」：顶栏与页脚是深靛蓝，强调色是琥珀，卡片是暖纸色，已授权用松绿，仅建议用陶土色。标题略带衬线，正文用柔和无衬线。卡片像索引卡，悬停时轻轻上浮，边线转为琥珀。背景可有极淡的遗忘曲线水印。各页同一主题，导航高亮当前页。列表一律用卡片，不用密集表格。操作按钮对应的功能必须全部实现。

	页面顶部导航栏
		左侧显示一条先下降再轻轻回升的曲线小标，以及「遗忘提醒」
		右侧显示标签：首页、编排方案、提醒书架、曲线图鉴
		窄屏时标签收入菜单，功能不变

	全局数据约定
		表：遗忘提醒
		数据源：遗忘提醒/默认表格
		登记字段只有：学习内容、内容类型、提醒类型、频率、学习日期、提醒时段、同意提醒、允许共享
		提醒方案是指令流，不是用户填写的。新建由后台在 SubmitRecord 后异步生成。要显示它，先调用 GetCellValue，再用 Markdown 主题渲染。前端不得编造方案正文。
		布尔值只用「是」或「否」
		当前行从 1 开始计数，初始为 0。SubmitRecord 成功后当前行是 1。
		GetTableCSV 返回不含标题行的 CSV。文本第 1 行对应行号 1。搜索、筛选、排序只改变展示，展示序号不是行号。每张卡片必须记住原始行号。
		删除时行号先 toString() 再传给 payload。
		修改登记用 SetCellValue 逐字段写当前行，不用 SubmitRecord。
		本表没有图片、文件、关联表。不要调用选择图片、拍照、语音、文件接口，也不要虚构关联表。

	首页
		主标题：遗忘提醒
		说明：把一次学习，排成可暂停、可取消、可免打扰的回访。没有明确同意时，只保留建议，不创建提醒。
		主按钮：编排一次回访，点击跳转到「编排方案」
		次按钮：打开书架，点击跳转到「提醒书架」
		接下来是并列的三张颜色不同的统计卡
			全部方案
				API名称:GetRecordCount,数据源:遗忘提醒/默认表格
			已授权提醒
				API名称:GetTableCSV,数据源:遗忘提醒/默认表格,字段:[同意提醒]
				筛选同意提醒为「是」后计数
			仅建议方案
				同一份 CSV 中筛选同意提醒为「否」后计数
			CSV 为空时三张卡显示 0，不报错
		曲线速览：四枚只读芯片，不读表
			标准间隔：第1、3、7、14、30天
			记忆高频：前3天每天，再接标准间隔
			错题强化：第1、2、5、10、21天
			每周一次：降频
			芯片下小字：22:00–8:00 不发送；方案里的普通日最多 3 条
		最近回访：卡片最多 5 张，按学习日期降序，日期相同则保持 CSV 原顺序
			API名称:GetTableCSV,数据源:遗忘提醒/默认表格,字段:[学习内容,内容类型,提醒类型,频率,学习日期,提醒时段,同意提醒,允许共享]
			每张卡片显示学习内容、内容类型、提醒类型、频率、学习日期、提醒时段
			同意提醒为「是」显示「已授权」，为「否」显示「仅建议」
			允许共享为「是」显示「可共享」，为「否」显示「不读取其他资料」
			点击最近卡片：进入「提醒书架」，并打开该原始行号的方案阅读层
			空状态文案温暖，并有按钮「写下第一份学习内容」，跳转编排方案

	「编排方案」页面
		左上大标题：编排方案
		说明：写清学了什么、怎么检验、何时轻轻敲你。只有同意提醒，才会真正创建提醒。
		右上按钮：去书架，跳转提醒书架
		左侧表单，右侧「这一次会怎样」说明卡。说明卡随选项即时改文案，不提交，不调用接口。
		表单标题:遗忘提醒,表:遗忘提醒,字段:[{字段名:学习内容,类型:文本},{字段名:内容类型,类型:单选项,可选项:理解类,记忆类,应用类,错题类},{字段名:提醒类型,类型:单选项,可选项:复习提醒,计划提醒,探索提醒,每日确认},{字段名:频率,类型:单选项,可选项:标准间隔,记忆高频,错题强化,每周一次},{字段名:学习日期,类型:日期},{字段名:提醒时段,类型:单选项,可选项:放学后,夜间,早起,午休},{字段名:同意提醒,类型:布尔},{字段名:允许共享,类型:布尔}]
			不要隐藏虚构的编号或创建日期
			学习内容为多行文本，必填，占位「例如：一元二次方程求根公式的推导」
			内容类型必填。说明卡：理解类用开放问答，记忆类用填空默写，应用类用变形练习，错题类用针对性练习
			提醒类型必填。说明卡：复习提醒围绕学习内容巩固；计划提醒写清今天要做的事，做完回复「完成」，不编造未提供的时长；探索提醒按咖啡聊天三问回收感觉；每日确认用晚间30秒三问
			频率必填。说明卡对应四档间隔，并注明每周一次是降频
			学习日期必填，默认今天，可改
			提醒时段必填。旁注：放学后取 16:30–17:30 或 19:00–20:00；夜间取 20:00–21:00；早起取 7:00–7:30；午休取 12:00–12:30。并固定提示 22:00–8:00 不发送
			同意提醒是开关，默认「否」。开为「是」，关为「否」。文案写明：只有明确同意才创建提醒，否则只给建议方案
			允许共享是开关，默认「否」。开为「是」，关为「否」。文案写明：为「否」时不读取其他技能资料
			提醒方案不出现在填写项中
		按钮：生成方案
			先校验必填。未通过只在字段下提示，不调用接口
			通过后把八个登记字段组成 JSON 文本，布尔用「是」或「否」
			API名称:SubmitRecord,数据源:遗忘提醒,payload:表单JSON文本
			调用形式：callAppBridge({type:"SubmitRecord", data:"遗忘提醒", payload:"表单JSON文本"})
			提交成功后当前行设为 1
			按钮进入等待，文案「正在按遗忘曲线写方案…」
			指令描述没有要求以 JSON 格式输出，所以轮询指令流字段「提醒方案」，不轮询其他字段
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:提醒方案,行号:1
			调用形式：callAppBridge({type:"GetCellValue", data:"遗忘提醒/默认表格", payload:"提醒方案/1"})
			取到非空文本即停止。仍为空则间隔重试，只显示温和等待，不伪造进度百分比，也不本地补写方案
			结束后在本页「方案预览」用 Markdown 主题显示全文
			同意提醒为「是」时预览标题为「已授权的提醒方案」；为「否」时为「建议方案（尚未创建提醒）」
			预览区按钮：去书架查看、再编一份
			再编一份只清空本页表单和预览，两个开关回到「否」，当前行设为 0，不删除刚提交的记录
		按钮：清空
			只清空本页表单和预览，不删记录，当前行设为 0

	「提醒书架」页面
		左上大标题：提醒书架
		说明：每张卡片是一次学习的回访票。点开可读方案，可改登记，可删除。
		右上按钮：+ 编排方案，跳转编排方案并清空表单，当前行设为 0
		搜索框：按学习内容包含匹配，实时过滤
		筛选器：内容类型、提醒类型、频率、提醒时段、同意提醒（全部/是/否）、允许共享（全部/是/否），可组合
		按钮：清除筛选
		排序：学习日期新到旧、学习日期旧到新，默认新到旧
		筛选和排序都不改变原始行号
		主体是卡片，不是表格。卡片字段与编排表单的登记字段一致，以便点开后编辑
			API名称:GetTableCSV,数据源:遗忘提醒/默认表格,字段:[学习内容,内容类型,提醒类型,频率,学习日期,提醒时段,同意提醒,允许共享]
			进入页面、生成返回、保存、删除后都重新获取
			同意提醒为「是」盖「已授权」丝带，为「否」盖「仅建议」丝带
			每张卡片必须有：查看方案、编辑、删除
			点击卡片主体等同查看方案
		查看方案是书架上的阅读层，不是另一张数据表页面
			当前行设为该卡片原始行号
			八个登记字段分别调用 GetCellValue 填阅读层抬头
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:学习内容,行号:当前行
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:内容类型,行号:当前行
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:提醒类型,行号:当前行
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:频率,行号:当前行
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:学习日期,行号:当前行
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:提醒时段,行号:当前行
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:同意提醒,行号:当前行
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:允许共享,行号:当前行
			方案正文单独获取
			API名称:GetCellValue,数据源:遗忘提醒/默认表格,字段名:提醒方案,行号:当前行
			调用形式：callAppBridge({type:"GetCellValue", data:"遗忘提醒/默认表格", payload:"提醒方案/当前行"})
			为空时显示「方案仍在生成」，并有「刷新方案」按钮再次 GetCellValue
			有文本时用 Markdown 主题显示全文，只渲染后台结果，包含间隔、文案、可回复动作、暂停/取消/调频口令、共享边界时原样呈现
			阅读层按钮：编辑这条、删除这条、关闭
			从首页最近卡片进入时，直接打开对应原始行号的阅读层
		编辑
			标题：修改回访登记
			不用 SubmitRecord
			用当前行八个字段的 GetCellValue 填充，开关按「是」「否」还原
			提醒方案在表单下方只读，用 Markdown 显示，不能当输入框修改
			保存前沿用新建的必填校验
			保存时八个登记字段依次调用 SetCellValue
			调用形式：callAppBridge({type:"SetCellValue", data:"遗忘提醒/默认表格", payload:"字段名/当前行/值"})
			保存成功后关闭表单，刷新 CSV，停留在书架
			提示：登记已更新；提醒方案是提交时生成的，修改登记不会自动重写方案。要全新方案，请重新编排一份
			取消只关闭表单，不写接口
		删除
			先确认，确认文案包含该条学习内容
			API名称:DeleteRecord,数据源:遗忘提醒/默认表格,payload:原始行号.toString()
			调用形式：callAppBridge({type:"DeleteRecord", data:"遗忘提醒/默认表格", payload:原始行号.toString()})
			成功后若阅读层正打开该行，关闭它，当前行设为 0，再刷新 CSV
			取消确认不调用接口
		空状态要区分：还没有任何方案时，给跳转编排的按钮；筛选无结果时，给清除筛选
		需要按字段值定位行时才使用 GetRecordRow
			调用形式：callAppBridge({type:"GetRecordRow", data:"遗忘提醒/默认表格", payload:"字段名/值"})
			返回行号从 1 开始。日常编辑和删除优先用 CSV 原始行号，避免同名内容找错行

	「曲线图鉴」页面
		这不是数据表页面，不调用 SubmitRecord、SetCellValue、DeleteRecord
		标题：曲线图鉴
		说明：频率决定间隔，内容类型只决定检验形式，提醒类型决定文案任务
		四张频率卡
			标准间隔：第1、3、7、14、30天
			记忆高频：前3天每天，之后接标准间隔
			错题强化：第1、2、5、10、21天
			每周一次：降频
		四张内容类型卡
			理解类：开放问答
			记忆类：填空默写
			应用类：变形练习
			错题类：针对性练习
		四张提醒类型卡
			复习提醒：围绕学习内容巩固
			计划提醒：写清今天要做的事，做完回复「完成」，不编造未提供的时长
			探索提醒：按咖啡聊天三问回收感觉
			每日确认：晚间30秒三问
		时段卡
			放学后：16:30–17:30 或 19:00–20:00
			夜间：20:00–21:00
			早起：7:00–7:30
			午休：12:00–12:30
			22:00–8:00 不发送
		边界卡
			同意提醒不是「是」时，只给建议方案，不创建提醒
			允许共享为「否」时，不读取其他技能资料
			普通日最多 3 条
			文案要有内容、有动作、有温度
			暂停、取消、调频靠方案里的回复口令，本应用不另建字段
		底部按钮：按这个去编排，跳转编排方案

	交互与失败
		加载计数、CSV、单元格时用安静的加载态
		接口失败提示可重试，不清空用户已填表单
		按钮和卡片可键盘聚焦
		不要用户登录，不要把指令流当手工输入，不要用展示序号删除或改单元格
