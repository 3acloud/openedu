# 英语写作教练
	这是一个面向小学高段、初中、高中学生的英语写作教练网页应用，包含首页、写作台、作品集、学情页面。教练不代写论点、整段或整篇，只展示后台生成的批注，让学生自己改。
	不要用户登录页。不要编造表里没有的字段。本表没有自动编号ID、没有创建日期，主体和表单都不要出现这类字段。
	页面是暖纸色书房主题，不是绿色后台、也不是通用紫渐变。背景为羊皮纸色渐变（#F3EBDD到#E7F0EC），卡片为#FFFCF7，主色墨蓝#1E3A4C，强调色珊瑚#D4654F，辅色松绿#3D7A6A、浅金#C4A35A。标题用衬线字体，正文用柔和无衬线。卡片悬停轻微上浮，左侧有一条学段色条：小学高段金、初中松绿、高中墨蓝。按钮必须全部能用，失败要在页面里提示，禁止静默失败，禁止用假数据冒充接口结果。
	页面顶部导航栏，墨蓝底、纸色字
		左侧是打开的笔记本小图标和「英语写作教练」，图标下用很小的英文 Writing Studio
		右侧标签：首页、写作台、作品集、学情
		当前标签用珊瑚下划线
	全应用只有一张表。表名：英语作文。数据源一律写：英语作文/默认表格。SubmitRecord的data用表名「英语作文」，不要写成数据源。
	字段只允许这6个，单选项只能用给定可选项，不能手输新选项：
		学段：单选项，可选项仅「小学高段」「初中」「高中」
		写作类型：单选项，可选项仅「作文批改」「邮件」「机场英语」「购物议价」「餐厅点餐」「演讲稿」「自我介绍」「应用文」「读后续写」「概要写作」
		题目要求：文本
		作文正文：文本
		图片：图片，单元格里存的是图片全局文件名，不是Base64
		批改反馈：指令流，不是用户填写的。不要放进可编辑表单，不要SetCellValue，不要由前端生成批改文字、范文或评分。只在SubmitRecord之后由后台异步写成，前端用GetCellValue取出并用Markdown主题显示
	主体列表（作品集卡片与首页最近列表）展示的字段必须与可编辑表单字段一致：学段、写作类型、题目要求、作文正文、图片。这样点一条就能载入表单。批改反馈只在详情区另取。
	表操作必须用下面的调用，返回值当真实数据用：
		callAppBridge({type:"GetTableCSV", data:"英语作文/默认表格", payload:"学段,写作类型,题目要求,作文正文,图片"})
			返回不含标题行的csv文本。图片字段文本是全局文件名。用标准CSV解析（字段可被双引号包裹，内部允许逗号、换行和转义引号），禁止按逗号简单split。解析后的第1条记录行号是1，以此类推。无日期字段，不要自己编日期排序；返回顺序就是行序，第1行视为最新。
		callAppBridge({type:"GetRecordCount", data:"英语作文/默认表格"})
			返回记录数
		callAppBridge({type:"GetCellValue", data:"英语作文/默认表格", payload:"字段名/行"})
			查看详情必须走GetCellValue，不要只用CSV缓存充当详情。行是数字行号。
		callAppBridge({type:"SetCellValue", data:"英语作文/默认表格", payload:"字段名/行/值"})
			只用于修改已有行。payload按前两个斜杠拆成字段名、行号、其余全部是值，值里可以有斜杠和换行。依次设置当前行要改的字段，不能用SubmitRecord代替修改。
		callAppBridge({type:"SubmitRecord", data:"英语作文", payload:"表单JSON文本"})
			只用于新建。JSON键只能是学段、写作类型、题目要求、作文正文、图片。图片没有则传空字符串。不要把批改反馈放进JSON。提交后当前行是1。
		callAppBridge({type:"DeleteRecord", data:"英语作文/默认表格", payload:"行号字符串"})
			行号必须toString()后再传。删除前要确认。
		callAppBridge({type:"SelectImage"})
			返回图片全局文件名
		callAppBridge({type:"CapturePhoto"})
			返回图片全局文件名
		已保存图片的展示链接是"https://www.ithinkair.com:3031/download/全局文件名"
		在浏览器打开图片用"https://www.ithinkair.com:3031/private/全局文件名"
		刚选中、尚未提交的图片，用callAppBridge({type:"ImageUrl", data:"Image"})预览
	指令流规则：SubmitRecord成功后当前行设为1，立刻轮询批改反馈，因为指令描述没有指定「以JSON格式输出」。每隔2秒调用GetCellValue，payload为"批改反馈/1"，直到文本非空，再用Markdown主题渲染到批注区。等待时显示「教练正在读你的句子，请稍候」，并禁用重复提交。超过60次仍为空，显示「批改还在进行，可稍后到作品集刷新」，并提供按钮「继续等待」重新轮询当前行。轮询过程中不要编造批注。
	作文正文永远按纯文本显示，不把学生输入当HTML。批改反馈按Markdown渲染，去掉脚本。当前行初始是0。
	首页
		主标题：英语写作教练
		说明：从语法、用词、逻辑指出具体句子，再用追问带你自己改。教练不代写。
		主按钮：开始一篇，跳到写作台，并清空表单、当前行设为0
		学段提示小字：小学高段把意思写清楚；初中留意时态和连接；高中留意衔接、准确用词，读后续写要接得上原文
		三个统计卡片，点击卡片跳到作品集并带上对应筛选
			总篇数
				callAppBridge({type:"GetRecordCount", data:"英语作文/默认表格"})
			小学高段篇数、初中篇数、高中篇数可并成一条学段分布，数据来自
				callAppBridge({type:"GetTableCSV", data:"英语作文/默认表格", payload:"学段,写作类型,题目要求,作文正文,图片"})
				在解析后的记录里按学段计数
		接下来是写作类型入口，10张小卡片，文案分别是：作文批改、邮件、机场英语、购物议价、餐厅点餐、演讲稿、自我介绍、应用文、读后续写、概要写作。点击跳到写作台，预填该写作类型，当前行设为0，表单其余项清空
		最近写作：标题「最近写过」。取上面GetTableCSV解析结果的前5条，行号就是1到5。用卡片，不用大表格。每张卡片显示学段色条、写作类型、题目要求前40字、作文正文前80字、图片缩略（有全局文件名才显示，链接用download地址）
			没有正文时，卡片写「手写稿，待识别」
			点击卡片：进入作品集，当前行设为该行号，逐字段GetCellValue载入表单和批改反馈，展开详情
			无记录时显示空状态：「还没有作文。写一段，或拍一张手写稿。」按钮「去写作台」
	写作台
		左上大标题：写作台
		说明：先选学段和类型，再写下题目要求与正文。正文可以空，但必须有手写图片，后台会按图片识别后再批改。
		右上按钮：看作品集，跳到作品集
		左侧是稿纸表单，右侧是批注纸。窄屏时批注纸排在表单下面。
		表单标题:英语作文,表:英语作文,字段:[{字段名:学段,类型:单选项,可选项:小学高段,初中,高中},{字段名:写作类型,类型:单选项,可选项:作文批改,邮件,机场英语,购物议价,餐厅点餐,演讲稿,自我介绍,应用文,读后续写,概要写作},{字段名:题目要求,类型:文本},{字段名:作文正文,类型:文本},{字段名:图片,类型:图片}]
			学段、写作类型用分段按钮，必选
			题目要求是多行文本。标签随写作类型变化，数据字段名始终是题目要求：
				作文批改：题目
				邮件、应用文：对象与要点
				机场英语、购物议价、餐厅点餐：场景任务
				演讲稿：场合、听众与要点
				自我介绍：介绍对象与要包含的信息
				读后续写：原文和两个段首句
				概要写作：原文
			作文正文是多行文本，显示英文字数（按空白分词，仅界面统计，不是字段）。场景类标签写成「你写的对话或句子」，其他类型写成「作文正文」
			图片区标题：手写稿（可选）。显示当前图，没有图时是虚线稿纸框
				按钮：拍照，调用CapturePhoto，把返回的全局文件名放进图片字段并预览
				按钮：从相册选，调用SelectImage，同样保存全局文件名并预览
				按钮：清除图片，仅当已有图片时可点，清空预览和文件名
			学段或写作类型未选，或正文与图片都空时，「请教练批改」不可点，并提示「请贴上作文，或拍一张手写稿」
		按钮：请教练批改
			组装JSON文本，例如{"学段":"初中","写作类型":"读后续写","题目要求":"...","作文正文":"...","图片":"全局文件名或空字符串"}
			callAppBridge({type:"SubmitRecord", data:"英语作文", payload:"上述JSON文本"})
			提交后当前行设为1，按指令流规则轮询payload为"批改反馈/1"
			批注区在等待时显示骨架和等待文案；得到文本后用Markdown显示
			批注区标题固定为「教练批注 · 语法 / 用词 / 逻辑」，标题下小字：「指向具体句子，用追问让你自己改。这里不会出现代写的整篇。」
		按钮：写新的一篇，位置在表单右上。清空五个可编辑字段和批注区、图片预览、本地修改框，当前行设为0
		批注区右上角两个按钮：上一篇、下一篇
			callAppBridge({type:"GetRecordCount", data:"英语作文/默认表格"})
			当前行<=1时，上一篇不可点
			当前行为0或当前行>=记录数时，下一篇不可点
			点击上一篇或下一篇：当前行加一或减一，然后对学段、写作类型、题目要求、作文正文、图片、批改反馈分别GetCellValue，payload形如"作文正文/3"
			图片用download链接显示。批改反馈为空则显示「这篇还没有批注」并给出按钮「刷新批注」，只对当前行重新GetCellValue，不新建记录
		学生修改区，标题「我自己改」，在批注区下方。不是新字段，是界面文本框，载入记录时用作文正文填入
			按钮：保存到这篇。仅当前行>=1可点。依次SetCellValue当前行的学段、写作类型、题目要求、作文正文、图片。作文正文写入修改框里的文字。不要写批改反馈。保存后用GetCellValue回读这五个字段刷新表单。旁边注明：保存不会重新批改。
			按钮：作为新一篇请教练再看。用修改框的文字作为作文正文，连同当前学段、写作类型、题目要求、图片，按新建规则SubmitRecord，再轮询新的第1行批改反馈。旧篇保留。
		按钮：删除这篇。仅当前行>=1可点。确认后callAppBridge({type:"DeleteRecord", data:"英语作文/默认表格", payload:当前行.toString()})，然后清空表单，当前行设为0，并刷新记录数
	作品集
		左上大标题：作品集
		说明：每一篇都在，点开就能改自己的句子，或再请教练看新的一篇
		右上按钮：+ 新的一篇，跳到写作台并执行「写新的一篇」
		搜索框：按题目要求、作文正文、写作类型包含匹配，在已取回的记录里筛，不另造接口
		筛选器：学段（全部加三个可选项）、写作类型（全部加十个可选项）。筛选在浏览器里做，保留原始行号，不能把筛选后的序号当成行号
		数据：
			callAppBridge({type:"GetTableCSV", data:"英语作文/默认表格", payload:"学段,写作类型,题目要求,作文正文,图片"})
		主体用卡片列表，不要单独再做一张只读表的页面。每张卡片显示学段、写作类型、题目要求、作文正文前80字、图片缩略
			点击卡片：当前行=该记录原始行号，用GetCellValue逐字段填充右侧表单（学段、写作类型、题目要求、作文正文、图片），并GetCellValue取批改反馈，Markdown显示
			卡片上的按钮都要实现：
				查看批改：滚动到批注并GetCellValue，payload为"批改反馈/行号"
				编辑：聚焦右侧表单，不新建
				删除：确认后DeleteRecord，payload为该行号.toString()，删除后刷新GetTableCSV，若删的是当前行则当前行设为0
		右侧为同一张表的编辑表单，字段与卡片一致：学段、写作类型、题目要求、作文正文、图片。图片可重新拍照或从相册选，也可清除。
			按钮：保存修改。对当前行依次SetCellValue五个字段，不提交新记录，不改批改反馈
			按钮：请教练看新一篇。用表单当前内容SubmitRecord，跳到写作台并轮询第1行批改反馈
			批改反馈在表单下方用Markdown显示，只读。空则显示「尚未生成」和「刷新批注」
		无匹配时显示「没有这样的作文」，按钮「清除筛选」
	学情
		左上大标题：学情
		说明：看看你更常练哪一类，不打分，不排名
		顶部四个纸卡片
			总篇数：GetRecordCount，数据源英语作文/默认表格
			手写稿篇数、有正文篇数、各学段篇数：来自GetTableCSV，payload为"学段,写作类型,题目要求,作文正文,图片"。图片字段非空计入手写稿，作文正文非空计入有正文
		图只用页面内的横向条，条宽表示数量，不加载外部图表库
			写作类型分布：按十个可选项计数，0也要显示，避免学生以为类型丢了
			学段分布：小学高段、初中、高中三根条
		条形图没有点击跳转以外的写操作。点击某一类型的条，跳到作品集并选中该写作类型筛选；点击某一学段的条，跳到作品集并选中该学段
		底部按钮：继续写，跳到写作台并清空为新篇
		不要按月份画趋势，因为表上没有日期字段
	各页操作按钮对应的功能必须全部实现。列表用卡片。首页最近卡片点击后必须能看到该行详情和批改反馈。新建只走SubmitRecord，修改只走SetCellValue，批改反馈只读、只轮询、只展示。
