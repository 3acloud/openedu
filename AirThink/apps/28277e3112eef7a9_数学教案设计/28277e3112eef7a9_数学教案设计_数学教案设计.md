# 数学教案设计

这是一个供初中及高一数学教师起草、审阅和回看教案的网页应用，包含首页、备课台、教案匣三个页面。不需要用户登录。不要编造表中不存在的字段，不要添加自动编号 ID、创建日期或其它未定义字段。全站只有一张表「数学备课」。教案正文不由页面自行编写或调用技能生成，只来自 SubmitRecord 之后后台异步写入的「教案草稿」。

页面统一为「靛蓝稿纸」主题：背景是暖米纸色，顶部导航为深靛蓝，点缀色为琥珀金，卡片为白底细线边，悬停时微微抬起并露出淡淡的几何辅助线。标题用稳重的衬线感字体，正文用清晰的无衬线字体。按钮、卡片、输入框风格一致。空状态用简短的备课引导语，不要留白到没有说明。

页面顶部导航栏，深靛蓝背景
	左侧显示三角板与圆规组成的简洁 Logo，以及「数学教案设计」
	右侧标签：首页、备课台、教案匣
	当前页标签用琥珀金下划线标出，点击切换页面

字段约定
	表名：数学备课
	数据源：数学备课/默认表格
	用户可填写字段，且仅此六项：课题（文本）、学段（单选项：初中、高中）、年级（文本）、教材版本（文本）、课时分钟（数值）、班级学情（文本）
	教案草稿是指令流，不是手工填写项。提交后由后台按表定义异步生成，内容为 Markdown。生成的题目应带有【AI 生成，入库前请人工验算】。页面只展示、不改写该字段
	高中学段在表单旁固定提示：高中内容限定在高一预备知识与函数范围，年级建议填写高一
	GetTableCSV 返回不含标题行的 CSV，行顺序与表行号一致，第一条数据的行号是 1。筛选、搜索只影响展示，必须保留原始行号。编辑、删除、取详情都用原始行号
	新提交的记录当前行是 1，首页「最近」按 GetTableCSV 返回顺序取前 5 条，不发明日期字段来排序

首页
	主标题：数学教案设计
	说明：把课题和班级学情交给备课台，生成待教师审定的教案草稿。草稿含概念建构、例题、变式、小结和错因预防，入库前请人工验算
	主按钮：开始备课，点击进入备课台，并清空未提交的表单，当前行设为 0
	并列三张统计卡，悬停抬起
		备课总数
			callAppBridge({type:"GetRecordCount", data:"数学备课/默认表格"})
		初中课题
			callAppBridge({type:"GetTableCSV", data:"数学备课/默认表格", payload:"课题,学段,年级,教材版本,课时分钟,班级学情"})
			筛选学段为「初中」后计数
		高中课题
			同一份 CSV 中筛选学段为「高中」后计数
	最近备课
		标题：最近备课
		无记录时显示空状态，并给出「开始备课」按钮
		有记录时用卡片显示前 5 条，字段与表单一致：课题、学段、年级、教材版本、课时分钟、班级学情（班级学情超过 48 字则截断并加省略号）
		数据来自上面的 GetTableCSV，卡片绑定原始行号
		每张卡片有「查看草稿」按钮。点击卡片或「查看草稿」都进入教案匣并打开该行详情
		学段用不同色的小标签区分初中与高中

备课台
	左上标题：备课台
	说明：填写课题与学情后生成待审教案。生成结果只作草稿，教师验算并审定后再使用
	左侧是备课表单，右侧是稿纸预览。窄屏时上下排列，预览仍在表单之后
	表单标题：数学备课
	表：数学备课
	字段：[{字段名:课题,类型:文本},{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:年级,类型:文本},{字段名:教材版本,类型:文本},{字段名:课时分钟,类型:数值},{字段名:班级学情,类型:文本}]
	课题、年级、教材版本、班级学情为输入框，班级学情用多行文本，占位提示写清知识弱项和分层需求
	学段用两个互斥选项，只能是「初中」或「高中」
	课时分钟只接受正数
	选择高中时，在学段下方显示限定提示
	不显示、不提交教案草稿输入框
	按钮：生成教案草稿
		六项都通过校验才可点击，否则按钮不可用，并在字段下显示缺项或格式错误
		点击后调用 callAppBridge({type:"SubmitRecord", data:"数学备课", payload:"表单JSON"})
		payload 只含课题、学段、年级、教材版本、课时分钟、班级学情。课时分钟在 JSON 中是数字，不是字符串
		提交成功后当前行设为 1，右侧进入等待态
	按钮：清空
		清空六个输入项、取消等待、清空右侧稿纸，当前行设为 0，不删除已有记录
	提交后的轮询
		轮询字段是教案草稿，不是别的字段。指令要求以 Markdown 文本输出，不要按 JSON 解析
		每隔约 2 秒调用 callAppBridge({type:"GetCellValue", data:"数学备课/默认表格", payload:"教案草稿/当前行"})
		等待消息：正在按概念建构四步组织教案，请稍候
		得到非空文本后停止轮询，用 Markdown 主题渲染到右侧稿纸
		超过约 90 秒仍为空则停止自动轮询，显示「草稿仍在生成」
		按钮：继续等待，点击后重新开始对当前行教案草稿的轮询
	右侧稿纸
		标题：待审教案草稿
		醒目提示：题目标有【AI 生成，入库前请人工验算】，请教师审定后再使用
		未生成时显示阅读提纲，提纲不是教案正文，只列出将出现的部分：可观测目标、核心素养、概念建构四步（情境引入、抽象概括、应用辨析、体系化）、例题示范、变式训练、课堂小结、常见错因预防、提问链与各环节用时
		生成后 Markdown 渲染标题、列表、表格和强调文字。正文区域可滚动
		按钮：复制草稿，把当前 GetCellValue 得到的 Markdown 原文复制到剪贴板，成功后按钮短暂显示「已复制」
		按钮：打印审阅，只打印右侧稿纸区域
		稿纸右上角有 < 和 >
			< 读取上一行，> 读取下一行
			先 callAppBridge({type:"GetRecordCount", data:"数学备课/默认表格"}) 得到记录数
			当前行初始为 0。当前行小于等于 1 时 < 不可操作。当前行大于等于记录数或记录数为 0 时 > 不可操作
			点击后当前行加一或减一，再逐字段 callAppBridge({type:"GetCellValue", data:"数学备课/默认表格", payload:"字段名/当前行"})
			回填课题、学段、年级、教材版本、课时分钟、班级学情，并以 Markdown 显示教案草稿
			若该行教案草稿仍为空，显示等待消息并按上面的规则轮询该行

教案匣
	左上标题：教案匣
	说明：回看已提交的备课记录。修改学情用保存，不会重新生成草稿；要新草稿请回备课台重新生成
	右上按钮：新备课，进入备课台并执行与「清空」相同的重置
	搜索框：按课题或教材版本包含匹配，不区分大小写也可按原文包含匹配
	筛选：全部、初中、高中。筛选与搜索同时生效
	列表用卡片，不用另做只读页。卡片就是主体列表，字段与表单完全一致
		callAppBridge({type:"GetTableCSV", data:"数学备课/默认表格", payload:"课题,学段,年级,教材版本,课时分钟,班级学情"})
		每张卡片显示课题、学段、年级、教材版本、课时分钟、班级学情，并记住原始行号
		无匹配时显示「没有符合条件的备课记录」
	每张卡片的操作都必须实现
		查看草稿：打开详情层
		编辑：打开编辑层并载入该行
		删除：先确认「删除后不能恢复」。确认后 callAppBridge({type:"DeleteRecord", data:"数学备课/默认表格", payload:行号.toString()})，成功后重新 GetTableCSV 和 GetRecordCount 刷新列表与首页统计
	点击卡片主体等同于查看草稿
	详情层
		标题为该行课题
		逐字段调用 callAppBridge({type:"GetCellValue", data:"数学备课/默认表格", payload:"字段名/行号"}) 获取课题、学段、年级、教材版本、课时分钟、班级学情、教案草稿
		上方用信息条显示六个备课字段
		下方用 Markdown 主题显示教案草稿。为空则显示「草稿尚未生成」并提供「继续等待」，轮询该行的教案草稿
		同样显示人工验算提示
		按钮：去编辑，关闭详情并打开该行编辑层
		按钮：关闭
	编辑层
		标题：修改备课信息
		只允许改课题、学段、年级、教材版本、课时分钟、班级学情。教案草稿只读，不出现输入框，也不要用 SetCellValue 改它
		打开时当前行设为该卡片的原始行号，用 GetCellValue 逐字段填入，不要用 CSV 片段代替详情
		按钮：保存修改
			校验规则与生成时相同
			依次调用 callAppBridge({type:"SetCellValue", data:"数学备课/默认表格", payload:"字段名/当前行/值"}) 写入六个字段
			不要调用 SubmitRecord
			保存后关闭编辑层，刷新卡片，并提示「已保存。教案草稿不会因此重新生成」
		按钮：取消，关闭编辑层，不写表
	从首页点进某条最近备课：切到教案匣，按原始行号直接打开详情层

交互与刷新
	进入首页、从其它页回到首页时刷新统计和最近卡片
	进入教案匣时刷新卡片
	删除、保存、生成成功后，相关列表和计数都立即刷新
	所有已写明的按钮都要有可见反馈：不可用、进行中、成功或失败原因
	callAppBridge 失败时在页面上说明失败，不要假装已保存或已生成
	布尔值若将来出现，只用「是」或「否」。本表没有布尔字段，不要自行添加
