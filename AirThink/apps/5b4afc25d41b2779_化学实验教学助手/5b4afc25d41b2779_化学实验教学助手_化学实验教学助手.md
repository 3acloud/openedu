# 化学实验教学助手

这是一个给初高中化学教师审核用的实验课规划网页应用，包含首页、规划实验课、方案库。不包含登录页。帮助教师按实验主题、班额、课时和器材条件整理安全分级、演示或分组、操作轮换、实验报告及操作考试练习要点。前端只采集条件并展示后台生成结果，不手写实验步骤，不替教师放行高风险学生操作。

本表只有「实验教学任务」，没有自动编号 ID，也没有创建日期。不要编造这些字段，不要在表格或表单上出现未定义字段。字段名只能是：实验主题、学段、班额、每节课分钟数、器材套数、教学需求、现场条件与要求、实验教学方案。

页面统一用「琉璃实验台」主题：导航与主按钮为深钴蓝 #0E3A5C，强调色为琥珀安全色 #D9920B，页面背景 #F3F6FA 带极淡分子点阵，卡片白底、细边框、玻璃高光，悬停轻微上浮。初中用 #1F7A8C 标签，高中用 #0E3A5C 标签。危险操作按钮用 #B42318。字体为 Noto Sans SC、sans-serif。列表用卡片，不用单独的只读表页面。所有按钮的功能都要实现。

顶部导航栏，钴蓝底，白字
	左侧：烧瓶与笔记本图标，以及「化学实验教学助手」
	右侧标签：首页、规划实验课、方案库
	当前页标签用琥珀下划线

数据操作约定
	列表与统计的数据源一律是「实验教学任务/默认表格」
	新建才使用 SubmitRecord，data 是表名「实验教学任务」，payload 是 JSON 文本
	提交成功后当前行固定为 1，新记录出现在第 1 行
	修改当前行必须逐字段 SetCellValue，禁止用 SubmitRecord 冒充修改
	实验教学方案是指令流，用户不能填写，提交后由后台异步生成；详情必须 GetCellValue 后用 Markdown 主题显示
	指令描述没有要求「以JSON格式输出」，因此只轮询「实验教学方案」
	布尔值本表不用；若以后出现，只能用「是」或「否」
	删除时 payload 必须是行号.toString()
	GetTableCSV 返回不含标题行，行序与表行号一致，第 1 条数据的行号是 1

首页
	主标题：化学实验教学助手
	说明：按班额、课时和器材套数规划实验课，生成待教师审核的安全分级、分组轮换、报告与操作考试练习方案
	琥珀提示条：高风险操作只安排教师演示、视频或仿真；方案须教师对照学校实验室规定审核后才能使用
	主按钮：规划新实验课，点击进入「规划实验课」，清空表单，当前行设为 0
	次按钮：查看方案库，点击进入「方案库」
	四张并列统计卡片，数字可点击并跳到方案库对应筛选
		全部方案
			API名称:GetRecordCount,数据源:实验教学任务/默认表格
			callAppBridge({type:"GetRecordCount", data:"实验教学任务/默认表格"})
		初中方案
			API名称:GetTableCSV,数据源:实验教学任务/默认表格,字段:[学段]
			callAppBridge({type:"GetTableCSV", data:"实验教学任务/默认表格", payload:"学段"})
			统计学段等于「初中」的行数
		高中方案
			同一 GetTableCSV 的学段列，统计学段等于「高中」的行数
		含操作考试练习
			API名称:GetTableCSV,数据源:实验教学任务/默认表格,字段:[教学需求]
			callAppBridge({type:"GetTableCSV", data:"实验教学任务/默认表格", payload:"教学需求"})
			统计教学需求文本中包含「操作考试练习」的行数
	课前三问卡片，横向三格，只做入口，不写入表
		主题是否已写清；班额和器材套数能否分组；教学需求是否已勾选
		点击任意一格进入「规划实验课」
	最近方案
		标题：最近生成的方案
		说明：新提交的记录在第 1 行，取前 4 条；没有记录时显示空烧瓶插画和「还没有方案，去规划一节实验课」
		API名称:GetTableCSV,数据源:实验教学任务/默认表格,字段:[实验主题,学段,班额,每节课分钟数,器材套数,教学需求,现场条件与要求]
		callAppBridge({type:"GetTableCSV", data:"实验教学任务/默认表格", payload:"实验主题,学段,班额,每节课分钟数,器材套数,教学需求,现场条件与要求"})
		每张卡片显示实验主题、学段标签、班额、每节课分钟数、器材套数、教学需求标签；现场条件与要求最多两行
		对这 4 条再分别取方案摘要
			API名称:GetCellValue,数据源:实验教学任务/默认表格,字段名:实验教学方案,行号:该卡片行号
			callAppBridge({type:"GetCellValue", data:"实验教学任务/默认表格", payload:"实验教学方案/行号"})
			有内容则显示纯文本前 60 字；为空则显示「生成中或尚未生成」
		点击最近卡片：进入方案库并打开该行详情，不直接进入编辑

规划实验课
	左上标题：规划实验课
	说明：填写课堂条件后生成待审核方案。预计分组只在页面上计算，不是表字段，不要提交
	右上按钮：+ 新建，清空表单、清空方案区，当前行设为 0
	左侧条件纸卡片，右侧方案笔记卡片；窄屏改为上下排列
	本地预估条，随班额和器材套数即时变化，不调用接口
		器材套数大于 0 时，预计分组数 = 向上取整(班额 / 器材套数)，每组约等于班额 / 预计分组数
		器材套数小于 1 或班额小于 1 时，预估条显示「请先填写有效班额和器材套数」，生成按钮不可用
	表单标题:实验教学任务,表:实验教学任务,字段:[{字段名:实验主题,类型:文本},{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:班额,类型:数值},{字段名:每节课分钟数,类型:数值},{字段名:器材套数,类型:数值},{字段名:教学需求,类型:多选项,可选项:实验课组织,实验报告指导,操作考试练习},{字段名:现场条件与要求,类型:文本},{字段名:实验教学方案,类型:指令流,指令描述:请使用技能 xiaozhi-teach-chemistry-lab-guide，为化学教师生成待审核的实验教学方案。实验主题：{{实验主题}}；学段：{{学段}}；班额：{{班额}}；每节课分钟数：{{每节课分钟数}}；器材套数：{{器材套数}}；教学需求：{{教学需求}}；现场条件与要求：{{现场条件与要求}}。先判定实验安全等级；高风险操作仅安排教师演示或视频、仿真。按所选需求给出演示或分组、角色轮换、时间与器材安排、安全准备，以及实验报告或操作考试练习要点。遵循学校实验室规定，输出 Markdown 文本。}]
		实验教学方案不渲染输入框，不参与手工提交
		实验主题必填
		学段用分段按钮，只能是「初中」或「高中」
		班额、每节课分钟数、器材套数必须是大于 0 的数字
		教学需求用三个复选框，至少选一项；提交时按所选标签用英文逗号拼接，顺序固定为：实验课组织,实验报告指导,操作考试练习
		现场条件与要求用多行文本，占位提示写通风、护具、是否允许学生动手、学校禁止项；不要预填任何实验步骤
	主按钮：生成待审核方案
		未通过校验时禁用
		只在当前行为 0 的新建状态使用 SubmitRecord
		payload 只含七个条件字段，例如 {"实验主题":"氧气的实验室制取","学段":"初中","班额":48,"每节课分钟数":45,"器材套数":12,"教学需求":"实验课组织,实验报告指导","现场条件与要求":"有通风橱和护目镜，学生不得进行高温操作"}
		callAppBridge({type:"SubmitRecord", data:"实验教学任务", payload:"表单JSON文本"})
		提交成功后当前行设为 1，并开始轮询
		若用户是从方案库带入的编辑状态，此按钮改为不可用，避免误把修改提交成新记录
	编辑状态下的按钮：保存条件
		依次调用 SetCellValue 更新当前行的七个条件字段，不调用 SubmitRecord，不写实验教学方案
		callAppBridge({type:"SetCellValue", data:"实验教学任务/默认表格", payload:"实验主题/当前行/值"})
		同样更新学段、班额、每节课分钟数、器材套数、教学需求、现场条件与要求
		保存后提示「条件已更新，原方案不会自动重算」
	编辑状态下的按钮：按此条件新建并生成
		先确认「将新增一条方案，当前行会变为 1」
		确认后用当前表单七个字段 SubmitRecord，当前行设为 1，再按下面的轮询规则等待新方案
	轮询标题:实验教学方案,表:实验教学任务,字段:实验教学方案,输出到:方案笔记,等待消息:正在生成待审核方案，请稍候
		仅在 SubmitRecord 成功后轮询，每 2 秒一次
		callAppBridge({type:"GetCellValue", data:"实验教学任务/默认表格", payload:"实验教学方案/当前行"})
		内容非空即停止，用 Markdown 主题渲染到「方案笔记」
		轮询时禁用生成、翻页和新建；最多 60 次
		超时后停止并提示「后台仍可能在生成，请稍后到方案库查看第 1 行」，禁止自动再次提交
	方案笔记
		标题：实验教学方案（待教师审核）
		顶部琥珀丝带：先看安全等级；高风险只保留教师演示、视频或仿真
		空状态：填写左侧条件并生成后，方案会显示在这里
		右上角按钮：上一行、下一行
			API名称:GetRecordCount,数据源:实验教学任务/默认表格
			callAppBridge({type:"GetRecordCount", data:"实验教学任务/默认表格"})
			当前行初始为 0；当前行小于等于 1 时上一行不可用；当前行大于等于记录数时下一行不可用
			点击后只读取，不提交
			API名称:GetCellValue,数据源:实验教学任务/默认表格,字段名:实验主题,行号:目标行
			七个条件字段都用 GetCellValue 回填表单，payload 形如「实验主题/行号」「教学需求/行号」
			实验教学方案同样 GetCellValue，并用 Markdown 显示
			教学需求按英文逗号拆回复选框
		按钮：复制方案，把当前 Markdown 原文复制到剪贴板；没有方案时禁用
		按钮：回到本条编辑，仅当当前行大于 0 时可用，把页面切到编辑状态，保存走 SetCellValue

方案库
	左上标题：方案库
	说明：审阅、修改课堂条件或删除已生成的任务；修改条件不会重算指令流
	右上按钮：+ 规划新方案，进入规划实验课并清空，当前行设为 0
	搜索框：按实验主题包含匹配
	筛选：学段全部/初中/高中；教学需求全部/实验课组织/实验报告指导/操作考试练习
	筛选和搜索都在前端对 GetTableCSV 结果进行，不新造字段
	API名称:GetTableCSV,数据源:实验教学任务/默认表格,字段:[实验主题,学段,班额,每节课分钟数,器材套数,教学需求,现场条件与要求]
	callAppBridge({type:"GetTableCSV", data:"实验教学任务/默认表格", payload:"实验主题,学段,班额,每节课分钟数,器材套数,教学需求,现场条件与要求"})
	主体用卡片墙，不用独立只读页
		每张卡片显示与表单一致的七个条件字段
		教学需求显示为标签
		现场条件与要求超过两行则折叠
		卡片左上用行号小字显示「第 N 行」，N 来自 CSV 顺序
		点击卡片主体：打开编辑层并载入该行，而不是只读跳转
		每张卡片的按钮都要实现：查看方案、编辑条件、按此新建、删除
	查看方案
		打开右侧抽屉或居中模态，不新建页面
		标题为该行实验主题，副标题为学段、班额、课时、器材套数
		callAppBridge({type:"GetCellValue", data:"实验教学任务/默认表格", payload:"实验教学方案/行号"})
		内容用 Markdown 主题显示；为空时显示「方案尚未生成」
		抽屉内按钮：复制方案、关闭、编辑此条
	编辑条件
		编辑层标题：编辑实验教学任务
		当前行设为该卡片行号
		七个条件字段逐个 GetCellValue 回填
		callAppBridge({type:"GetCellValue", data:"实验教学任务/默认表格", payload:"字段名/行号"})
		实验教学方案只在编辑层下方只读预览，不能输入
		保存按钮逐字段 SetCellValue
			callAppBridge({type:"SetCellValue", data:"实验教学任务/默认表格", payload:"字段名/行号/值"})
			字段顺序：实验主题、学段、班额、每节课分钟数、器材套数、教学需求、现场条件与要求
		取消按钮关闭层，不写表
		保存成功后刷新卡片，保持当前筛选
	按此新建
		读取该行七个条件字段，确认后 SubmitRecord
		成功后当前行设为 1，跳到规划实验课并轮询实验教学方案
	删除
		先确认「删除第 N 行后不可恢复」
		callAppBridge({type:"DeleteRecord", data:"实验教学任务/默认表格", payload:行号.toString()})
		成功后重新 GetTableCSV 和 GetRecordCount
		若删除的是当前行，把当前行设为 0 并清空规划页方案区
	定位
		首页点进某条时，可用行号直接打开；也可 callAppBridge({type:"GetRecordRow", data:"实验教学任务/默认表格", payload:"实验主题/实验主题值"})
		主题可能重复时以 CSV 行号为准，不以 GetRecordRow 的首次匹配覆盖已确定行号
	无匹配时显示「没有符合条件的方案」，并提供「清除筛选」按钮

交互与校验
	当前行全应用共用，初始 0；只有 SubmitRecord 成功才把当前行置 1
	从方案库载入行时，当前行改为该行号
	生成、保存、删除进行中，对应按钮显示忙碌并防止重复点击
	数值字段拒绝空值、0、负数和非数字
	学段和教学需求拒绝表定义之外的值
	卡片、按钮、导航都要有悬停反馈；点击区域不互相遮挡
	页面不出现登录、注册、权限或用户中心
	不调用选图、拍照、录音、读写文件接口；本表没有图片、文件和关联表字段
