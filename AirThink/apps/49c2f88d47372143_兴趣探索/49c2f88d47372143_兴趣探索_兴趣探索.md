# 兴趣探索

这是一个面向学生的兴趣探索手账网页应用，品牌名显示为「兴趣罗盘」。引导学生记下每次探索里被吸引的内容、遇到的困难、困难时的反应和时间感，并查看后台生成的本次探索反馈。长期追踪必须先看清记录说明，并如实填写学生同意与监护人同意或知情。页面不提供学科辅导、生涯规划或升学建议。不需要登录页。本表没有自动编号ID，也没有创建日期字段，禁止编造姓名、学校、电话、身份证、计划编号、记录编号、创建日期等表定义之外的字段。

全站主题「暖纸与罗盘」：页面背景是由 #FBF6EF 到 #F3E6D4 的暖纸纵向渐变；顶部导航为深靛蓝 #1E3A4C；主按钮与罗盘指针用琥珀 #E07A3D；继续探索的强调色用松绿 #1F8A70。字体用圆润无衬线（PingFang SC、Nunito）。卡片白底、大圆角、轻阴影，悬停时轻微上浮并出现琥珀色光边。困难反应用固定色点：想放弃 #C46B6B，想找资料继续 #1F8A70，有点烦但还想搞懂 #E0A106。时间感用固定色点：过得很快 #E07A3D，差不多 #7A8B99，有点熬 #6B5B95。窄屏改为底部四标签导航。装饰用纯CSS缓慢旋转的小罗盘，不承载数据。每页页脚固定一句：不提供学科辅导、生涯规划或升学建议；困难反应只作线索，样本少时不下结论。

操作表只使用下列桥接，数据源一律写「兴趣探索/默认表格」，提交时表名写「兴趣探索」。布尔值只使用「是」或「否」。csv不含标题行，字段顺序与payload一致；返回顺序即表行顺序，第1条数据的行号是1。文本里若含逗号，按CSV引号规则解析。无关联表，不要为关联表再次取csv。无图片、无文件字段，不要做上传、拍照或语音入口。

- 取表：callAppBridge({type:"GetTableCSV", data:"兴趣探索/默认表格", payload:"学段,探索领域,本次做了什么,吸引我的内容,遇到的困难,困难时的反应,时间感,他人反馈,既往探索记录,学生同意长期记录,监护人同意或知情"})
- 记录数：callAppBridge({type:"GetRecordCount", data:"兴趣探索/默认表格"})
- 按字段值查行号：callAppBridge({type:"GetRecordRow", data:"兴趣探索/默认表格", payload:"字段名/值"})。仅在该值能够唯一对应时使用；列表点击以csv顺序行号为准。
- 新建：callAppBridge({type:"SubmitRecord", data:"兴趣探索", payload:"表单JSON文本"})。提交成功后当前行设为1。payload只含下面11个手工字段，不要包含探索反馈。
- 改已有记录：对当前行逐个callAppBridge({type:"SetCellValue", data:"兴趣探索/默认表格", payload:"字段名/行/值"})，禁止用SubmitRecord修改。不要对探索反馈调用SetCellValue。
- 删除：callAppBridge({type:"DeleteRecord", data:"兴趣探索/默认表格", payload:行号.toString()})
- 单元格详情：callAppBridge({type:"GetCellValue", data:"兴趣探索/默认表格", payload:"字段名/行"})
- 指令流「探索反馈」不是手工字段。表定义中的指令已指定技能 aba6f1cff807b807_xiaozhi-interest-explorer。前端不得调用该技能，不得改写指令，不得在浏览器里编造反馈正文。指令描述没有要求“以JSON格式输出”，因此提交后只轮询「探索反馈」。详情用GetCellValue取出后，以暖纸Markdown主题渲染，并转义不安全HTML。

页面顶部导航栏，深靛蓝背景。左侧是罗盘图标和「兴趣罗盘」，图标下小字「兴趣探索」。右侧标签：首页、记下探索、探索足迹、线索分布。当前页标签用琥珀下划线。四个标签都能切换页面。当前行初始为0。

			API名称:GetTableCSV,数据源:兴趣探索/默认表格,字段:[困难时的反应]

	最近足迹：卡片列表，最多5张。新提交的记录在第1行，因此取csv前5条，不要编造日期排序。
		API名称:GetTableCSV,数据源:兴趣探索/默认表格,字段:[学段,探索领域,本次做了什么,吸引我的内容,遇到的困难,困难时的反应,时间感,他人反馈,既往探索记录,学生同意长期记录,监护人同意或知情]

		没有记录时显示空状态「还没有探索足迹」和按钮「记下第一次」，点击进入「记下探索」。
		点击最近列表项查看详情，不直接进入编辑。详情弹出层标题「这次探索」。逐字段调用GetCellValue显示全部手工字段；探索反馈另取并按Markdown显示。
			API名称:GetCellValue,数据源:兴趣探索/默认表格,字段名:对应字段,行号:该卡片行号
			API名称:GetCellValue,数据源:兴趣探索/默认表格,字段名:探索反馈,行号:该卡片行号
		详情按钮：关闭；编辑这条（关闭弹层并打开探索足迹的编辑抽屉）；删除这条（确认后DeleteRecord，成功后关闭弹层并刷新首页）。探索反馈为空时显示「反馈还在生成，可稍后刷新」，刷新按钮再次GetCellValue。

记下探索
	左上标题：记下这次探索。说明：先写这次实际发生的事。反馈由后台生成，页面自己不下兴趣结论。
	右上按钮：去足迹看看，进入「探索足迹」。
	布局为左表单、右反馈信。窄屏时反馈信排在表单下面。
	表单上方固定记录说明，提交前始终可见：
		记录内容：学段、探索领域、本次做了什么、吸引我的内容、遇到的困难、困难时的反应、时间感、他人反馈、既往探索记录、学生是否同意长期记录、监护人是否同意或知情，以及提交后生成的探索反馈。
		保存期限：记录保存在本应用中，可随时删除；删除后列表不再显示。
		可见范围：只在本应用内查看。不设公开分享、外链发布或学生档案导出。
		更正与删除：到探索足迹打开该条，可修改手工字段或删除整条。修改手工字段不会重写已经生成的探索反馈。
		勾选框文案：我已经看过上面的记录说明。这是页面状态，不是表字段，不要提交。
	表单标题:记下这次探索,表:兴趣探索,字段:[{字段名:学段,类型:单选项,可选项:小学中段,小学高段,初中,高中},{字段名:探索领域,类型:文本},{字段名:本次做了什么,类型:文本},{字段名:吸引我的内容,类型:文本},{字段名:遇到的困难,类型:文本},{字段名:困难时的反应,类型:单选项,可选项:想放弃,想找资料继续,有点烦但还想搞懂},{字段名:时间感,类型:单选项,可选项:过得很快,差不多,有点熬},{字段名:他人反馈,类型:文本},{字段名:既往探索记录,类型:文本},{字段名:学生同意长期记录,类型:布尔},{字段名:监护人同意或知情,类型:布尔}]
		学段、困难时的反应、时间感用大号可选芯片，选中态为对应色，提交值必须是可选项原文。

探索足迹

	主体用卡片列表充当主体表格，不用另做只读表页面。取数的字段必须与表单字段一致，以便点卡片载入编辑。
		API名称:GetTableCSV,数据源:兴趣探索/默认表格,字段:[学段,探索领域,本次做了什么,吸引我的内容,遇到的困难,困难时的反应,时间感,他人反馈,既往探索记录,学生同意长期记录,监护人同意或知情]

		API名称:GetCellValue,数据源:兴趣探索/默认表格,字段名:各手工字段及探索反馈,行号:当前行
		提示：保存只会更新手工字段，不会重新生成探索反馈。想要新的反馈，请新记一次探索。

线索分布
