# 每周学习复盘
	这是一个每周学习复盘网页应用，只有一张表「学习周报」。把学生一周的学习记录和自我复盘收成一份有证据的周报：小学中高段是三问版，初高中是六模块周报，下周只抓一个重点、至多三条行动；家庭分享版只在学生授权后出现在生成结果里。不要登录页，不要编造表里没有的字段。
	视觉是「夜读手账」，不要做成绿色后台或植物识别风。纸色背景 #F3EEE4，卡片 #FFFCF7，细边 #E5D8C4。顶部导航是墨蓝 #1C3554。强调色用台灯铜 #C4843C，完成与授权用苔绿 #3E7464，删除用 #9B3D3B。标题用衬线，正文用柔和 sans-serif。卡片和按钮有轻微抬起的悬停，档案卡片左缘像手账装订线。四个学段用不同墨色小印：小学中段 #6E8B74，小学高段 #3E7464，初中 #1C3554，高中 #8A5A2B。

	页面顶部导航栏，墨蓝底，底部一条铜细线
		左侧是打开的手账加小台灯图标，以及「每周学习复盘」
		右侧标签：首页、撰写周报、复盘档案
		当前页标签用铜下划线。三个标签都能切换页面，切换时不丢失档案页的搜索和筛选

	表操作约定
		本表没有自动编号ID，也没有创建日期。不要编造计划编号、记录编号、周报ID或任何未定义字段
		数据源一律写：学习周报/默认表格
		没有关联表，不要为其它表调用GetTableCSV
		布尔只使用「是」或「否」，不要用 true、false、1、0
		手填字段只有：周开始日期、周结束日期、学生昵称、学段、学习记录文件、自我复盘、家庭分享授权、情绪分享授权
		学段只能是：小学中段、小学高段、初中、高中
		日期用 YYYY-MM-DD
		学习记录文件存的是 SelectFile 返回的全局文件名，不是本地路径
		周报内容是指令流，用户不填写，提交 JSON 里不要带这个字段。指令描述没有要求「以JSON格式输出」，生成结束后只轮询周报内容
		主体列表用卡片，不用另做只读页。GetTableCSV 的字段必须与手填表单字段完全一致，顺序也一致：周开始日期,周结束日期,学生昵称,学段,学习记录文件,自我复盘,家庭分享授权,情绪分享授权
		GetTableCSV 返回不含标题行的 CSV，按返回顺序记录原始行号，第一条数据是 1。搜索、筛选、排序只改变展示，不改变行号。GetCellValue、SetCellValue、DeleteRecord 一律用原始行号
		payload「字段名/行/值」只按前两个斜杠切分，其余整段都是值，值里可以有斜杠和换行
		新建用 SubmitRecord。提交成功后当前行固定为 1，再轮询周报内容。修改已有记录只对当前行逐字段 SetCellValue，不要用 SubmitRecord，否则会多出一条记录
		修改手填字段不会重新生成周报内容。需要新周报时清空表单再新建
		删除前确认，确认文案带学生昵称和周日期。DeleteRecord 的 payload 必须是行号.toString()
		文件下载链接是 https://www.ithinkair.com:3031/download/全局文件名
		浏览器打开文件用 https://www.ithinkair.com:3031/private/全局文件名
		HTML 学习记录用上述 private 链接放进 iframe，不要当普通文本塞进页面
		文本学习记录可调用 ReadFile 预览前 400 字；读失败就只提供打开和下载
		周报内容详情先 GetCellValue，再用 Markdown 主题渲染这一份文本，不要拆成假字段，不要执行其中的脚本
		当前行初始是 0。当前行小于 1 时没有记录可读

	首页
		主标题：每周学习复盘
		说明：把一周的学习记录收成有证据的周报；数据不够就直说，不编造统计。下周只留一个重点
		主按钮：撰写本周复盘。点击进入「撰写周报」，当前行设为 0，清空表单，周开始日期默认本周一，周结束日期默认本周日，两个授权默认「否」
		四张并列手账卡片，可点击并跳到已套好筛选的复盘档案
			全部周报
				API名称:GetRecordCount,数据源:学习周报/默认表格
			本月周报
				API名称:GetTableCSV,数据源:学习周报/默认表格,字段:[周开始日期,周结束日期,学生昵称,学段,学习记录文件,自我复盘,家庭分享授权,情绪分享授权]
				周开始日期落在当前月的记数
			家庭分享已授权
				同一份 CSV 中家庭分享授权为「是」的记数
			学段覆盖
				同一份 CSV 按学段统计，卡片里列出四个学段各自的数量；点某个学段印进入档案并筛该学段
		最近手账：最多 5 张卡片，按周开始日期降序
			API名称:GetTableCSV,数据源:学习周报/默认表格,字段:[周开始日期,周结束日期,学生昵称,学段,学习记录文件,自我复盘,家庭分享授权,情绪分享授权]
			每张卡片显示学生昵称、学段印、周开始日期至周结束日期、自我复盘前 42 字、家庭分享授权徽章
			点击卡片打开周报阅读层，不是只把首页换成另一页空壳
			没有记录时显示空手账，并放「撰写本周复盘」按钮
		首页不显示周报内容全文；点开后再取

	撰写周报
		左上标题随模式变化：新建是「撰写周报」，编辑是「修改周报」
		说明：只依据学习记录写结论。小学中段和小学高段生成三问版，初中和高中生成六模块周报
		右上按钮：查看档案，进入复盘档案
		表单标题:学习周报,表:学习周报,字段:[{字段名:周开始日期,类型:日期},{字段名:周结束日期,类型:日期},{字段名:学生昵称,类型:文本},{字段名:学段,类型:单选项,可选项:小学中段,小学高段,初中,高中},{字段名:学习记录文件,类型:文本},{字段名:自我复盘,类型:文本},{字段名:家庭分享授权,类型:布尔},{字段名:情绪分享授权,类型:布尔}]
			没有隐藏的 ID 字段
			周日期用两个日期控件。结束日期早于开始日期时不能提交，并在字段下说明
			学段用四枚可选印，不要自由输入。选中后在表单旁提示：小学中段或小学高段将生成三问版；初中或高中将生成六模块周报；两种都只给一个下周重点和至多三条行动
			学习记录文件不是文本框
				按钮：选择学习记录，调用 SelectFile，把返回的全局文件名写入该字段
				按钮：清除文件，只清空未提交的选择
				选中后显示文件名、浏览器打开、下载。文本文件用 ReadFile 显示短预览；HTML 用 private 链接的 iframe 预览
			自我复盘是多行文本，可空。占位：可以写下本周最想记住的一件事；没有也不编造
			家庭分享授权、情绪分享授权用开关，存「是」或「否」
			授权说明固定显示：仅家庭分享授权为「是」时，生成结果才附家庭分享版；情绪内容还要情绪分享授权同时为「是」。两个开关可以分别设置
		新建主按钮：生成周报。学生昵称、学段、两个日期、学习记录文件缺一不可，不满足时按钮不可用并说明缺什么
			点击后调用 callAppBridge({type:"SubmitRecord", data:"学习周报", payload:表单JSON文本})
			JSON 只含八个手填字段，布尔为「是」或「否」，文件字段为全局文件名，不含周报内容
			提交后当前行设为 1
			立刻进入等待：正在按学段整理有证据的周报，数据不足会在周报里说明
			每 2 秒调用 callAppBridge({type:"GetCellValue", data:"学习周报/默认表格", payload:"周报内容/1"})，直到得到非空文本，最多 30 次
			得到后把这一份 Markdown 渲染到页面下方的「本周周报」纸页
			超时后保留表单，显示「生成时间较长，可稍后刷新」，并提供「刷新周报」按钮继续只轮询当前行的周报内容，不要再次 SubmitRecord
		编辑主按钮：保存修改。从档案进入编辑时出现，生成周报按钮隐藏
			保存时按原始行号依次 SetCellValue 八个手填字段
				API名称:SetCellValue,数据源:学习周报/默认表格,payload:字段名/当前行/值
			不要提交周报内容，不要调用 SubmitRecord
			保存成功后提示：手填内容已更新；已生成的周报不会因此重写
		次按钮：清空并新建。清空八个手填字段和纸页上的周报，当前行设为 0，周日期恢复本周一至本周日，授权恢复「否」，模式回到新建
		进入编辑时，用当前原始行号逐字段 GetCellValue 回填，不要用排序后的卡片序号
			API名称:GetCellValue,数据源:学习周报/默认表格,payload:字段名/当前行
			周报内容也取一次，渲染在表单下方，只读

	复盘档案
		左上标题：复盘档案
		说明：按周回看有证据的复盘。点卡片可读全文，编辑只改手填内容
		右上按钮：+ 撰写周报，进入新建模式
		搜索框：匹配学生昵称或自我复盘，输入即筛
		筛选：学段、家庭分享授权、情绪分享授权、周开始日期范围。可一键清除筛选
		排序：默认周开始日期降序，按钮可改成升序。排序不改变原始行号
		列表数据
			API名称:GetTableCSV,数据源:学习周报/默认表格,字段:[周开始日期,周结束日期,学生昵称,学段,学习记录文件,自我复盘,家庭分享授权,情绪分享授权]
			以手账卡片列出全部筛选结果，不要改成字段更少的另一套表
			卡片显示八个手填字段：日期写成一段，学段用墨印，文件显示文件名并附打开、下载，自我复盘超过 80 字则截断，两个授权用「是 / 否」徽章
			每张卡片的操作都必须可用：查看周报、编辑、删除、打开学习记录、下载学习记录
			查看周报：记下该卡原始行号为当前行，打开阅读层
			编辑：当前行设为该原始行号，进入撰写周报的修改模式并回填
			删除：确认后调用 callAppBridge({type:"DeleteRecord", data:"学习周报/默认表格", payload:原始行号.toString()})，然后重新 GetTableCSV 和 GetRecordCount；若删的是当前行，当前行设为 0 并关闭阅读层
			打开学习记录走 private 链接；下载走 download 链接。没有文件名时两个按钮不可用
		无匹配时显示空抽屉，并提供清除筛选、去撰写两个按钮
		点击卡片主体等同查看周报

	周报阅读层
		从首页最近卡片或档案卡片打开，盖在当前页上，不单独做只读路由
		先按当前行取周报内容
			API名称:GetCellValue,数据源:学习周报/默认表格,payload:周报内容/当前行
		纸页顶部写学生昵称、学段、周开始日期至周结束日期
		正文是单份 Markdown。家庭分享版和情绪内容若出现，是生成文本的一部分，不要另造字段，也不要因为前端授权开关再删一次
		内容为空时显示「周报还在生成或尚未生成」，按钮「刷新周报」只重新 GetCellValue，不要 SubmitRecord
		危机例外文字如果出现在周报里，原样放在纸页前部，不折叠、不改写
		右上角：编辑、删除、关闭。编辑和删除与档案卡片同一套行号逻辑
		左上角上一则、下一则
			API名称:GetRecordCount,数据源:学习周报/默认表格
			当前行小于等于 1 时，上一则不可用
			当前行大于等于记录数时，下一则不可用
			切换时当前行加一或减一，再逐字段 GetCellValue 刷新纸页和八个手填字段摘要
		学习记录在纸页侧栏提供打开、下载；文本则 ReadFile 短预览，HTML 则 iframe

	各页按钮的功能都要真正实现。新建、回填、保存、删除、搜索、筛选、排序、文件选择、打开、下载、轮询和阅读层切换不能只留界面。全站沿用同一夜读手账主题，卡片可悬停，列表用卡片。
