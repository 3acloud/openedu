# 物理错题分析

这是一个物理错题分析网页应用，面向初中与高一学生收集错题作答，提交后等待后台根据已配置的物理错误DNA技能生成错因分析。前端只负责录入、展示、检索和按已有数据做弱项对照，不调用技能、不改写分析、不自行累计次数。无登录页。全站统一「深空实验室」主题。

主题
	背景为午夜海军蓝纵向渐变（#0B1220 到 #16243A），用纯CSS画极淡的轨道圆环，不使用外链装饰图。
	主色电光青 #2EE6D6，强调色琥珀金 #F0B429，删除与警示用珊瑚红 #FF6B6B，卡片为半透明深蓝玻璃，边框 1px rgba(46,230,214,0.28)，圆角 16px。
	悬停时卡片上浮并增强青色辉光。按钮为胶囊形。字体为 system-ui、PingFang SC、Microsoft YaHei、sans-serif。
	四种基础错因固定配色，全站一致：概念模糊=电光青，计算失误=琥珀金，读题失误=紫罗兰 #A78BFA，方法用错=珊瑚红。
	窄屏时顶部标签可横向滚动，卡片改为单列。

数据约定
	本应用只有一张表：物理错题。没有自动编号ID，没有创建日期，禁止编造任何表定义之外的字段。
	字段只能是：题目文件、学段、知识点、学生答案、正确答案、基础错因、28天累计次数、错因分析。
	学段可选项只有：初中、高一。基础错因可选项只有：概念模糊、计算失误、读题失误、方法用错。
	28天累计次数是数值，由录入人按通用错题本已有次数填写。前端不得累加、不得在删除或编辑时改写其他行的该字段。
	错因分析是指令流，不是手工字段。只在 SubmitRecord 提交后由后台异步生成。编辑时禁止用 SetCellValue 改它，也禁止前端拼接五维错因。
	指令描述未要求“以JSON格式输出”，因此轮询字段就是错因分析本身。详情必须用 Markdown 主题渲染。
	题目文件存文件全局文件名。选择文件用 SelectFile；拍摄题目用 CapturePhoto；从相册选取用 SelectImage。三者都只把返回的全局文件名写入题目文件。
	图片（jpg、jpeg、png、gif、webp、bmp）用 https://www.ithinkair.com:3031/download/全局文件名 显示。
	下载一律用 https://www.ithinkair.com:3031/download/全局文件名 。
	在浏览器打开用 https://www.ithinkair.com:3031/private/全局文件名 。
	若题目文件是 html，用 private 链接放入 iframe 打开，不跳走当前应用。
	GetTableCSV 返回无标题行 CSV。按标准 CSV 解析，支持引号字段，禁止按裸逗号拆开学生答案。CSV 行序即表行序，第 1 行数据的行号是 1。
	SetCellValue 的 payload 固定为「字段名/行号/值」。解析时只切分前两段，余下整段都是值，以便答案中的分式斜杠不被截断。
	当前行初始为 0。SubmitRecord 成功后当前行变为 1。

页面顶部导航栏，固定在顶部，深海军蓝背景
	左侧是轨道环 Logo 和「物理错题分析」
	右侧标签：首页、错题诊断、错题档案、弱项光谱
	当前页标签用电光青下划线。点击标签切换页面，不刷新丢失未保存编辑前提示确认。

错题诊断
	左上大标题：错题诊断
	说明：上传题目文件并填写作答，提交后等待错误DNA生成分析
	右上按钮：错题档案，跳转到错题档案
	左栏是录入区，右栏是分析轨道。窄屏改为上下排列
	题目文件区
		未选择时显示轨道虚线框和「把题目放进诊断台」
		按钮：选择文件，调用 SelectFile，返回全局文件名后预览
		按钮：拍摄题目，调用 CapturePhoto，返回全局文件名后预览
		按钮：相册图片，调用 SelectImage，返回全局文件名后预览
		按钮：移除文件，只清空当前未提交的文件名和预览，不删表
		已选文件显示文件名；图片直接预览；html 用 private 链接放在小 iframe；其他文件显示打开与下载两个链接
	表单标题:错题诊断,表:物理错题,字段:[{字段名:题目文件,类型:文本},{字段名:学段,类型:单选项,可选项:初中,高一},{字段名:知识点,类型:文本},{字段名:学生答案,类型:文本},{字段名:正确答案,类型:文本},{字段名:基础错因,类型:单选项,可选项:概念模糊,计算失误,读题失误,方法用错},{字段名:28天累计次数,类型:数值},{字段名:错因分析,类型:指令流}]
		错因分析不出现在录入控件里
		学段、知识点、学生答案、正确答案、基础错因、28天累计次数、题目文件都必填
		28天累计次数只接受大于等于 0 的数字
		学生答案和正确答案用多行文本框
	按钮：提交诊断。缺必填项时禁用，并在字段下提示
		校验通过后调用 SubmitRecord。payload 是 JSON 文本，只含用户字段，不含错因分析
		API名称:SubmitRecord,数据源:物理错题,payload:{"题目文件":"全局文件名","学段":"所选学段","知识点":"知识点","学生答案":"学生答案","正确答案":"正确答案","基础错因":"所选基础错因","28天累计次数":数值}
		提交成功后当前行设为 1，清空右栏旧分析，显示等待态
	轮询标题:错题诊断,表:物理错题,字段:错因分析,输出到:分析轨道,等待消息:正在定位物理错误DNA，请稍候
		每 2 秒调用一次 GetCellValue，最多 60 次
		API名称:GetCellValue,数据源:物理错题/默认表格,字段名:错因分析,行号:1
		返回去空白后非空即结束轮询，用 Markdown 渲染到分析轨道
		超时后显示「分析仍在生成，可稍后在错题档案查看」，并提供「再查一次」按钮，再次按当前行轮询错因分析
	分析轨道右上角按钮：< 与 >
		API名称:GetRecordCount,数据源:物理错题/默认表格
		< 读取上一行，> 读取下一行。行号变化后，八个字段全部改由 GetCellValue 读取并回填左栏预览，错因分析刷新到右栏
		当前行小于等于 1 时，< 不可操作
		当前行大于等于记录数时，> 不可操作
		当前行为 0 时，两个按钮都不可操作
	按钮：+ 新的诊断，位于分析轨道下方。点击清空表单、预览和分析轨道，当前行设为 0，不删除记录
	等待轮询期间禁止重复提交。按钮打开题目、下载题目在已有题目文件时可用

错题档案
	左上大标题：错题档案
	说明：回看每一道物理错题，核对作答，或修正录入
	右上按钮：+ 新的诊断，跳转到错题诊断并执行清空
	搜索框：按知识点、学生答案、正确答案包含匹配，前端过滤
	筛选器：学段（全部、初中、高一）、基础错因（全部和四个可选项）、仅看高频（28天累计次数大于等于 3）
	排序：默认行序、累计次数从高到低、累计次数从低到高、知识点拼音序。排序只改变显示，不改行号
	主体用卡片，不用只读独立页
		API名称:GetTableCSV,数据源:物理错题/默认表格,字段:[题目文件,学段,知识点,学生答案,正确答案,基础错因,28天累计次数,错因分析]
		GetTableCSV 字段与表单字段一致，便于点卡片编辑
		每张卡片显示：学段、知识点、基础错因色标、28天累计次数、学生答案前 42 字、正确答案前 42 字、错因分析纯文本前 60 字、题目缩略或文件名
		卡片按钮必须全部实现：查看详情、编辑、删除、打开题目、下载题目
	查看详情
		模态层标题为知识点
		八个字段都以该行 GetCellValue 为准，其中错因分析用 Markdown 渲染
		按钮：编辑、删除、打开题目、下载题目、关闭
	编辑
		不新开页面。在右侧抽屉打开同一字段表单
		点击卡片空白处也进入编辑，当前行设为该行行号
		用 GetCellValue 逐字段填充。题目文件显示已有文件名和预览，允许重新选择文件、拍摄或相册替换
		错因分析只读，放在抽屉底部，Markdown 显示，并注明「仅新建提交后由后台生成，保存修改不会重新生成」
		按钮：保存修改。依次 SetCellValue 更新当前行的题目文件、学段、知识点、学生答案、正确答案、基础错因、28天累计次数，禁止提交错因分析，禁止用 SubmitRecord 保存修改
			API名称:SetCellValue,数据源:物理错题/默认表格,payload:字段名/当前行/值
		按钮：取消，关闭抽屉且不写表
		保存成功后刷新卡片列表
	删除
		先确认「删除这道错题？分析会一并移除」
		API名称:DeleteRecord,数据源:物理错题/默认表格,payload:行号.toString()
		删除后刷新列表和记录数。若删的是当前行，当前行设为 0
	空状态：显示轨道图标和按钮「去诊断第一道错题」

弱项光谱
	左上大标题：弱项光谱
	说明：只对照已录入的学段、知识点、基础错因和 28 天累计次数。不生成新错因，不累加次数
	右上按钮：刷新，重新 GetRecordCount 和 GetTableCSV
	API名称:GetTableCSV,数据源:物理错题/默认表格,字段:[题目文件,学段,知识点,学生答案,正确答案,基础错因,28天累计次数,错因分析]
	顶部四个对照卡片：错题总数、知识点种数、高频记录数、出现最多的基础错因
	学段对照：初中与高一两张玻璃卡，显示记录数，以及该学段里累计次数最高的三条知识点
	基础错因光谱：四种错因各一张色卡，显示数量和占比。点击色卡跳到错题档案并套上对应筛选
	知识点热列：按知识点汇总条数、累计次数最大值和合计值。合计只用于本页展示，不写回 28天累计次数
		每行一个知识点卡片，显示条数、最大累计次数、主要基础错因
		点击知识点卡片跳到错题档案，搜索框填入该知识点
	最新分析摘录
		若记录数大于 0，调用 GetCellValue 读取第 1 行错因分析，Markdown 渲染
		API名称:GetCellValue,数据源:物理错题/默认表格,字段名:错因分析,行号:1
		摘录区按钮：查看这道错题，打开第 1 行详情
		无记录时不显示摘录，提示先去错题诊断
	本页没有任何写表按钮，禁止在此页 SubmitRecord、SetCellValue、DeleteRecord

全局交互
	所有声明的按钮都要有真实功能，不能只做样式。
	列表和首页最近记录都用卡片。
	GetCellValue 得到的错因分析一律 Markdown 渲染，保留标题、列表和强调，不把原始指令描述显示给用户。
	打开题目、下载题目在文件名为空时禁用。
	接口失败时在页面内显示短错误，不跳登录，不伪造分析内容。
	操作成功后相关卡片、统计和当前行状态立即按重新取数的结果刷新。
