# 写作教学指导

这是一个面向语文教师的写作教学指导网页应用，包含首页、撰写指导、指导档案三个视图。不需要用户登录页面。不要编造表定义以外的字段：本表没有自动编号ID、没有创建日期。不要代写学生作文；生成结果供教师教学使用，由教师决定最终评价。

页面统一主题为宣纸墨韵：背景米宣纸色渐变（#f6f0e4 到 #efe4d2），主色墨蓝（#1c3d5a），强调色朱砂（#c44536），辅助青灰（#5f7d8a）。标题用衬线宋体，正文用柔和无衬线。卡片如信笺，圆角浅影，悬停上浮并出现朱砂细边。指导类型用印章式标签，六种类型各有固定底色。当前导航项用朱砂下划线。所有操作按钮的功能必须实现。必须调用宿主注入的 callAppBridge，不要用本地假数据顶替；调用失败时给出简短错误提示。

数据操作约定（全应用统一）：
	数据源一律写「写作指导/默认表格」。SubmitRecord 的 data 写「写作指导」。
	获取列表：callAppBridge({type:"GetTableCSV", data:"写作指导/默认表格", payload:"指导类型,学段,写作主题,真实情境,体裁,字数要求,学情与教学需求,参考文件"})。返回不含标题行的 CSV。按标准 CSV 解析，保留字段内逗号与换行。第 1 条数据的行号是 1，筛选、搜索、排序时必须保留原始行号。
	记录数：callAppBridge({type:"GetRecordCount", data:"写作指导/默认表格"})。
	单元格：callAppBridge({type:"GetCellValue", data:"写作指导/默认表格", payload:"字段名/行"})。
	改单元格：callAppBridge({type:"SetCellValue", data:"写作指导/默认表格", payload:"字段名/行/值"})。值里的半角「/」先换成全角「／」再提交，读回后还原。
	删除：callAppBridge({type:"DeleteRecord", data:"写作指导/默认表格", payload:行号.toString()})。删除前确认。
	新建：callAppBridge({type:"SubmitRecord", data:"写作指导", payload:表单JSON文本})。不要把「教学指导」放进 payload。提交成功后当前行是 1。
	选参考文件：callAppBridge({type:"SelectFile"})，返回全局文件名，写入「参考文件」。
	打开文件链接：https://www.ithinkair.com:3031/private/全局文件名 。下载文件链接：https://www.ithinkair.com:3031/download/全局文件名 。若文件名以 .html 结尾，在详情里用 iframe 打开 private 链接。
	「教学指导」是指令流，不是手工字段。只在 SubmitRecord 之后由后台异步生成。显示前先 GetCellValue，再用 Markdown 主题渲染。修改已有记录只用 SetCellValue 逐字段更新，不用 SubmitRecord，也不要 SetCellValue 写「教学指导」。
	当前行初始为 0。布尔字段本表没有，不要出现是/否开关。

左侧固定墨栏，不随视图滚动。
	上方朱砂方印「写」，旁侧应用名「写作教学指导」，小字「真实表达 · 个人风格」。
	导航三项：首页、撰写指导、指导档案。
	底部小字：由教师决定最终评价，不代写学生作文。

首页
	眉题：语文课堂写作工坊
	主标题：写作教学指导
	说明：按学段、主题与学情，生成可上课使用的任务设计、过程引导、三维评价、风格培养、课堂讲评或修改指导。
	主按钮：开始撰写指导，点击进入「撰写指导」，清空表单，当前行设为 0，右侧讲评卷清空。
	其下是六枚统计印章，横向排列，可点击：
		全部指导
			API名称:GetRecordCount,数据源:写作指导/默认表格
		任务设计、过程引导、评价标准、风格培养、课堂讲评、修改指导
			API名称:GetTableCSV,数据源:写作指导/默认表格,字段:[指导类型]
			按指导类型分组计数；点击某枚印章进入指导档案并套用该类型筛选
	接下来是最近指导：标题「最近指导」，说明「新提交的记录在第 1 行」。以信笺卡片显示前 5 条，没有记录时显示空状态文案和「去撰写第一份」按钮。
		API名称:GetTableCSV,数据源:写作指导/默认表格,字段:[指导类型,学段,写作主题,真实情境,体裁,字数要求,学情与教学需求,参考文件]
		取行号 1 到 5。卡片展示写作主题、指导类型印章、学段、体裁、字数要求；真实情境截取前 36 字。
		点击最近卡片查看详情，不进入编辑。详情用右侧抽屉「讲评卷」，不要另做只读页面。

撰写指导
	左上大标题：撰写指导。说明随模式变化：新建时「填写学情后生成一份教学指导」；编辑时「正在修改第 N 行，保存不会重新生成讲评」。
	右上按钮：指导档案，进入指导档案。
	左侧信笺表单，标题：写作指导。表：写作指导。字段：[{字段名:指导类型,类型:单选项,可选项:任务设计,过程引导,评价标准,风格培养,课堂讲评,修改指导},{字段名:学段,类型:文本},{字段名:写作主题,类型:文本},{字段名:真实情境,类型:文本},{字段名:体裁,类型:单选项,可选项:记叙文,议论文,说明文,应用文,其他},{字段名:字数要求,类型:数值},{字段名:学情与教学需求,类型:文本},{字段名:参考文件,类型:文本}]
		指导类型用六枚可点选印章，不要只用下拉框。选中写入指导类型。印章下各有一行短说明：任务设计是真实情境任务与达成要求；过程引导是构思、起草、修改支架；评价标准是结构、语言、思维三维量规；风格培养是真实表达与个人风格；课堂讲评是讲评流程与追问；修改指导是结合参考材料的修改路径。
		学段是文本框。快捷芯片写入文本：小学低年级、小学中年级、小学高年级、初中、高中。芯片不是新字段。
		体裁用单选标签。
		字数要求是数值框。快捷芯片写入 400、600、800。
		真实情境、学情与教学需求用多行文本。
		参考文件：按钮「选取参考材料」调用 SelectFile。选中后显示全局文件名，以及打开、下载、移除。移除只清空表单里的文件名，不删记录。
		必填：指导类型、学段、写作主题、体裁、字数要求。字数要求须为正数。未满足时按钮不可提交，并在字段下提示。
	表单底部按钮，按模式互斥，功能都要实现：
		生成教学指导：仅当前行为 0 的新建模式显示。校验通过后 SubmitRecord。payload 为 JSON 文本，只含指导类型、学段、写作主题、真实情境、体裁、字数要求、学情与教学需求、参考文件。参考文件可为空字符串。提交后当前行设为 1，进入轮询。
		保存修改：仅编辑模式显示。对当前行依次 SetCellValue 更新上述 8 个字段，不调用 SubmitRecord，不改教学指导，保存后提示「输入已更新，原教学指导未重新生成」。
		重新生成：仅编辑模式显示。用当前表单值 SubmitRecord 新建一条，不覆盖旧行。提交后当前行设为 1 并轮询。旧记录仍留在档案。
		清空重写：清空全部表单字段与右侧讲评卷，当前行设为 0，切回新建模式。
	右侧讲评卷：
		卷首显示写作主题，副信息显示学段、体裁、字数要求、指导类型。
		新建提交后轮询教学指导。轮询标题:写作指导,表:写作指导,字段:教学指导,输出到:讲评卷正文,等待消息:正在按学情生成教学指导，请稍候…
		API名称:GetCellValue,数据源:写作指导/默认表格,字段名:教学指导,行号:1
		每 2 秒轮询一次，最多 45 次。得到非空文本后用 Markdown 渲染。超时则提示稍后在档案中刷新阅读，并保留「刷新讲评」按钮再次 GetCellValue。
		讲评卷右上角按钮：复制全文（复制已得到的 Markdown 文本）、刷新讲评。
		未生成时显示引语：先写下学生真正要面对的情境。

指导档案
	左上大标题：指导档案。说明：浏览、阅读、修改或删除已有指导。
	右上按钮：+ 撰写指导，进入撰写指导并清空为新建模式。
	搜索框：按写作主题、学段、真实情境包含匹配，输入即筛选。
	筛选器：指导类型（全部加六个可选项）、体裁（全部加五个可选项）。筛选与搜索可叠加，且不丢失原始行号。
	排序：默认行号升序（最新在前）；可切换字数要求升序、降序。
	主体用信笺卡片，不用单独只读页。卡片展示并绑定的字段与表单一致：指导类型、学段、写作主题、真实情境、体裁、字数要求、学情与教学需求、参考文件。长文本在卡片上截断，数据仍保留全文。
		API名称:GetTableCSV,数据源:写作指导/默认表格,字段:[指导类型,学段,写作主题,真实情境,体裁,字数要求,学情与教学需求,参考文件]
		无匹配时显示空状态。
		点击卡片主体：进入撰写指导的编辑模式，当前行设为该行号，用 GetCellValue 逐字段回填表单。
			API名称:GetCellValue,数据源:写作指导/默认表格,字段名:指导类型,行号:当前行
			学段、写作主题、真实情境、体裁、字数要求、学情与教学需求、参考文件同样逐字段 GetCellValue。
		每张卡片的操作按钮都要实现：
			阅读全文：打开讲评卷抽屉。
			编辑：同点击卡片。
			删除：确认后 DeleteRecord，payload 为该行号.toString()，成功后刷新列表与首页统计。
			打开参考：仅参考文件非空时显示，访问 private 链接；另给下载链接。html 文件在抽屉内 iframe 打开。
	讲评卷抽屉（首页最近卡片与档案「阅读全文」共用）：
		打开时当前行设为该行。用 GetCellValue 读取八个输入字段作卷首信息，再读取教学指导并用 Markdown 渲染。
		API名称:GetCellValue,数据源:写作指导/默认表格,字段名:教学指导,行号:当前行
		教学指导为空时显示「尚未生成或仍在生成」，按钮「刷新讲评」再次 GetCellValue。
		按钮：编辑（进入编辑模式并关闭抽屉）、删除（确认后 DeleteRecord）、关闭。
		按钮标题：< 与 >，位于抽屉右上角。用 GetRecordCount 限定范围。当前行<=1 时 < 不可操作；当前行>=记录数时 > 不可操作。点击后当前行加一或减一，重新 GetCellValue 刷新卷首与教学指导。
		API名称:GetRecordCount,数据源:写作指导/默认表格

交互收尾：
	从撰写指导生成成功、保存成功或删除成功后，返回首页或档案时重新 GetRecordCount 与 GetTableCSV，统计印章和最近卡片立即更新。
	编辑模式保存用 SetCellValue；只有「生成教学指导」和「重新生成」使用 SubmitRecord，并只轮询教学指导。
	全应用不出现登录、注册、伪造的记录编号或创建日期。
