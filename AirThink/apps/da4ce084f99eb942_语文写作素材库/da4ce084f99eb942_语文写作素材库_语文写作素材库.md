# 语文写作素材库
	这是一个语文写作素材库网页应用，帮助学生存入写作素材并获得标签建议，按主题找回适用内容，依据学生明确确认记录使用情况，并生成素材小结或导出文稿。包含页面：首页、存入素材、检索素材、确认使用、素材册、小结导出。不需要用户登录页面。不要编造表定义之外的字段，不要使用模拟数据，不要新建第二张表。操作按钮对应的功能必须全部实现。
	全站只有一张表。表单标题:素材操作,表:素材操作,字段:[{字段名:操作类型,类型:单选项,可选项:存入素材,检索素材,确认使用,查看月度小结,导出素材库},{字段名:素材内容,类型:文本},{字段名:来源,类型:文本},{字段名:主题,类型:文本},{字段名:处理结果,类型:指令流,指令类型:任务智能体,指令描述:"使用技能 xiaozhi-chinese-material-library 执行{{操作类型}}。存入时处理{{素材内容}}，记录{{来源}}，建议主题、类型、情感色彩标签及写作场景，并请学生确认标签；来源不确定时标记待确认。检索时围绕{{主题}}返回最相关的素材及适用位置。确认使用时仅依据学生明确确认的{{素材内容}}记录使用。查看月度小结或导出素材库时，按技能规则生成结果；缺少跨会话统计能力时仅汇总本次会话的数据。以 Markdown 文本输出。",输出类型:文本}]
		表定义中没有自动编号ID，也没有创建日期，表单和列表都不要自行添加这些字段，也不要添加类型、情感色彩、写作场景等独立字段。这些建议只出现在处理结果的Markdown中。
		处理结果不是用户手工填写的。新建提交的JSON只含操作类型、素材内容、来源、主题。不要把处理结果放进SubmitRecord。修改已有记录时也不要SetCellValue处理结果。

		每次提交结束前禁用该次提交按钮。各页面已生成的处理结果快照不要因为另一次提交被清掉
