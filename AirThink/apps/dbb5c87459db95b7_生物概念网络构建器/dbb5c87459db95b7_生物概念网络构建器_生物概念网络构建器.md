# 生物概念网络构建器
	这是一个面向初高中生的生物概念网络构建网页应用，用单页状态切换首页、开始构建、我的网络三个视图。不包含用户登录、注册或账号页面。不要做成花草识别或拍照应用。
	应用说明：面向初高中生，围绕指定章节或主题梳理生物概念，通过分层提问、关系连线与易混概念辨析，帮助学生用自己的话构建概念网络。
	表名只有「概念网络构建」。字段只有这四个，禁止编造记录编号、ID、创建日期、状态或其他字段，因此没有需要隐藏的自动编号字段：
		学段：单选项，只能是「初中」或「高中」
		章节或主题：文本
		已有理解与疑问：文本
		概念网络引导：指令流，任务智能体，输出类型为文本。指令已配置技能 xiaozhi-biology-concept-network，按大概念、重要概念、次位概念逐步提问，提示可读成完整句子的连接词，并辨析易混概念；以 Markdown 文本输出互动引导，不直接给出供背诵的完整概念图。前端不得改写该指令，不得在浏览器里调用该技能，不得自己编写概念图内容。
	页面统一采用「概念脉络」主题，不要套用生产管理或花草识别的布局。背景为嫩绿到浅青的渐变，导航为深青绿渐变，主按钮为叶绿青，疑问点缀用琥珀黄。初中角标青绿，高中角标海蓝。卡片白底圆角，悬停时上浮并淡淡显出节点连线。字体用 PingFang SC、Microsoft YaHei 等柔和无衬线。装饰只用 CSS 或 SVG 概念节点，不使用图片字段。
	本应用没有图片、文件、语音字段，不要出现选择图片、拍照、录音、上传文档按钮，也不要展示文件下载链接。

	表操作一律调用 callAppBridge，页面里的 API名称 都按下面的方式落地：
		获取列表：callAppBridge({type:"GetTableCSV", data:"概念网络构建/默认表格", payload:"学段,章节或主题,已有理解与疑问"})。payload 不要加空格。返回不含标题行的 csv，列顺序与 payload 一致，按标准 CSV 解析引号、逗号和换行。
		提交新建：callAppBridge({type:"SubmitRecord", data:"概念网络构建", payload:"表单json文本"})。data 是表名，不是数据源。json 只包含学段、章节或主题、已有理解与疑问。
		记录数：callAppBridge({type:"GetRecordCount", data:"概念网络构建/默认表格"})
		单元格：callAppBridge({type:"GetCellValue", data:"概念网络构建/默认表格", payload:"字段名/行"})
		修改：callAppBridge({type:"SetCellValue", data:"概念网络构建/默认表格", payload:"字段名/行/值"})。只按前两个斜杠拆分，值本身可以含斜杠和换行。
		删除：callAppBridge({type:"DeleteRecord", data:"概念网络构建/默认表格", payload:行号.toString()})。payload 必须是文本。
		行号从 1 开始。GetTableCSV 原序第 n 条就是行号 n。章节或主题可能重复，不要用 GetRecordRow 按主题查找来代替行号。筛选和排序只改变显示，卡片必须记住原始行号。删除或新建成功后重新获取列表，重新编号。
		概念网络引导不是手工填写项。指令描述没有要求「以JSON格式输出」，所以提交后轮询概念网络引导本身，不要解析 JSON，不要另造字段。详情用 GetCellValue 取出后按 Markdown 渲染，不执行其中的脚本，也不要解析成力导向图或背诵概念图。
		布尔值本表用不到。统计、列表、详情、手账只能来自接口真实返回；失败时数字显示「—」，列表显示错误与重试，禁止写死假记录、假数量。

	页面顶部导航栏，深青绿渐变
		左侧是三个圆点连线的概念节点 Logo 和「生物概念网络构建器」，点击 Logo 回到首页
		右侧标签：首页、开始构建、我的网络。当前标签用琥珀色下划线标出
		三个标签都必须能切换视图
		若开始构建有未保存修改，切换视图、点 Logo 或离开当前记录前先确认

	首页
		主标题：生物概念网络构建器
		一句标题：先提问，再连线，概念网自己长出来
		说明使用应用说明原文
		按钮：开始梳理概念，点击进入「开始构建」的新建模式（当前行设为 0，清空表单和手账）
		静态三步，不可点击：选学段与章节；用自己的话写下已有理解和疑问；跟着大概念、重要概念、次位概念的提问把概念连起来
		接下来并列三张统计卡片，窄屏改为纵向
			全部概念网
				API名称:GetRecordCount,数据源:概念网络构建/默认表格
				点击进入我的网络，筛选为全部
			初中主题
				API名称:GetTableCSV,数据源:概念网络构建/默认表格,字段:[学段,章节或主题,已有理解与疑问]
				在本地统计学段等于「初中」的数量
				点击进入我的网络，筛选为初中
			高中主题
				同样一次或合并后的 GetTableCSV 中统计学段等于「高中」的数量
				点击进入我的网络，筛选为高中
			实现时统计和最近列表合并为一次 GetTableCSV 即可，字段必须是学段、章节或主题、已有理解与疑问
		最近概念网：卡片形式，不要用表格。取 GetTableCSV 原序前 4 条（新提交记录在第 1 行），不要打乱顺序
			每张卡片显示学段角标、章节或主题、已有理解与疑问摘要（最多三行；空白则显示「还没写下已有理解」）
			点击卡片打开概念详情层，详情行等于该条原始行号
			没有记录时显示空状态和按钮「去构建第一条」，点击进入开始构建的新建模式
			不要在首页放编辑、删除，避免和学生的阅读入口抢操作；删除放在详情层

	开始构建
		窄屏时表单在上、手账在下；宽屏左右分栏
		左栏标题：从这里出发
		左栏说明：写下学段、章节，以及你已经知道的和还困惑的。引导会提问，不会直接给你一张供背诵的概念图
		右栏标题：概念引导手账
		手账上方静态提示：将按大概念、重要概念、次位概念提问，为每条连线提示能读成完整句子的连接词，并辨析易混概念
		三个静态标签，不可点击：大概念、重要概念、次位概念
		试试这些主题，只填充输入框，不写入表、不自动提交
			初中：细胞是生命活动的基本单位、光合作用、人体的消化与吸收
			高中：细胞膜的结构与功能、有丝分裂、基因的自由组合定律
			点击后当前行设为 0，切到新建模式，填入学段和章节或主题，保留已写的已有理解与疑问，清空手账
		表单标题:概念网络构建,表:概念网络构建,字段:[{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:章节或主题,类型:文本},{字段名:已有理解与疑问,类型:文本}]
			学段是两个互斥选项，不能自由输入
			章节或主题单行，去掉首尾空格后必填
			已有理解与疑问多行，允许空白。占位文案：我知道叶绿体和光合作用有关，但不清楚光反应和暗反应怎么连
			概念网络引导不作为输入框出现
		按钮标题：生成引导
			只在新建模式（当前行为 0）显示
			学段未选或章节或主题为空时禁用，并提示补全
			点击调用 SubmitRecord。例如 payload：{"学段":"初中","章节或主题":"光合作用","已有理解与疑问":""}
			API名称:SubmitRecord,表:概念网络构建,payload:学段、章节或主题、已有理解与疑问的json文本
			提交后当前行是 1
			提交中禁用按钮。失败则提示「提交没有成功，请检查后重试」，保留已填内容
		轮询标题:概念网络构建,表:概念网络构建,字段:概念网络引导,输出到:概念引导手账,等待消息:正在按大概念、重要概念、次位概念为你编排提问……
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:概念网络引导,行号:当前行
			提交成功后立即轮询。每 2 秒一次。空、null 或纯空白继续等待，等待时用手账区显示等待消息，并用三个概念节点依次点亮的 CSS 动画，不要提前展示编造的引导
			得到非空文本后停止轮询，概念引导手账使用 Markdown 格式呈现：浅色纸感背景，左侧青绿竖线，标题、列表、引用、表格清晰可读
			连续失败 3 次，或超过 90 秒仍为空：停止轮询，提示可稍后刷新
		按钮标题：刷新引导
			按当前行重新 GetCellValue；若仍为空，重新开始轮询
		按钮标题：保存修改
			仅当前行大于等于 1 时显示
			依次设置当前行的学段、章节或主题、已有理解与疑问
			API名称:SetCellValue,数据源:概念网络构建/默认表格,payload:字段名/行/值
			不要对概念网络引导调用 SetCellValue，修改不要用 SubmitRecord
			成功提示：已保存。修改已有理解不会自动重写已生成的引导；若要新的提问，请再生成一条
		按钮标题：再生成一条
			仅当前行大于等于 1 时显示
			先确认：将按当前内容新建一条概念网，原来的记录会保留。确定吗？
			确认后用当前三个字段 SubmitRecord，不删除原记录
			提交后当前行是 1，并按同一规则轮询新的概念网络引导
		按钮标题：删除本条
			仅当前行大于等于 1 时显示
			确认文案：确定删除这条概念网络吗？删除后不能恢复。
			API名称:DeleteRecord,数据源:概念网络构建/默认表格,payload:当前行.toString()
			成功后清空表单与手账，当前行设为 0，刷新记录数和列表
		按钮标题：清空重来
			有未保存修改时先确认
			清空表单及概念引导手账，当前行设为 0，回到新建模式
		按钮标题：<
			位于概念引导手账右上角，读取上一行
		按钮标题：>
			位于概念引导手账右上角，读取下一行
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:学段,行号:目标行
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:章节或主题,行号:目标行
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:已有理解与疑问,行号:目标行
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:概念网络引导,行号:目标行
			四个字段都要读。引导非空则 Markdown 显示；为空则进入等待并轮询
			有未保存修改时，离开前先确认
		API名称:GetRecordCount,数据源:概念网络构建/默认表格
		当前行初始是 0
		当前行小于等于 1 时，< 不可操作
		当前行为 0 且记录数为 0 时，> 不可操作
		当前行为 0 且记录数大于等于 1 时，> 可操作，点击进入第 1 行
		当前行大于等于记录数且当前行不为 0 时，> 不可操作
		进入已有行后变为编辑模式：显示保存修改、再生成一条、删除本条，隐藏生成引导
		当前行为 0 且尚未生成时，手账显示：填写左侧内容并生成引导后，提问会出现在这里

	我的网络
		左上大标题：我的概念网
		说明：回看每一次梳理，改一改自己的理解，或删掉不需要的记录
		右上按钮：+ 新建一条，进入开始构建的新建模式，当前行设为 0 并清空表单和手账
		搜索框：章节或主题或已有理解与疑问包含关键字即显示，输入时即时筛选
		筛选器：全部、初中、高中。与搜索同时生效。首页统计卡片跳转时带上对应筛选
		排序：最新在前（默认，保持原始行号顺序）、章节名称（中文 localeCompare）。排序不改变原始行号
		主体用卡片，不要表格，也不要另做只读页面
			API名称:GetTableCSV,数据源:概念网络构建/默认表格,字段:[学段,章节或主题,已有理解与疑问]
			卡片字段与可编辑表单一致：学段、章节或主题、已有理解与疑问
			每张卡片按钮：查看、编辑、删除。编辑和删除必须阻止冒泡
			点击卡片或查看：打开概念详情层
			编辑：进入开始构建，当前行等于该卡片原始行号，GetCellValue 填充三个可编辑字段，并读取概念网络引导显示在手账，进入编辑模式
			删除：确认后
				API名称:DeleteRecord,数据源:概念网络构建/默认表格,payload:行号.toString()
				成功后重新 GetTableCSV 和 GetRecordCount
			无匹配时显示「没有找到对应的概念网」
			一条都没有时显示空状态和「去构建第一条」

	概念详情层
		首页最近卡片和我的网络的查看共用这个弹出层，不为只读内容单独建页面
		标题是章节或主题，角标是学段，已有理解与疑问用引用样式
		概念引导用 Markdown 显示
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:学段,行号:详情行
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:章节或主题,行号:详情行
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:已有理解与疑问,行号:详情行
			API名称:GetCellValue,数据源:概念网络构建/默认表格,字段名:概念网络引导,行号:详情行
		概念网络引导为空时，显示等待文案并每 2 秒轮询，直到非空或超时
		按钮：编辑这条、删除、关闭，三个都必须实现
			编辑这条：关闭详情层，按我的网络的编辑规则进入开始构建
			删除：确认后 DeleteRecord，关闭详情层并刷新；若开始构建正在看同一行，则清空重来
			关闭：只关闭详情层
	每次进入视图，以及提交、保存、删除成功后，刷新统计、最近卡片和我的网络。
	各页面保持同一套概念脉络主题，卡片有悬停效果。操作按钮对应的功能必须要都实现。
