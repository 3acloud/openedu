# 地理读图教练

这是一个面向初高中学生的地理读图教练网页应用，帮助学生看着地图识别图名、图例、比例尺、方向和关键数值，并结合自己的作答获得逐步提示与错因分析。页面只有三处：首页「探险起点」、读图工坊、练习手账。不要登录页，不要编造表里没有的字段。全站统一「课堂地图册」主题，所有写出的按钮都必须真正可用。

表只有一张：地理读图。字段只允许这些，禁止自行增加记录编号、计划编号、创建日期、识别时间等字段：
学段（单选项：初中、高中）、是否选考地理（布尔，值只用「是」或「否」）、题目与问题（文本）、地图文件（文本，存全局文件名）、我的作答（文本）、读图指导（指令流，任务智能体，文件字段是地图文件，输出类型文本）。
读图指导不是用户填写的。指令描述是：使用技能 xiaozhi-geography-map-reader，针对对应学段学生的题目与问题、高中是否选考地理、学生已有作答进行指导；先引导识别图名、图例、比例尺、方向和关键数值，再依据图中证据逐步提示；若有作答则分析具体错因；不要在学生尝试前直接给出原题答案；以中文 Markdown 输出。前端不要调用该技能，也不要自己生成答案。提交后由后台异步写入读图指导。指令描述没有要求「以JSON格式输出」，因此轮询字段就是「读图指导」本身。

数据源一律写：地理读图/默认表格。提交时表名写：地理读图。

## 主题

背景是暖纸色 #F4EFE4，上面用极淡的经纬网线。主色是海图蓝 #0E4D6C，辅色是河流青 #1F8A70，强调色是指南针金 #C6A15B，错因与删除用地图钉红 #C45C4A。标题用衬线字，正文用清晰的无衬线中文黑体。卡片像折过的地图页，圆角，浅阴影，悬停时轻微抬起并亮出金色边。按钮像地图钉，悬停加深。学段用丝带徽章：初中为青色，高中为蓝色。空状态画一个小指南针，并写一句鼓励学生先看图名和图例的话，不要放假数据。

页面顶部一条固定导航，海图蓝底。
左侧是金色指南针图标和「地理读图教练」。
右侧标签：探险起点、读图工坊、练习手账。当前标签用金色下划线。窄屏时标签收成菜单，仍能跳转。

## 探险起点

主标题：地理读图教练。说明：拍下或上传地图，写下题目和你自己的判断，教练按图给提示，不替你提前公布答案。
主按钮：开始读图。点击进入读图工坊的新建状态：当前行设为 0，清空全部表单和指导区。

其下四张并列统计卡，点击后跳到练习手账并带上对应筛选：
总练习数。调用 callAppBridge({type:"GetRecordCount", data:"地理读图/默认表格"})。
初中练习数、高中练习数。调用 callAppBridge({type:"GetTableCSV", data:"地理读图/默认表格", payload:"学段,是否选考地理,题目与问题,地图文件,我的作答"})，csv 无标题行，按学段筛选计数。
已写作出答数。同一份 csv 中「我的作答」非空的行数。

再下方是「最近读图」。因为新建提交后当前行是 1，最新记录在行号 1。取上面这份 csv 的前 5 行，做成卡片，不要用空表格占位。每张卡片显示：学段徽章、是否选考地理（是/否）、题目与问题（最多两行）、我的作答摘要（没有则写「还没写作出答」）、地图缩略图。地图文件是全局文件名，图片地址是 https://www.ithinkair.com:3031/download/全局文件名 。再对这 5 行各自调用 callAppBridge({type:"GetCellValue", data:"地理读图/默认表格", payload:"读图指导/行号"})，有内容则徽章为「指导已生成」，空则「生成中」。点击卡片查看详情：打开练习手账的详情面板，当前行设为该行号，用 GetCellValue 逐字段加载。无记录时不显示假卡片，只保留开始读图按钮。

静态小贴士三张，只讲读图方法，不涉及任何具体题目答案：先读图名，再定方向，最后对图例和数值。

## 读图工坊

左上标题：读图工坊。说明：先自己看图、写判断，再请教练顺着图里的证据提示你。
右上按钮：练习手账，跳转到练习手账。

这是左右分栏的地图桌。窄屏改为上图下表单。左侧是地图灯箱，右侧是作答纸和教练纸。

地图灯箱初始是虚线框和文案「把课本或试卷上的地图放进来」。有文件后显示预览。三个按钮都必须实现：
拍摄地图：callAppBridge({type:"CapturePhoto"})，返回的全局文件名写入地图文件并立刻预览。
相册选图：callAppBridge({type:"SelectImage"})，同样写入并预览。
选择文件：callAppBridge({type:"SelectFile"})，返回全局文件名。图片仍用下载地址预览；pdf 等非图片显示文件名，并提供「在浏览器打开」。
清除地图：只清空本地预览和地图文件字段，不删表格记录。
在浏览器打开的地址是 https://www.ithinkair.com:3031/private/全局文件名 。下载地址是 https://www.ithinkair.com:3031/download/全局文件名 。若文件名以 .html 结尾，用 iframe 打开 private 链接，不要当成图片。

右侧表单标题是地理读图，表是地理读图。表单字段与主体列表字段一致，只有：
学段：单选，初中或高中，必填，默认不预选，避免误提交。
是否选考地理：开关。学段为高中时显示并必选，值为「是」或「否」。学段为初中时隐藏开关，提交值固定为「否」，并注明初中不区分选考。
题目与问题：多行文本，必填，占位「把题目原文和要求写在这里」。
地图文件：不手输文件名，只显示当前全局文件名，值来自上面三个选择按钮。
我的作答：多行文本，可空。旁注：建议先写下你的判断；留空时教练只给读图步骤，不直接给原题答案。
读图指导不出现在输入表单里，也不放进提交 JSON。

灯箱下方有一张「提交前自检」清单，仅供学生自己勾选，不入库：我看过图名、我确认了方向、我查过图例和比例尺、我圈出了关键数值。勾选状态不参与提交。

新建状态（当前行为 0）主按钮：请教练读图。学段、题目与问题、地图文件都有值才可点。点击后用 JSON 文本提交，布尔必须是「是」或「否」，不要传 true/false，不要包含读图指导：
callAppBridge({type:"SubmitRecord", data:"地理读图", payload:"表单JSON"})
提交后当前行设为 1。然后轮询，不要在前端写答案。每 2 秒调用一次 callAppBridge({type:"GetCellValue", data:"地理读图/默认表格", payload:"读图指导/1"})。等待时指导区显示：「教练正在看你的地图。请先自己找出图名、方向、图例和关键数值。」最多轮询 30 次。得到非空文本后，用与主题一致的 Markdown 渲染到「教练指导」区。超时则提示稍后到练习手账刷新查看，并留下「刷新指导」按钮。提交成功后重新拉取列表，因为新记录会使行号变化。

编辑状态从练习手账或最近卡片进入。当前行设为该行号。用 GetCellValue 按字段填充：payload 分别为「学段/行号」「是否选考地理/行号」「题目与问题/行号」「地图文件/行号」「我的作答/行号」「读图指导/行号」。地图按全局文件名预览。读图指导只读，Markdown 显示。
保存修改按钮：依次调用 callAppBridge({type:"SetCellValue", data:"地理读图/默认表格", payload:"字段名/行号/值"})，只更新学段、是否选考地理、题目与问题、地图文件、我的作答。不要用 SubmitRecord 修改，不要对读图指导调用 SetCellValue。保存后提示：修改不会自动重写教练指导。
重新请教练读图按钮：用当前表单值再次 SubmitRecord，当作新的一次练习；提交后当前行变为 1，并按上面的规则轮询读图指导。旧记录保留。
清空重来按钮：当前行设为 0，清空表单、预览和指导区，回到新建状态，不删除已有记录。
刷新指导按钮：对当前行调用 GetCellValue 读取读图指导并 Markdown 显示。当前行为 0 时该按钮不可用。

## 练习手账

左上标题：练习手账。说明：每一次读图都留在这里，可以回看指导、修改作答或删除。
右上按钮：新的读图。进入读图工坊新建状态。

上方搜索框：按题目与问题、我的作答包含关键字筛选。筛选器：学段（全部、初中、高中）、是否选考地理（全部、是、否）、指导状态（全部、已生成、未生成）。筛选在已获取的数据上完成，改变筛选后重新获取。

主体不要做成只能看的单独页面。用卡片列表充当主体表格，卡片字段必须与表单字段一致。获取：
callAppBridge({type:"GetTableCSV", data:"地理读图/默认表格", payload:"学段,是否选考地理,题目与问题,地图文件,我的作答"})
返回 csv 不含标题行。第 1 条数据对应行号 1，以此类推。题目和作答里可能有逗号或换行，按 CSV 引号规则解析，禁止粗暴 split 截断题目。
每张卡片显示学段、是否选考地理、题目与问题、我的作答摘要、地图缩略图。指导状态通过 callAppBridge({type:"GetCellValue", data:"地理读图/默认表格", payload:"读图指导/行号"}) 判断。
点击卡片主体：查看详情，不是直接丢弃未保存内容。若工坊有未保存修改，先确认。
每张卡片三个按钮都要实现：
查看指导：打开本页详情面板。
修改：进入读图工坊编辑状态并加载该行。
删除：确认后调用 callAppBridge({type:"DeleteRecord", data:"地理读图/默认表格", payload:行号.toString()})。payload 必须是文本。删除后重新 GetTableCSV 和 GetRecordCount，丢弃旧行号。

详情面板在本页右侧或全屏抽屉中打开，不新建路由页面。加载方式是逐字段 GetCellValue，不要只用 csv 里的截断文本。显示地图大图、五个业务字段、以及读图指导的 Markdown。面板按钮：
在浏览器打开地图，访问 private 链接。
下载地图，访问 download 链接。
修改这条，进入编辑状态。
删除这条，同删除按钮。
刷新指导，再次 GetCellValue。
关闭，只关面板。
详情里的上一张、下一张：行号减一或加一，再用 GetCellValue 加载。先 callAppBridge({type:"GetRecordCount", data:"地理读图/默认表格"})。当前行小于等于 1 时上一张不可用；当前行大于等于记录数时下一张不可用。

## 行号与通用规则

当前行初始为 0。只有 SubmitRecord 成功后才把当前行设为 1。查看、编辑、删除使用当时 csv 顺序对应的行号。提交或删除后立即刷新，不得沿用过期行号。
需要按字段值查找行时才用 callAppBridge({type:"GetRecordRow", data:"地理读图/默认表格", payload:"字段名/值"})，行号从 1 开始。题目可能重复，优先使用列表行号。
布尔只显示和提交「是」「否」。
读图指导的详情一律 GetCellValue 后按 Markdown 主题渲染，不要当纯文本把标记符直接堆在页面上。
任何页面都不要出现用户登录、注册、权限角色。不要调用表中不存在的字段。不要把读图指导当成手工输入。不要在学生提交前，用前端文案泄露原题答案。
