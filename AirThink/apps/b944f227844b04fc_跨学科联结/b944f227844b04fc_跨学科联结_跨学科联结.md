# 跨学科联结

这是一个跨学科联结网页应用，包含首页「联结星图」、发起探索、探索档案三个导航页面，以及从列表进入的探索详情。不包含登录页。页面统一采用「午夜书房侦探笔记」主题：墨蓝 `#1B2A4A`、暖杏 `#E8A838`、纸色 `#F6F0E6`、松绿点缀 `#2F6F62`。背景为纸色微渐变，标题用衬线字体（Noto Serif SC 或系统衬线），正文用无衬线。卡片白底、左侧暖杏细条，悬停轻微上浮并加深阴影。学科用彩色小芯片展示。所有操作按钮的功能必须实现。本表没有自动编号 ID 和创建日期字段，不要编造这些字段，不要做隐藏占位。字段名必须与表定义完全一致。

页面顶部导航栏，墨蓝背景
	左侧显示罗盘图标和「跨学科联结」
	右侧标签：联结星图、发起探索、探索档案
	当前页标签用暖杏下划线标出

数据约定
	表名：联结探索
	数据源：联结探索/默认表格
	字段仅限：学段、主题、好奇的问题、探索学科、已有发现、自述联结、探索引导与记录
	学段是单选项，可选项只有：小学高段、初中、高中
	探索学科是多选项，可选项只有：历史、地理、语文、数学、物理、化学、生物、政治、其他。提交和设值时用英文逗号连接，读取时按英文逗号拆成芯片
	已有发现、自述联结允许为空。学段、主题、好奇的问题必填，探索学科至少选一项。校验不通过时不调用提交或设值
	探索引导与记录是指令流，不是用户手工填写的。不要把它放进可编辑输入框，不要对它调用 SetCellValue
	指令描述未指定「以JSON格式输出」，因此轮询字段就是探索引导与记录。内容用 Markdown 主题渲染，不把原文当纯文本预格式化堆砌
	GetTableCSV 返回不含标题行的 csv。按请求字段顺序、按标准 CSV 规则解析（支持引号字段）。csv 第 1 行对应行号 1，筛选和搜索时必须保留原始行号，编辑和删除都用原始行号
	新建提交后当前行是 1。当前行初始是 0
	布尔值本表不使用

首页「联结星图」
	主标题：跨学科联结
	说明：从一个真实问题出发，把历史、科学、语言和数学连成你自己的侦探笔记
	主按钮：发起一次联结，点击进入「发起探索」页面
	并列四张统计卡片，各用不同点缀色
		探索总数
			API名称:GetRecordCount,数据源:联结探索/默认表格
		小学高段、初中、高中各一张
			API名称:GetTableCSV,数据源:联结探索/默认表格,字段:[学段]
			按学段精确匹配计数。无记录时显示 0
	接下来是学科热度条：统计探索学科里各学科被选中的次数，用短横条从多到少排列，没有数据时显示「还没有学科足迹」
		API名称:GetTableCSV,数据源:联结探索/默认表格,字段:[探索学科]
		一条记录里重复学科只计一次
	最近探索列表，标题：最近的侦探笔记。卡片形式，最多 5 条
		API名称:GetTableCSV,数据源:联结探索/默认表格,字段:[学段,主题,好奇的问题,探索学科,已有发现,自述联结,探索引导与记录]
		新记录在第 1 行，取前 5 行。每张卡片显示学段芯片、主题、好奇的问题（超过 42 字截断）、探索学科芯片、引导状态（探索引导与记录非空为「笔记已生成」，否则为「整理中」）
		点击卡片查看详情，进入探索详情，当前行设为该卡片原始行号，并加载该行
		无记录时不显示空表，显示引导文案和按钮「开始第一则联结」，点击进入发起探索

「发起探索」页面
	左上大标题：发起探索
	说明：写下你真正好奇的问题。引导由后台整理，信息不完整也会留待你以后补充，不会替你编造发现
	右上按钮：查看档案，进入探索档案
	表单标题:联结探索,表:联结探索,字段:[{字段名:学段,类型:单选项,可选项:小学高段,初中,高中},{字段名:主题,类型:文本},{字段名:好奇的问题,类型:文本},{字段名:探索学科,类型:多选项,可选项:历史,地理,语文,数学,物理,化学,生物,政治,其他},{字段名:已有发现,类型:文本},{字段名:自述联结,类型:文本},{字段名:探索引导与记录,类型:指令流}]
		学段用三个可选卡片，单选
		主题单行输入，占位：例如 一座桥、一场雨、家里的冰箱
		好奇的问题多行输入，占位：我真正想搞懂的是……
		探索学科用可多选芯片
		已有发现、自述联结为多行输入。自述联结占位：我自己觉得这些学科是这样连上的……
		探索引导与记录不在表单里编辑。提交前该区域显示「提交后，这里会出现 Markdown 侦探笔记」
	按钮：生成侦探笔记。校验通过后才可点
		使用 callAppBridge({type:"SubmitRecord", data:"联结探索", payload:表单JSON文本}) 提交
		JSON 只含学段、主题、好奇的问题、探索学科、已有发现、自述联结，不含探索引导与记录
		提交成功后当前行设为 1，按钮进入等待态，不可重复提交
		轮询标题:联结探索,表:联结探索,字段:探索引导与记录,输出到:侦探笔记,等待消息:正在按你的学段整理各学科视角和追问，不会替你编造发现
		轮询用 callAppBridge({type:"GetCellValue", data:"联结探索/默认表格", payload:"探索引导与记录/1"})，每 2 秒一次，最多 30 次
		得到非空文本后，用 Markdown 主题显示在表单下方「侦探笔记」区，并刷新首页统计会在再次进入首页时重新请求
		超时后停止轮询，显示「还在整理」，按钮「继续等待」只继续轮询当前行，不得再次 SubmitRecord
	按钮：清空重写。清空六个输入和侦探笔记显示，当前行设为 0，不删除已提交记录
	提交成功后额外显示按钮：去档案看看，进入探索档案

「探索档案」页面
	左上大标题：探索档案
	说明：你的每一次跨学科立案都留在这里
	右上按钮：+ 新的联结，进入发起探索并清空表单，当前行设为 0
	搜索框：按主题或好奇的问题包含匹配，输入即筛选
	筛选器：学段（全部、小学高段、初中、高中）、探索学科（全部及九个学科，命中字段中包含该学科即可）
	按钮：清除筛选，恢复全部
	主体用卡片列表，不用单独只读表页。卡片展示字段与表单字段一致：学段、主题、好奇的问题、探索学科、已有发现、自述联结、探索引导与记录
		API名称:GetTableCSV,数据源:联结探索/默认表格,字段:[学段,主题,好奇的问题,探索学科,已有发现,自述联结,探索引导与记录]
		已有发现、自述联结超过 60 字截断。探索引导与记录在卡片上只显示状态芯片，不贴全文
		卡片按行号升序，即最新在前。支持按主题笔画或按学段分组切换，默认最新在前
		无匹配时显示「没有对应的探索」
	每张卡片操作按钮都要实现
		查看详情：进入探索详情，当前行=该行行号
		编辑：打开编辑层，当前行=该行行号，逐字段 GetCellValue 填入
		删除：先确认「删除后这则联结和侦探笔记都会去掉」，确认后 callAppBridge({type:"DeleteRecord", data:"联结探索/默认表格", payload:行号.toString()})，然后重新 GetTableCSV
	点击卡片主体等同查看详情

编辑层
	标题：修改探索
	只编辑学段、主题、好奇的问题、探索学科、已有发现、自述联结。探索引导与记录在层内只读，用 Markdown 显示；若为空显示「这则笔记尚未生成」
	打开时当前行=目标行号，逐个调用
		API名称:GetCellValue,数据源:联结探索/默认表格,字段名:对应字段,行号:当前行
		payload 格式为「字段名/行号」
	按钮：保存修改
		依次 callAppBridge({type:"SetCellValue", data:"联结探索/默认表格", payload:"字段名/行号/值"}) 更新上述六个字段
		行号写入 payload 前 toString()。不要 SetCellValue 探索引导与记录，不要用 SubmitRecord 提交修改
		保存后关闭编辑层并刷新档案卡片。提示：来源已更新；已生成的侦探笔记不会因此自动重写，若要按新内容重新整理，请新建一则联结
	按钮：取消，关闭且不写表

探索详情
	不是导航项，由首页最近卡片或档案卡片进入
	左上返回：来自首页则回联结星图，来自档案则回探索档案
	版式左右分栏，窄屏改为上下
		左侧「学生案卷」：学段、主题、好奇的问题、探索学科芯片、已有发现、自述联结
		右侧「侦探笔记」：探索引导与记录，Markdown 主题显示
	数据来自逐字段 GetCellValue，数据源:联结探索/默认表格，行号:当前行。字段为学段、主题、好奇的问题、探索学科、已有发现、自述联结、探索引导与记录
	若探索引导与记录为空，显示等待文案并按发起探索相同间隔轮询该当前行，直到有内容或用户离开页面。离开即停止轮询
	右上角按钮：< 和 >
		API名称:GetRecordCount,数据源:联结探索/默认表格
		< 读取上一行，当前行减 1 后重新 GetCellValue
		> 读取下一行，当前行加 1 后重新 GetCellValue
		当前行<=1 时 < 不可操作
		当前行>=记录数时 > 不可操作
	按钮：编辑这则，打开同一编辑层
	按钮：删除这则，确认后 DeleteRecord，payload 为当前行.toString()。删除后记录数减 1；若已无记录则回档案，否则当前行不超过新的记录数并重新加载
	详情页不提供把指令流另存成用户编造结论的输入

交互与实现约束
	每个页面进入时重新请求该页所需的 GetRecordCount 或 GetTableCSV，从编辑、删除、新建返回时也要刷新
	callAppBridge 的 data、payload 必须按上述类型使用。GetTableCSV 的 payload 是逗号分隔字段名，且字段都属于联结探索
	关联表：本表无关联表字段，不要额外 GetTableCSV 其他表
	不要实现登录、不要新增表、不要新增字段、不要显示未定义字段
	操作失败时在页面内给出短提示，不要静默失败
	空的已有发现和自述联结保持空白，界面不得自动补写示例发现或示例联结冒充学生内容
