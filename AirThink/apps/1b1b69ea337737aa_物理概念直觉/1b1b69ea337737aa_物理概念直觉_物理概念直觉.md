# 物理概念直觉

这是一个面向中学物理学习的网页应用，名字叫「物理概念直觉」。学生先填概念，再由后台按生活经验、实验想象、公式推导的顺序生成直觉讲解。页面要让人感到「先别急着套公式，先把感觉点亮」。不需要登录页。不要编造表里没有的字段，本表没有自动编号ID，也没有创建日期。

统一主题「晨光实验室」：暖纸色背景 `#F6F3EC`，带很淡的方格，像实验记录纸。顶部导航是深海蓝 `#16324F`。点睛色用琥珀金 `#E8A317`，表示顿悟。三步各有固定色，全站不要换：生活经验是陶土橙 `#D4764E`，实验想象是湖青绿 `#1F8A70`，公式推导是靛蓝 `#3D5A80`。卡片白底、圆角、轻阴影，悬停上浮并出现淡金边。字体用柔和无衬线。按钮、卡片、列表项的悬停和点击都要有反馈。所有出现的按钮都必须真正可用。

数据表只有一张：表名「物理概念」。数据源固定写「物理概念/默认表格」。字段只有：概念名称（文本）、概念类型（单选项，只能是「有明确生活体验」「抽象但可想象」「已背公式但不理解」）、已记公式（文本）、直觉讲解（指令流，不是用户填写的）。直觉讲解由后台在 SubmitRecord 之后异步生成。指令描述没有要求「以JSON格式输出」，所以提交后轮询「直觉讲解」本身。详情用 Markdown 主题显示，前端不得自己编造物理讲解。

操作表一律走下面这些桥，不要换成别的接口：
- 取不含标题行的 CSV：`callAppBridge({type:"GetTableCSV", data:"物理概念/默认表格", payload:"概念名称,概念类型,已记公式"})`。需要看直觉讲解时不要靠 CSV，改用 GetCellValue。
- 新建：`callAppBridge({type:"SubmitRecord", data:"物理概念", payload:表单JSON文本})`。JSON 只含概念名称、概念类型、已记公式。提交后当前行是 1，新记录出现在第 1 行。
- 记录数：`callAppBridge({type:"GetRecordCount", data:"物理概念/默认表格"})`。
- 按名称查行：`callAppBridge({type:"GetRecordRow", data:"物理概念/默认表格", payload:"概念名称/值"})`，行号从 1 开始。
- 删除：`callAppBridge({type:"DeleteRecord", data:"物理概念/默认表格", payload:行号.toString()})`。
- 读单元格：`callAppBridge({type:"GetCellValue", data:"物理概念/默认表格", payload:"字段名/行号"})`。
- 改已有记录：对当前行的概念名称、概念类型、已记公式依次 `callAppBridge({type:"SetCellValue", data:"物理概念/默认表格", payload:"字段名/行号/值"})`，不要用 SubmitRecord 冒充修改。已记公式可能含斜杠，值取第二个斜杠之后的全部文本。不要对直觉讲解调用 SetCellValue。
- 列表先取完整 CSV，给每条记下原始行号（第 1 条数据行号为 1）。搜索和筛选只改变显示，不改变行号。编辑、删除、查看都用这个行号。

页面顶部固定导航。左侧是一枚小灯泡图标和「物理概念直觉」。右侧三个标签：首页、直觉工坊、概念库。当前页标签用琥珀金下划线。窄屏时标签收成菜单，功能不减。

## 首页

主标题：物理概念直觉。说明：先建立直觉，再看懂公式。副文案：生活里碰一碰，脑子里做个实验，最后才把公式翻译成人话。
主按钮「+ 建立一个概念直觉」，跳到直觉工坊，并清空表单，当前行设为 0。

接着是一条不可打乱的三步光带，只作说明，不写假的物理结论：1 生活经验，2 实验想象，3 公式推导。光带末端有一枚小标记「还要做一次迁移验证」。三步用各自的固定色。

再下面并排四张统计卡，数字来自接口，不要写死：
- 概念总数：`callAppBridge({type:"GetRecordCount", data:"物理概念/默认表格"})`。
- 生活体验型、可想象型、公式未通型：`callAppBridge({type:"GetTableCSV", data:"物理概念/默认表格", payload:"概念类型"})`，分别统计三个可选项的数量。卡片颜色对应三步色。点击某一张类型卡，跳到概念库并带上该类型筛选。

然后是「最近点亮的概念」。因为新提交的记录在第 1 行，取 CSV 前 4 条。接口：`callAppBridge({type:"GetTableCSV", data:"物理概念/默认表格", payload:"概念名称,概念类型,已记公式"})`。用卡片，不要用表。每张卡片显示概念名称、类型徽章、已记公式（空则写「还没记下公式」）。点击卡片进入概念库并打开该行详情：用该行号 `callAppBridge({type:"GetCellValue", data:"物理概念/默认表格", payload:"直觉讲解/行号"})`，Markdown 显示。没有记录时显示空状态：「还没有概念。先从一个你背过、但说不清的公式开始。」并给出同一个新建按钮。

## 直觉工坊

左上大标题：直觉工坊。说明：选一种概念类型，严格按生活经验、实验想象、公式推导等待讲解，不能把顺序倒过来展示。
右上按钮「去概念库」，跳到概念库。

左侧是建立表单，标题：建立一个概念直觉。表：物理概念。字段与主体列表一致，便于之后点卡片编辑：概念名称、概念类型、已记公式。没有隐藏的编号或日期字段。
- 概念名称：单行文本，占位「例如：惯性、压强、欧姆定律」。必填。
- 概念类型：不要用枯燥下拉框。做成三张可选入口卡，文案分别是「生活里体验过」「抽象，但想得见」「公式会背，意思不懂」。提交值必须原样分别是「有明确生活体验」「抽象但可想象」「已背公式但不理解」。必须单选。
- 已记公式：多行文本，占位「会背就写上，例如 F=ma；不会就留空」。当类型是「已背公式但不理解」时必填，否则可空。
- 主按钮「点亮直觉」：校验通过才可点。点击后把表单 JSON 提交：`callAppBridge({type:"SubmitRecord", data:"物理概念", payload:"{\"概念名称\":\"...\",\"概念类型\":\"...\",\"已记公式\":\"...\"}"})`。提交后当前行设为 1。
- 次按钮「清空」：清空三个输入和右侧讲解，当前行设为 0，停止轮询。

右侧是讲解舞台，初始显示三盏未点亮的灯：生活经验、实验想象、公式推导，以及一句「提交后，讲解会按这个顺序出现」。
提交后立刻进入等待，不要先显示编造的课文。等待文案：「正在按生活经验 → 实验想象 → 公式推导建立直觉，请稍候」。三盏灯按这个顺序依次亮起，只表示等待进度。
轮询：每 2 秒 `callAppBridge({type:"GetCellValue", data:"物理概念/默认表格", payload:"直觉讲解/1"})`，直到文本非空。轮询标题：物理概念直觉。表：物理概念。字段：直觉讲解。输出到：讲解舞台。等待消息：正在建立直觉…。超过约 60 秒仍为空，停止轮询并提示「讲解还在生成，可稍后在概念库打开这条记录」，不要伪造内容。
生成结束后，用 Markdown 主题渲染直觉讲解。舞台顶部重复显示本次的概念名称、类型徽章、已记公式条（等宽字体；为空则写「还没有记下公式，先从体验出发」）。Markdown 区域保持后台原文，不重组、不补写物理结论。若文中能看出生活经验、实验想象、公式推导、迁移验证，可用侧边四个小锚点帮助跳读；认不出就不要硬拆。

讲解舞台右上角有「<」「>」。
- `<` 读上一行，`>` 读下一行。行号用当前行，不是筛选后的序号。
- 两个方向都用 GetCellValue 读取概念名称、概念类型、已记公式、直觉讲解，并回填左侧表单（此时是浏览，不是新建）。
- 记录数用 `callAppBridge({type:"GetRecordCount", data:"物理概念/默认表格"})`。
- 当前行初始为 0。当前行小于等于 1 时 `<` 不可用。当前行大于等于记录数，或当前行为 0 时，`>` 不可用。
- 浏览时主按钮文案改为「另建一条新直觉」。点击它不覆盖当前行，而是清空输入、当前行设为 0，再按新建流程 SubmitRecord。

舞台下方一行说明：修改旧记录不会自动重写直觉讲解。想按新信息重讲，请另建一条。

## 概念库

左上大标题：概念库。说明：回看已经点亮的概念，也可以改正名称、类型和公式。
右上按钮「+ 建立直觉」，跳到直觉工坊并清空，当前行设为 0。

上方搜索框：按概念名称包含匹配。筛选器：全部类型，以及三个概念类型原文字。筛选和搜索同时生效。没有单独的只读页。

主体用卡片墙，不用数据表格。数据：`callAppBridge({type:"GetTableCSV", data:"物理概念/默认表格", payload:"概念名称,概念类型,已记公式"})`。每张卡片左缘用类型色条，显示概念名称、类型徽章、已记公式。这三者和表单字段一致。卡片记住 CSV 原始行号。
每张卡片三个按钮，都必须实现：
- 看直觉：打开右侧或全屏详情。`callAppBridge({type:"GetCellValue", data:"物理概念/默认表格", payload:"概念名称/行号"})`、概念类型、已记公式、直觉讲解各读一次。直觉讲解用 Markdown 主题显示。直觉讲解为空时显示「这条讲解还在生成」，并提供「再读一次」重新 GetCellValue，不要编造。
- 编辑：打开编辑表单并载入该行。表单标题：改正这个概念。表：物理概念。字段仍是概念名称、概念类型、已记公式，概念类型用同样的三张入口卡。保存时依次 SetCellValue 这三个字段到该行号，成功后刷新卡片。明确提示：这次保存不会重写直觉讲解。
- 删除：先确认「删除后，这条直觉讲解也会一起消失」。确认后 `callAppBridge({type:"DeleteRecord", data:"物理概念/默认表格", payload:行号.toString()})`，然后重新 GetTableCSV 和 GetRecordCount。

点击卡片主体等同于看直觉。详情里再给「去改正」按钮，打开同一编辑表单。
空状态：没有记录时显示「概念库还是空的」，按钮跳到直觉工坊。筛选无结果时显示「没有符合的概念」，可一键清除筛选。

卡片可按「最新提交」（CSV 原顺序，第 1 行在前）或按概念名称排序。默认最新提交在前。

## 全局约束

三个页面共用晨光实验室主题。从首页统计卡、最近卡片、概念库卡片进入详情时，都要真正读到对应行，不能只跳页面。新建只走 SubmitRecord，修改只走 SetCellValue，删除只走 DeleteRecord，列表计数和字段展示都来自上述桥接。布尔值若将来出现，只能用「是」或「否」；本应用没有布尔字段。没有图片字段和文件字段，不要加上传、拍照或语音。操作失败时用一句人话说明，不要弹出未处理的异常。
