# 时空线索构建器

这是一个面向初高中历史学习的网页应用，名称「时空线索构建器」。围绕史事的时间与地点，让学生练习纪年换算、构建时间轴、对照同期中外史事，并识读历史地图。不包含登录页。页面只有三处：首页、线索工坊、练习册。全站统一「星图卷轴」主题，所有操作按钮的功能都必须实现。

视觉与交互
	导航栏背景 #152238，底边 2px 金线 #C6A15B。内容区背景 #F4EFE4，叠一层极淡的经纬网格。卡片 #FFFBF5，圆角 16px，悬停时上浮并亮起金边。主按钮朱砂色 #8C3A3A，次按钮青瓷色 #1F6F6A。标题用宋体或衬线回退，正文用无衬线。动效克制。
	四个练习方向固定色标，全站一致：时间轴 #C6A15B，中外对照 #1F6F6A，纪年换算 #8C3A3A，历史地图 #2C4A7C。
	列表一律用卡片，不用朴素表格充当主列表。卡片可点，效果等同点中表格行。
	本表没有自动编号 ID，也没有创建日期。字段名只能是：学段、练习方向、学习内容、文件、时空引导。禁止编造任何字段。

数据表
	表名：时空练习
	数据源一律写：时空练习/默认表格
	字段：
		学段，单选项，可选项只有：初中、高中
		练习方向，单选项，可选项只有：时间轴、中外对照、纪年换算、历史地图
		学习内容，文本
		文件，文本，存文件或图片的全局文件名，不是本地路径
		时空引导，指令流，任务智能体生成，输出类型为文本。不是用户手工填写的字段，表单上不提供输入框，也不加入 SubmitRecord 的 json，也不要用 SetCellValue 去改它
	指令流由后台在 SubmitRecord 之后异步生成。前端不调用技能。生成结果是 Markdown：简明讲解、必要的空白框架、下一步提示；时段特征按教材表述。界面只负责展示，不另写历史评价。

顶部导航
	左侧：金色罗盘图标 +「时空线索构建器」
	右侧标签：首页、线索工坊、练习册
	当前页标签用金线标出。窄屏时标签收成菜单，功能不变。

首页
	主标题：时空线索构建器
	说明：把史事安放在时间与地图上。先定位时间与空间，再练习先后、因果和同期中外联系。
	四个方向入口卡片并列，每张卡片有色标、方向名、一句学法说明，点击后跳到线索工坊，并预选对应练习方向：
		时间轴：先定位时间，留出空白时间轴，自己填写后再核对
		中外对照：把同期中外史事并置，留出对照表
		纪年换算：先讲清规则，再留换算练习
		历史地图：以教材地图为准，练习识读地点与范围
	其下三枚统计卡片，数字来自接口，进入页面和从其他页返回时刷新：
		练习总数
			callAppBridge({type:"GetRecordCount", data:"时空练习/默认表格"})
		初中练习数、高中练习数
			callAppBridge({type:"GetTableCSV", data:"时空练习/默认表格", payload:"学段"})
			csv 无标题行。按「初中」「高中」计数。点卡片跳到练习册并带上学段筛选
		四个方向的数量做成一条细色标统计，不单独占满屏
			callAppBridge({type:"GetTableCSV", data:"时空练习/默认表格", payload:"练习方向"})
			按四个可选项分组计数。点某一方向跳到练习册并带上方向筛选
	最近线索
		标题：最近线索
		callAppBridge({type:"GetTableCSV", data:"时空练习/默认表格", payload:"学段,练习方向,学习内容,文件"})
		csv 无标题行。新提交的记录在第 1 行，最近列表取前 4 行。没有记录时显示空状态：「还没有线索，从四个方向里挑一个开始」。
		每张卡片显示：方向色标、学段徽章、学习内容前 40 字、文件名（没有文件写「未附材料」）
		点击卡片查看详情：打开卷轴详情，不新开页面
			当前行 = 该行行号（csv 第 1 行数据的行号是 1）
			callAppBridge({type:"GetCellValue", data:"时空练习/默认表格", payload:"时空引导/"+当前行})
			文本用 Markdown 主题渲染。空内容显示「线索还在生成，可稍后刷新」
			同时用 GetCellValue 读取学段、练习方向、学习内容、文件，显示在详情头部
		卡片上还有「到工坊继续」：跳转线索工坊，载入该行，进入编辑模式

线索工坊
	左卷右轴的双栏。窄屏改为上下排列，表单在上，引导在下。
	左上标题：线索工坊
	说明：选定学段和方向，写下要练的史事；历史地图可附上教材地图。生成后先自己填空白框架，再对照引导。
	右上两个文字按钮：清空、去练习册
		清空：清空表单与引导区，当前行设为 0，退出编辑模式，不删表记录
		去练习册：跳转练习册
	左栏表单标题：时空练习
	表：时空练习
	字段：[{字段名:学段,类型:单选项,可选项:初中,高中},{字段名:练习方向,类型:单选项,可选项:时间轴,中外对照,纪年换算,历史地图},{字段名:学习内容,类型:文本},{字段名:文件,类型:文本},{字段名:时空引导,类型:指令流}]
		学段、练习方向用分段选择，不能自由输入
		学习内容是多行文本。占位按当前方向变化，只作提示，不自动写入：
			时间轴：例如，鸦片战争到辛丑条约的主要史事
			中外对照：例如，秦汉与同时期地中海世界
			纪年换算：例如，康熙六十一年是公元哪一年
			历史地图：例如，识读教材地图上的丝绸之路主要地点
		文件区显示当前材料名。三个按钮都要把返回的全局文件名写入文件字段，并可替换：
			选择文件：callAppBridge({type:"SelectFile"})
			选择图片：callAppBridge({type:"SelectImage"})
			拍摄地图：callAppBridge({type:"CapturePhoto"})
		另有「移除材料」，只清空本表单里的文件名，不删历史记录
		若全局文件名像图片，预览地址为 https://www.ithinkair.com:3031/download/全局文件名
		若扩展名是 html，用 iframe 打开 https://www.ithinkair.com:3031/private/全局文件名
		其他文件提供两个链接：浏览器打开 https://www.ithinkair.com:3031/private/全局文件名 ，下载 https://www.ithinkair.com:3031/download/全局文件名
		时空引导不出现在输入区
	主按钮随模式变化：
		新建模式，按钮文案「生成线索」。学段、练习方向、学习内容都有值才可点。文件可空。
		点击后 callAppBridge({type:"SubmitRecord", data:"时空练习", payload:"表单json"})
		json 只含四个键：学段、练习方向、学习内容、文件。文件没有则传空字符串。不要提交时空引导。
		提交成功后当前行设为 1，进入轮询。
		编辑模式，按钮文案「保存修改」。不调用 SubmitRecord。
		依次调用，行号用当前行：
			callAppBridge({type:"SetCellValue", data:"时空练习/默认表格", payload:"学段/"+当前行+"/"+学段值})
			callAppBridge({type:"SetCellValue", data:"时空练习/默认表格", payload:"练习方向/"+当前行+"/"+练习方向值})
			callAppBridge({type:"SetCellValue", data:"时空练习/默认表格", payload:"学习内容/"+当前行+"/"+学习内容值})
			callAppBridge({type:"SetCellValue", data:"时空练习/默认表格", payload:"文件/"+当前行+"/"+文件值})
		值里若含斜杠，仍按「字段名/行/值」拼接，行号是纯数字，从左侧拆出字段名和行号，其余全部算作值。
		保存只更新这四个手工字段，不重新生成时空引导。按钮旁用一句小字说明：改内容不会重写已生成的引导；要重做请清空后新建。
	右栏「引导卷轴」
		标题：时空引导
		右上角两个翻页按钮：< 和 >
		callAppBridge({type:"GetRecordCount", data:"时空练习/默认表格"}) 取得记录数
		当前行初始是 0
		当前行小于等于 1 时，< 不可操作
		当前行大于等于记录数，或记录数为 0 时，> 不可操作
		点击 < 或 > 时，当前行减 1 或加 1，然后用 GetCellValue 读取该行的学段、练习方向、学习内容、文件、时空引导，填入左栏并在右栏渲染。此时进入编辑模式。
		新建提交后的轮询：
			等待文案：正在铺开时空线索…
			每 2 秒调用 callAppBridge({type:"GetCellValue", data:"时空练习/默认表格", payload:"时空引导/"+当前行})
			得到非空文本后停止轮询，用 Markdown 主题显示标题、列表、表格、引用和空白框架
			最多 30 次。仍为空则显示「生成时间较长，可点刷新再看」，刷新按钮再次 GetCellValue，不重新 SubmitRecord
		当前行是 0 且尚未提交时，右栏显示方向学法，不伪造引导正文
		Markdown 区域只渲染接口返回的时空引导，不在前端补写历史结论

练习册
	左上标题：练习册
	说明：按学段和方向回看线索。点卡片可看引导，编辑只改手工字段。
	右上按钮：+ 新建线索，跳到线索工坊并执行清空，当前行设为 0
	搜索框：按学习内容包含匹配，输入即筛
	筛选：学段（全部、初中、高中），练习方向（全部、时间轴、中外对照、纪年换算、历史地图）
	从首页带入的筛选要直接生效，地址或页面状态均可，但必须能看出当前筛选
	列表数据：
		callAppBridge({type:"GetTableCSV", data:"时空练习/默认表格", payload:"学段,练习方向,学习内容,文件"})
		csv 无标题行。展示字段与表单手工字段一致，便于点卡片后编辑。
		必须记住原始行号：第 1 行数据行号为 1，筛选后仍用原始行号编辑和删除
	每张卡片显示方向色标、学段、学习内容前 60 字、文件名。没有记录时显示空状态和「去生成第一条线索」按钮。
	每张卡片三个按钮，都必须可用：
		查看引导
			打开卷轴详情层
			callAppBridge({type:"GetCellValue", data:"时空练习/默认表格", payload:"时空引导/"+行号})
			并用 GetCellValue 核对其余字段
			时空引导用 Markdown 主题显示
			文件按线索工坊同一套链接规则打开、下载或预览
			详情层里有「在工坊中打开」，跳转并载入该行
		编辑
			跳到线索工坊，当前行设为该行号，进入编辑模式
			逐字段 callAppBridge({type:"GetCellValue", data:"时空练习/默认表格", payload:"字段名/"+行号})
			字段名为学段、练习方向、学习内容、文件、时空引导
			前四项填表，时空引导只读渲染
			保存走 SetCellValue，不走 SubmitRecord
		删除
			先确认。确认后 callAppBridge({type:"DeleteRecord", data:"时空练习/默认表格", payload:行号.toString()})
			payload 必须是文本行号。删除后刷新 csv 和首页统计会用到的计数。若删的是当前行，把当前行设为 0。
	点击卡片主体等同查看引导。

卷轴详情
	不是单独页面，是首页和练习册共用的浮层。
	头部：学段、练习方向色标、学习内容全文、材料链接
	主体：时空引导的 Markdown
	底部：在工坊中打开、关闭
	浮层打开时不改变其他页已填了一半的内容，除非用户点「在工坊中打开」

行号与刷新
	GetTableCSV 返回的 csv 没有标题行，行号从 1 开始，与 GetCellValue、SetCellValue、DeleteRecord 的行号一致。
	需要按值找行时可用 callAppBridge({type:"GetRecordRow", data:"时空练习/默认表格", payload:"字段名/值"})，行号从 1 开始。学习内容可能重复，练习册以 csv 顺序行号为准，不依赖 GetRecordRow 做删除。
	callAppBridge({type:"GetCellBullet", data:"时空练习/默认表格", payload:"字段名/行"}) 仅在单元格需要显示要点标记时使用；时空引导正文仍以 GetCellValue 的 Markdown 为准。
	新建成功后当前行是 1。编辑、翻页、查看详情都不得把当前行重置成 1，除非刚刚 SubmitRecord。

接口约束
	取表：callAppBridge({type:"GetTableCSV", data:"时空练习/默认表格", payload:"逗号分隔的字段名"})
	提交：callAppBridge({type:"SubmitRecord", data:"时空练习", payload:"json文本"})
	计数：callAppBridge({type:"GetRecordCount", data:"时空练习/默认表格"})
	改单元格：callAppBridge({type:"SetCellValue", data:"时空练习/默认表格", payload:"字段名/行/值"})
	读单元格：callAppBridge({type:"GetCellValue", data:"时空练习/默认表格", payload:"字段名/行"})
	删除：callAppBridge({type:"DeleteRecord", data:"时空练习/默认表格", payload:"行号文本"})
	选择材料：SelectFile、SelectImage、CapturePhoto，返回值即全局文件名
	图片预览链接：https://www.ithinkair.com:3031/download/全局文件名
	浏览器打开：https://www.ithinkair.com:3031/private/全局文件名
	下载：https://www.ithinkair.com:3031/download/全局文件名
	不要实现登录、不要增加第二张表、不要增加未定义字段、不要把指令流做成手工输入。每个写明的按钮都要接到上述真实操作，不能只做静态界面。
