# 智能词汇学习

这是一个智能词汇学习网页应用，只使用表「词汇学习」，不新建其他表，不编造表里没有的字段（没有自动编号ID、没有创建日期，表单和列表都不要出现这些字段）。不包含登录页。不调用图片、文件、语音接口。页面统一采用「夜读灯台」主题：墨蓝导航、暖纸背景、词卡式结果区。所有出现的按钮都必须真正实现。

主题
	整页背景 #f6f0e6，卡片 #fffdf8，细边 #e6dcc8，正文「Noto Sans SC」「Source Han Sans」,sans-serif
	顶部导航墨蓝 #1b2740，当前标签用琥珀 #e07a3d 下划线
	主按钮 #e07a3d，悬停略深；次按钮描边墨蓝
	学段徽章：小学高段 #2f6f62，初中 #3d5a99，高中 #6b4c7a
	学习方式色条：录入词汇 #2f6f62，到期复习 #c46b2d，课前预热 #3d5a99，词库报告 #6b4c7a
	卡片和按钮有轻微悬停上浮。空状态用一句短说明，不用假数据

导航
	左侧：打开的书本图标 + 「智能词汇学习」
	右侧标签：首页、学习台、学习档案
	无登录、无用户菜单

数据约定
	表名：词汇学习
	数据源：词汇学习/默认表格
	字段只有：学段（单选项：小学高段、初中、高中）、学习方式（单选项：录入词汇、到期复习、课前预热、词库报告）、词汇或词表（文本）、上课日期（日期）、复习作答（文本）、学习结果（指令流，不是用户填写）
	单选项只能选定义过的可选项，不能手输新值
	GetTableCSV 返回不含标题行的 csv，列顺序与 payload 字段顺序一致；字段内可能有逗号，按 csv 规则解析
	列表、可编辑表单、GetTableCSV 三者字段一致，均为：学段,学习方式,词汇或词表,上课日期,复习作答。这样点一行能回填编辑
	学习结果不放进 GetTableCSV。查看详情时用 GetCellValue 取全文，用 Markdown 渲染，适合学生阅读
	行号从 1 开始，等于当前 csv 数据行序号。当前行初始为 0
	SubmitRecord 的 data 是「词汇学习」，payload 是 json 文本，只含五个输入字段，不要提交学习结果
	提交成功后当前行设为 1，然后轮询学习结果
	指令描述没有「以JSON格式输出」，所以轮询字段就是「学习结果」，不要改去轮询别的字段
	修改已有记录只用 SetCellValue 逐字段写当前行，不用 SubmitRecord，也不要 SetCellValue 写学习结果
	删除时 payload 必须是行号.toString()
	前端只统计表里真实记录。掌握情况、到期词、预热内容、词库报告全部以学习结果原文为准；没有记录时展示原文中的如实说明，不编造掌握率、不承诺提醒或自动推送

首页
	主标题：智能词汇学习
	说明：收录单词与词表，生成今日词卡和课前预热，按作答看复习建议，需要时再看词库情况
	四张方式入口卡片，点击跳到学习台并预选对应学习方式
		录入词汇：把新单词或词表收进词库
		到期复习：生成今日到期词卡，并可带上作答
		课前预热：按上课日期安排预热
		词库报告：汇总已有学习记录
	入口下方一行小字：每日到期词汇合并成一张词卡，本应用不发送提醒
	统计区四张小卡片，数据来自同一次或分别请求后在前端计数，不用假数
		全部记录
			API名称:GetRecordCount,数据源:词汇学习/默认表格
			callAppBridge({type:"GetRecordCount", data:"词汇学习/默认表格"})
		录入词汇、到期复习、课前预热各一张（词库报告并入方式分布，不单独占第四张统计卡，避免和入口重复）
			API名称:GetTableCSV,数据源:词汇学习/默认表格,字段:[学习方式]
			callAppBridge({type:"GetTableCSV", data:"词汇学习/默认表格", payload:"学习方式"})
			按学习方式精确匹配计数
		其下一条学段分布：小学高段、初中、高中的记录数，用短进度条，不是图表库也可以
			API名称:GetTableCSV,数据源:词汇学习/默认表格,字段:[学段]
			callAppBridge({type:"GetTableCSV", data:"词汇学习/默认表格", payload:"学段"})
	最近学习
		标题旁按钮：查看全部档案，跳转学习档案
		卡片列表，取表格前 5 行（提交后新记录在第 1 行，故前 5 行即最近）
		API名称:GetTableCSV,数据源:词汇学习/默认表格,字段:[学段,学习方式,词汇或词表,上课日期,复习作答]
		callAppBridge({type:"GetTableCSV", data:"词汇学习/默认表格", payload:"学段,学习方式,词汇或词表,上课日期,复习作答"})
		每张卡片显示：学习方式色条、学段徽章、学习方式、词汇或词表（超过 40 字截断）、上课日期（空则显示「—」）
		点击最近卡片：打开详情，不直接进编辑
		无记录时显示：还没有学习记录，从一种学习方式开始
	详情（首页与学习档案共用同一详情层）
		标题：学习详情
		用 GetCellValue 按当前行读取五个输入字段和学习结果
			callAppBridge({type:"GetCellValue", data:"词汇学习/默认表格", payload:"字段名/行号"})
			字段名依次为：学段、学习方式、词汇或词表、上课日期、复习作答、学习结果
		输入字段以标签+文本展示；上课日期、复习作答为空显示「—」
		学习结果区标题「学习结果」，Markdown 渲染；内容为空时显示「结果尚未生成」
		右上角按钮：< 上一则、> 下一则
			API名称:GetRecordCount,数据源:词汇学习/默认表格
			当前行<=1 时 < 不可用；当前行>=记录数时 > 不可用
			切换后仍用 GetCellValue 重读该行
		底部按钮：去编辑（打开编辑层并回填）、删除、关闭
		删除：确认后 callAppBridge({type:"DeleteRecord", data:"词汇学习/默认表格", payload:行号.toString()})，成功后关闭详情并刷新首页与档案

学习台
	左上标题：学习台
	说明：选一种方式，写下学段和需要的内容，生成适合学生阅读的结果
	右上按钮：学习档案，跳转学习档案
	左侧四张方式选择卡，与首页四种学习方式相同，选中后有色条和描边。从首页带方式进入时预选该项
	右侧自适应表单，表单标题随方式变化：录入词汇、到期复习、课前预热、词库报告
		表:词汇学习
		字段:[{字段名:学段,类型:单选项,可选项:小学高段,初中,高中},{字段名:学习方式,类型:单选项,可选项:录入词汇,到期复习,课前预热,词库报告},{字段名:词汇或词表,类型:文本},{字段名:上课日期,类型:日期},{字段名:复习作答,类型:文本}]
		学习方式由左侧选择卡写入，表单上不再重复一个可乱改的下拉，避免和选择卡不一致
		学段：分段按钮，三种学段必选
		录入词汇：显示并必填词汇或词表，占位「每行一个单词，或粘贴词表」；隐藏上课日期和复习作答，提交时这两项为空字符串
		到期复习：词汇或词表选填，标签「使用语境（可选）」；复习作答选填，标签「学生作答（可选，用于调整复习建议）」；隐藏上课日期，提交为空字符串；方式说明：只根据已有学习记录判断到期词，没有记录会如实说明；到期词合并为一张词卡，不发送提醒
		课前预热：上课日期必填；词汇或词表选填，标签「使用语境（可选）」；隐藏复习作答，提交为空字符串
		词库报告：只保留学段；词汇或词表、上课日期、复习作答都隐藏并提交空字符串
	按钮：生成学习内容
		未满足当前方式的必填项时禁用
		点击后 callAppBridge({type:"SubmitRecord", data:"词汇学习", payload:表单json文本})
		json 键名必须是：学段、学习方式、词汇或词表、上课日期、复习作答
		提交后当前行设为 1
	按钮：清空
		清空表单、清空学习结果、取消方式预选以外的输入，当前行设为 0，不删除任何记录
	结果面板在表单下方，做成一张可阅读的词卡纸，最大宽度适合阅读
		等待时只显示：正在根据学习记录生成内容，请稍候…
		轮询标题:智能词汇学习,表:词汇学习,字段:学习结果,输出到:学习结果面板,等待消息:正在根据学习记录生成内容，请稍候…
		轮询 callAppBridge({type:"GetCellValue", data:"词汇学习/默认表格", payload:"学习结果/1"})
		约每 1.5 秒一次，直到文本非空再停止；空内容期间不编造词卡、报告或掌握率
		得到文本后用 Markdown 主题显示
		结果面板小字：内容来自本次学习结果；缺少记录时以其说明为准
	结果出现后显示按钮：再学一项
		作用同清空，但保留刚选的学习方式和学段，方便连续录入

学习档案
	左上标题：学习档案
	说明：查看、修改或删除已提交的学习。修改输入不会重新生成学习结果
	右上按钮：+ 新建学习，跳转学习台并清空
	搜索框：按词汇或词表、复习作答包含匹配，不区分大小写
	筛选：学段（全部、小学高段、初中、高中）、学习方式（全部、录入词汇、到期复习、课前预热、词库报告）
	筛选和搜索都在已取回的 csv 上完成，改变条件立即刷新卡片，不清空表格数据源
	主体用卡片列表，不用只读单独页
		API名称:GetTableCSV,数据源:词汇学习/默认表格,字段:[学段,学习方式,词汇或词表,上课日期,复习作答]
		callAppBridge({type:"GetTableCSV", data:"词汇学习/默认表格", payload:"学段,学习方式,词汇或词表,上课日期,复习作答"})
		每张卡片显示与表单一致的字段：学段、学习方式、词汇或词表（超过 80 字截断）、上课日期、复习作答（超过 40 字截断，空为「—」）
		卡片左侧学习方式色条
		点击卡片主体：进入编辑，当前行=该卡片行号，用 GetCellValue 逐字段回填五个输入字段
		每张卡片按钮：查看结果、编辑、删除
			查看结果：打开共用详情层，当前行=该行，逻辑同首页详情
			编辑：同点击卡片主体
			删除：确认后 callAppBridge({type:"DeleteRecord", data:"词汇学习/默认表格", payload:行号.toString()})，然后重新 GetTableCSV 并保持当前筛选
		无匹配时显示：没有符合条件的学习记录
	编辑层
		标题：修改学习记录
		字段与新建表单相同，并按该行学习方式显示或隐藏上课日期、复习作答、词汇或词表
		打开时：
			callAppBridge({type:"GetCellValue", data:"词汇学习/默认表格", payload:"学段/当前行"})
			同样读取学习方式、词汇或词表、上课日期、复习作答
		不展示、不编辑学习结果；层内说明：保存只更新输入字段，不会重新生成学习结果。若要新的词卡、预热或报告，请新建一次学习
		按钮：保存
			依次 SetCellValue，不要 SubmitRecord
			callAppBridge({type:"SetCellValue", data:"词汇学习/默认表格", payload:"学段/当前行/值"})
			再写学习方式、词汇或词表、上课日期、复习作答
			隐藏字段也要写成空字符串，避免旧值残留
			五个字段都写完后关闭编辑层，重新 GetTableCSV 刷新卡片
		按钮：取消，关闭且不写回
		必填规则与学习台相同，不满足则不能保存

刷新与空值
	从学习台提交成功并得到学习结果后，首页统计和最近列表、学习档案列表在下次进入时重新请求；学习台提供「已生成，去档案查看」链接，跳到学习档案并刷新
	日期空值在界面显示「—」，提交和 SetCellValue 时用空字符串
	任何操作失败时在该页面显示返回的错误信息，不写入假记录
